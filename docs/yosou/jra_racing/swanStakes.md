## 4. 過去データ・集計条件
### 4.1 定義・欠測・時間境界
- 母集団は2021～2025年の実出走89頭（同一馬の複数開催を別出走として数える）。全着順、前走、5代血統、発走前の年内勝利・GⅠ歴を照合。2026年のレース結果・当日値は一切入れていない。
- 成績表記は1着－2着－3着－4着以下／出走数・3着内率。率は該当全出走を分母に計算し、3着以内馬だけの割合と区別する。非該当群も同じ開催条件から抽出。
- 父ディープ系は父から父を遡る直系にディープインパクトを含むもの。母系のディープ内包や、ブラックタイド系をここへ含めない。
- 内包は対象馬を0代として1～5代の血統表内にRoberto、Danzig、Caro本人がある場合。父系・母系を問わない。6代以降は今回の非該当であり「完全に血を持たない」という意味ではない。血脈の重複を独立加点しない。全対象の5代表は62祖先セルを確認した。
- 母父条件はノーザンダンサーの父系かつ現役時に米国拠点の調教歴あり。海外遠征で米国レースに出ただけ、米国産であるだけ、広義の米国型であるだけの馬は含めない。該当母父一覧・根拠は4.5。
- 差し／追込の恒常的な脚質は今回のレース結果から確定しない。ここでは実際の4角位置の区分で代理照合し、5～9番手と10番手以下を併記する。今回の4角は事後データであり、2026年本番に確定値として入力できない。前走4角は別項目として扱う。
- OPクラスはOP特別、リステッド、GⅠ～GⅢを含む。勝利歴は当該スワンS発走より前に限定。前方好走馬の必要条件の観測であり、OP勝利馬全体の好走率を示す項目ではない。
- 前走は出走が成立した直前のレース。競走除外を前走として数えない。前走上がり順位は同レース出走馬の上がり秒数から `1 + 自馬より速い頭数` で求め、同タイムは同順位。前走5着以内の全37出走は該当する34レース結果で照合し、それ以外52出走は複合条件が着順だけで非該当と確定するため、上がり順位を省略した。未取得順位を0や最下位にはしていない。
- 前走着差は勝ち馬との秒差。勝利時の2着馬との差を敗戦条件へ混ぜない。馬体重はスワンS当日発表値、人気は当日確定単勝人気。2026年の当日未発表値は事前想定値で代用しない。
- 年内1400m勝利は当該年1月1日～スワンS発走前の芝1400m、クラスを問わない。ダート1400m勝利は主集計から除外。近1年のGⅠ馬券内は前年同日を含みスワンS発走前までの3着以内。前走5走表示だけで無実績と決めず、各馬の競走履歴を日付で絞った。
- 取得日は2026年だが、過去各年の実績条件は各年の発走前を境界とし、後のスワンSや年末重賞の勝利を混入させていない。これは事後取得による過去集団の照合であり、当時事前登録された仮説の検証成績ではない。
- 基本条件・血統の欠測は0件。上がり順位の省略52出走は上記複合条件の判定に影響しない。OP勝利歴は前方好走馬3出走の実例照合だけを完了し、着外を含む全出走のOP未勝利判定は主張しない。
