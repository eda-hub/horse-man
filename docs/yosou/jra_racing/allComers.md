# 産経賞オールカマー — 年次予想ノート

本ファイルはオールカマーの**レース固有知識を翌年以降へ引き継ぐためのノート**である。

予想ルールは docs/manual/、結果後の正式なProduction / Shadow回顧、KPI、エラー分類、実購入、ROI等は docs/validation/ を正本とし、本ファイルには保存しない。

## 1. レース構造

- 中山芝2200m・外回り
- スタート後まもなく急坂を上る
- 2コーナーから下り勾配が続き、中盤からスピードに乗りやすい
- 直線は310mと短いが、最後に高低差2.2mの急坂
- JRAのコース解説では、中盤から早めにスパートが始まりやすく、瞬発力だけでなく**長く脚を使い続ける能力**が要求される

したがって翌年も、単純な上がり順位だけでなく、
- 高速巡航
- 早め進出
- 4角までの位置取り
- 持続力
- 坂での余力
をセットで確認する。

## 2. JRA公式の過去10年傾向（2026年レース前集計）

### 人気

3着以内30頭のうち23頭が5番人気以内。

- 1番人気: 4-2-0-4
- 2番人気: 1-2-1-6
- 3番人気: 0-3-3-4
- 4番人気: 2-0-1-7
- 5番人気: 3-1-0-6
- 6〜10番人気: 0-2-4-43
- 11番人気以下: 0-0-1-30

通常年は上位人気の信頼度が比較的高い。ただし2026年は重馬場で9番人気の7歳馬が勝っており、**道悪時にこの集計をそのまま使わない**。

### 年齢

- 4歳: 6-3-3-14
- 5歳: 4-3-5-35
- 6歳: 0-4-1-26
- 7歳: 0-0-1-14
- 8歳: 0-0-0-10

2026年以前の集計では4・5歳が中心だったが、2026年は7歳メイショウゲキリンが勝利。年齢は能力の代理変数として機械的に消さず、当日の馬場・展開・個体状態を優先する。

### 枠

JRA公式の過去10年集計では、
- 連対馬20頭中14頭
- 3着以内30頭中17頭
が1〜4枠。

**内寄りの枠がやや優勢**という傾向は翌年も確認対象とする。ただし枠だけで評価せず、枠×脚質×当日馬場×隊列で扱う。

### 前走格

過去10年の3着以内30頭中20頭は前走GⅠ・GⅡ組。

- GⅠ: 6-4-3-24
- GⅡ: 0-3-4-20
- GⅢ: 4-2-1-37
- その他: 0-1-2-19

通常は格の高い前走組を優先的に確認する。ただし2026年は前走障害未勝利のメイショウゲキリンが勝利したため、ローテ区分だけで例外候補を排除しない。

## 3. 近年の馬場

JRA公式ページの過去3年は、
- 2023年: 晴・良
- 2024年: 曇・良
- 2025年: 曇・良

と全て良馬場だった。

そのため、近年の結果から作った人気・脚質・上がり・枠等の傾向は**良馬場寄りのサンプル**である可能性を意識する。

2026年は雨・重で行われ、9番人気メイショウゲキリンが逃げ切り、6番人気キャントウェイトが2着、3番人気ヴーレヴーが3着。通常年の人気・年齢傾向から大きく外れた。

翌年はまず、
1. 良馬場用の長期傾向
2. 道悪時の当日実測
を別々に扱う。

## 4. 2026年から残すレース固有知識

### 道悪時は当日バイアスを優先確認

2026年は重馬場で逃げ切りが発生した。

道悪だから自動的に前有利と決めないが、同日の中山芝で複数レースの4角位置・内外・上がりを確認し、一貫した前残りが見える場合は、通常の過去10年傾向より当日実測を重く見る。

### pace_keyを人気・能力順位と分離する

2026年勝ち馬メイショウゲキリンは9番人気だったが、実際は楽に先手を取り、そのまま逃げ切った。

翌年は低評価馬でも、
- ハナを切れる馬
- 他に競る馬が少ない馬
- 道悪で自分のリズムを守れる馬
を能力順位とは別に pace_key 候補として確認する。

### 個体のローテーション履歴

一般的な「休み明け成績」だけでなく、同じ馬について、
- 休養明け
- 叩き2戦目
- 秋2〜3戦目
- 目標GⅠの前哨戦
でパフォーマンスがどう変化するかを確認する。

コスモキュランダは、2025年オールカマー8着後に秋を使い、有馬記念2着。2026年もオールカマーで11着だった。

ただし「休み明けは必ず走らない」とは固定しない。馬場・位置取り・相手関係等の交絡を確認し、次回出走時に個体ローテーション仮説として再検証する。

### 直接実走をコース仮説より優先

急坂・中山2200mへの適性仮説は重要だが、馬自身が道悪で高いパフォーマンスを出している場合、その直接実走を無視して機械的に消さない。

翌年は、
- 同競馬場
- 同距離
- 似た高低差
- 同じ馬場状態
の直接実走を先に確認し、血統・一般的なコース印象は補助材料とする。

## 5. ユーザー蓄積傾向の扱い

翌年も確認する仮説:
- 前目有利
- 内枠有利
- 馬番10番以降不利
- 中山巧者
- ノーザンテースト系内包
- ロベルト系
- 前走上がり3位以内

現時点でJRA公式の長期集計から直接確認できるのは、**内寄りの枠がやや優勢、上位人気・若い馬・前走上級重賞組が比較的好成績**という部分。

馬番10番以降、ノーザンテースト系、ロベルト系、前走上がり順位については、翌年予想時に独立データで再確認する。単一傾向だけでProduction順位を機械的に動かさない。

## 6. 翌年の予想フロー

### 良馬場

1. 基礎能力と近走内容を通常どおり評価
2. 中山2200mの持続力・早め進出能力を確認
3. 中山・急坂・2200mの直接実績を確認
4. 枠×脚質×隊列を評価
5. JRA長期傾向をレース固有コンテキストとして確認
6. 人気・オッズは能力順位固定後に確認

### 稍重・重・不良

1. 長期傾向を良馬場前提で機械転用しない
2. 同日中山芝の関連レースを複数確認
3. 上位馬の4角位置、内外、逃げ・先行残存率を整理
4. 当日実測が弱ければ予想確信度・購入優先度を抑える
5. 当日実測が強ければ前受け・pace_keyを含む専用シナリオを作る
6. 各馬自身の道悪実走を血統傾向より優先
7. 通常と異なるローテ・調整過程がある馬は状態変化を確認

## 7. 翌年チェックリスト

- [ ] 馬場は良か、道悪か
- [ ] 過去傾向の母集団は今回馬場と整合するか
- [ ] 同日中山芝で2レース以上の当日実測があるか
- [ ] 4角で有利な位置帯はどこか
- [ ] pace_key / 単騎候補を能力順位と別に抽出したか
- [ ] 中山2200m・急坂・持続戦の直接実績を確認したか
- [ ] 各馬の道悪直接実走を確認したか
- [ ] 休み明け・叩き後等の馬個体ローテーションを確認したか
- [ ] 血統傾向を直接実走より上位に置いていないか
- [ ] 内枠傾向を脚質・馬場と組み合わせているか
- [ ] 外枠・高齢・人気薄を統計だけで機械的に消していないか
- [ ] 良馬場向け過去傾向を重馬場へそのまま転用していないか
