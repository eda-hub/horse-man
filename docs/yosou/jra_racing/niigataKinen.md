## 2. 予想時の基本方針

### 使用した競馬予想ルール

使用ルールは、チャットに添付された **「競馬予想ルール原本 v1.4.1（2026-08-30、自動実行対応・重賞Deep-Dive・購入最適化・情報源ポリシー版）」**。

運用は以下の順序で実施した。

1. MODE 1「単一レース・Champion正式予想」
2. Champion Coreを先に固定
3. 重賞Deep-Dive Moduleを適用
4. 過去傾向・5代血統・枠順・前走・騎手を確認
5. 当日馬場・馬体重・オッズを差分反映
6. 稍重への馬場変更により最終評価を再調整
7. ユーザー購入条件指定後、MODE 7で③④⑤⑧⑪の範囲内に限定して買い目を最適化

ZONE C2のExperimentalは正式予想には混入させず、Core / Module / Auditを中心に運用した。

### 情報源の扱い

- Tier 1: JRA公式を出走・馬場・斤量・結果・払戻等の事実確定に使用
- Tier 2: JBIS等を5代血統・血統構成確認に使用
- Tier 3: 競馬専門データサイトを過去傾向の発見・照合に使用
- 非公式サイトの◎○▲や買い目は直接採用しない
- SNS・匿名掲示板・出典不明の関係者情報は根拠にしない

### 海外情報の扱い

本レースはJRA国内重賞のため、海外現地主催者情報を予想材料として利用する必要はなかった。海外血統についてはJBIS等の血統DBで祖先・系統として確認し、血統を結論ではなく適性仮説として利用した。

### オッズの扱い

能力評価と市場価格を分離した。

- 「最も勝つと思う馬」と「最も買いたい馬」を別に設定
- オッズのみで印・能力順位を変更しない
- 価格は単勝・連系馬券の購入価値と資金配分にのみ反映

事前〜直前では⑧ダノンシーマを最も勝つ可能性が高い馬、⑪ステレンボッシュを最も買いたい馬として評価した。

### 能力・適性・展開・馬場の評価方法

特に重視した3要因は以下。

1. 新潟外2000mで必要な高速巡航力と長い末脚
2. 現在能力と実戦再現性
3. 当日の雨・稍重による持続力・スタミナ要求の増加

血統・枠・騎手は単独加点せず、実走能力と今回条件を補強または反証する材料として扱った。

## 7. 回顧

### 予想で良かった点

1. **○⑤ゾロアストロを稍重で上方修正し、最終勝率22%まで上げたこと**
   - 実際に1着。
   - 3歳55kg、持続力、2000m経験を評価した方向は正しかった。

2. **◎⑧ダノンシーマを連軸として維持したこと**
   - 実際に3着。
   - 稍重になっても「勝ち切り評価を少し下げるが連系の安定性は維持」という判断は概ね妥当だった。

3. **購入対象5頭の中に実際の1〜3着馬③⑤⑧を全て含めていたこと**
   - 馬の抽出自体は大きく外していなかった。

4. 過去傾向として重視した**若い馬・速い上がり・内過ぎない枠**が結果に反映された。

### 予想の反省点

1. **③ロデオドライブを稍重で下げ過ぎた**
   - 初2000m×57kg×稍重を不確実性として強く見たが、G1勝ちの絶対能力と重馬場勝ちの実走証拠をもう少し優先すべきだった。
   - 「未知≠弱点」の原則を守りつつも、最終段階で未知を実質的な減点として扱い過ぎた。

2. **⑪ステレンボッシュの妙味評価を買い目全体へ広げ過ぎた**
   - 価格差は存在しても、勝率レンジが広く、最終的には11着。
   - 「最も買いたい馬」＝「全券種の共通軸」ではないというルール45・48をより厳格に適用すべきだった。

3. **稍重化による④の上方修正がやや過大**
   - 59kg・長期休養という状態・負担重量の反証を、馬場適性上昇で打ち消し過ぎた。

### 買い方の反省点

最大の問題は、**予想対象馬の選択ではなく組み合わせ設計**。

最終予想では⑤と⑧が最上位級、③もヒモとして残していたにもかかわらず、購入時に⑪を中心とする構造へ寄り過ぎ、③⑤⑧の自然な本線組み合わせを落とした。

特に三連複③-⑤-⑧は、

- ⑤: 最終勝率22%の○
- ⑧: 最終勝率22%の◎・連軸
- ③: 勝率14%を残したG1馬

という3頭であり、購入前の「上位評価馬と本線シナリオから自然に生じる候補組み合わせを一度列挙する」という既存ルール48の監査を十分に実行できていなかった。

### エラー分類

- 主因: **馬券構造・資金配分ミス**
- 副因: **G（適性評価）/ ③の稍重2000m不確実性をやや過大評価**
- 副因: **妙味馬⑪への依存率過大**
- Core能力評価そのものは大幅変更不要。

**なし。**

5. 「未知」を理由にG1級の実走能力を大幅に下げない。初距離等はまず確率レンジ拡大として扱う。

## 9.2 血統

主な例:

- 2026 ロデオドライブ: サートゥルナーリア→ロードカナロア→キングカメハメハ

ただし直近5年の勝ち馬で直接このラインが明確なのは2022カラテのみ。**勝ち馬必須条件ではなく、連系・適性のプラス条件**として扱う。

### Danzig系

- 2025勝ち馬シランケドはDeclaration of War系でDanzigライン。
- 2026のロデオドライブは母系にDanehill〜Danzigを持つ。
- 5代血統まで広げると該当馬が増えやすく、母数効果が大きい。

したがって**Danzig内包単独では買わず、持続力・末脚・中距離実走等との複合条件**にする。

### Roberto系

- 2023 ノッキングポイント: モーリス系
- 2026 ゾロアストロ: モーリス系

直近5年でモーリス産駒が2勝。新潟外回りで必要な持続力との整合はあるが、まだ単独ルール化しない。

### 血統結論

優先度:

1. **Kingmambo〜キングカメハメハ系の近い内包: 強めの補助条件**
2. Roberto系: 継続観察
3. Danzig系: 補助条件
4. 血統より本人の2000m・長い直線・末脚実績を優先

### 前走上がり順位

過去10年集計（2026予想時点）では、

- 前走上がり1位: 2-3-3-16、複勝率33.3%
- 前走上がり4〜5位: 複勝率約35%
- 前走上がり6位以下: 複勝率約10.8%

2026は2着③ロデオドライブ、3着⑧ダノンシーマが前走上がり最速組に該当。

したがって**「前走上がり最速」は有効な買い要素。ただし1位だけに限定せず、上がり4〜5位まで含めてレース内容を評価する。**

### 前走4角10番手以下

2026では⑤ゾロアストロが前走4角15番手、③ロデオドライブが14番手で1・2着。一方、過去10年の前走脚質別では後方組の複勝率が突出しておらず、前走後方という事実だけでは強い買い条件にならない。

よって、

> **前走4角10番手以下 ＋ 上がり上位 / 高レベル戦で内容良好**

という複合条件に修正する。

## 9.8 距離

直近5年勝ち馬の前走距離は1600〜2400mまで幅広く、特定の前走距離に限定する合理性は低い。

新潟外2000mでは、前走距離そのものより、

- 高速巡航力
- 長い直線での末脚
- 2000m前後のスタミナ
- 高レベル戦での追走経験

を優先する。

# 10. 2026年結果と過去傾向の比較

## 強く一致した点

1. **若い馬優勢**
   - 3歳→3歳→4歳。
2. **極端な内枠の不振**
   - 1〜3着は5・3・7枠。直近5年の1〜2枠馬券内ゼロを継続。
3. **終盤性能の重要性**
   - 勝ち馬⑤が上がり33.8秒で最速。
4. **前走G1組**
   - ⑤皐月賞、③NHKマイルCが1・2着。
5. **上位人気の能力が素直に反映**
   - 2→3→1人気。
6. **Kingmambo〜キングカメハメハ系内包馬が馬券内**
   - ③ロデオドライブが該当。

## 部分的に一致した点

1. **外枠差し**
   - ⑧7枠は3着だが、1着⑤は5枠、2着③は3枠。
   - 「外枠限定」ではなく「内過ぎない枠」が正確。
2. **前走上がり最速**
   - ③⑧が該当して2・3着。
   - 勝ち馬⑤は非該当なので必須条件ではない。
3. **Danzig系内包**
   - ③等に確認できるが、広い5代内包では該当母数が増えるため補助評価に留める。
4. **前走4角10番手以下**
   - ⑤③は該当したが、過去全体では後方脚質自体の優位は弱い。

## 過去傾向に逆行・弱かった点

1. **荒れ傾向**
   - 2026は2→3→1人気、三連複810円の堅い決着。
2. **後方一気**
   - 1〜3着は全て4〜6番手。後方待機馬ではなかった。
3. **乗り替わり不利傾向**
   - ③はC.ルメールへの乗り替わりで2着。
4. **5枠の過去10年低勝率**
   - ⑤ゾロアストロが5枠から勝利。

### 総合整合度

2026年は、若馬・上がり・前走G1・内枠不振など主要項目が一致した一方、荒れ方・後方差し・細かな枠別傾向は外れた。

**過去傾向との整合度は概ね75〜80%程度（かなり高い）**と評価する。ただしこれは点数化された公式指標ではなく、複数の主要傾向を比較した便宜的評価。

# 11. 2027年に使用する買い条件

優先順位順。

### 強めの買い条件

1. **3〜5歳を中心評価。特に3歳でG1/G2級の能力証明がある馬**
2. **前走G1組**。大敗でも着順だけで消さず内容・相手レベルを再評価
3. **前走上がり最速〜上位5位程度**で、位置取り・ペースを考慮して末脚内容が優秀
4. **新潟外2000mに対応できる高速巡航＋長い末脚の実走証拠**
5. **3〜8枠**を基本的なプラス領域として確認
6. 父系または母父など近い世代に**Kingmambo〜キングカメハメハ系**を持つ馬

### 複合条件で使う買い要素

- Danzig系内包 ＋ 中距離実走 / 持続力 / 上がり性能
- Roberto系 ＋ 実走適性
- 前走4角10番手以下 ＋ 上がり上位
- 人気薄の前走G1大敗 ＋ 内容上の明確な巻き返し根拠

---

# 12. 2027年に使用する消し・割引条件

機械的な完全消しではなく、原則割引。

1. **1〜2枠 ＋ 末脚/位置取りに別の強い根拠がない馬**
2. 7歳以上を**勝ち馬候補としては割引**。ただし連下穴では残す
3. 前走後方だっただけで上がり・内容が伴わない馬
4. Danzig/Kingmambo等の血統だけが買い根拠で、実走が伴わない馬
5. 長期休養・高斤量など状態不確実性が大きいのに、馬場適性だけで評価を戻した馬
6. 妙味があるだけでCore中位以下の馬を全券種の共通軸にすること

---

# 13. 穴馬として評価する条件

1. **前走G1で大敗して人気を落としているが、相手レベル・ラップ・不利等から能力を維持している馬**
2. 7歳以上でも、長い直線の末脚・新潟実績・上がり性能が明確な馬は2〜3着穴として検討
3. 前走上がり上位なのに着順だけで人気を落としている馬
4. Kingmambo / Roberto / Danzig等の適性仮説と本人の実走が一致
5. 中〜外枠で、当日の馬場傾向と脚質が一致
6. 人気薄の理由が今回条件で解消されると説明できること

穴馬は「高オッズだから」ではなく、**価格乖離＋複数の独立根拠**がある場合のみ昇格する。
