#### 11.2 年齢

直近5年の勝ち馬は**3～5歳のみ**。

- 3歳：1勝
- 4歳：2勝
- 5歳：2勝
- 6歳以上：0勝

レース前の過去10年データでも3～5歳が各3勝、計9勝で中心。2026年も4歳馬が1、2着となり強く一致した。

一方、9歳ウインカーネリアンが3着。高齢馬全体は低率だが、直近G1級能力を維持している例外個体は年齢だけで消さない。

#### 11.3 性別

レース前過去10年では牝馬は5勝、勝率8.6%、複勝率24.1%で、牡・セン馬の勝率5.2%、複勝率16.7%を上回っていた。2026年は4歳牝馬サウンドモリアーナが勝利。

直近5年では牡3勝、牝2勝で一方的ではないため、**牝馬は加点材料だが単独決定要因にはしない**。

#### 11.4 人気・オッズ

2022～2026年の勝ち馬人気は **6、1、2、2、5番人気**。直近5年は全て6番人気以内。

過去10年データでは上位人気の安定感がありながら中穴も頻繁に馬券内へ入る。2026年は5人気→1人気→3人気で、極端な大荒れではなく、**上位人気＋中穴**の典型形だった。

来年も「1番人気を無条件に軸」ではなく、4～9番人気に根拠ある妙味馬がいるかを確認する。

#### 11.5 枠順・馬番

JRAの2025年時点過去10年では、1～4枠が1勝、5～8枠が9勝。内寄りは2、3着には来ても勝ち切りにくい傾向だった。

2026年は7枠14番が勝利し、傾向に強く一致。2枠3番パンジャタワーは2着で、**内枠は消しではないが、勝ち切り評価では外寄りを優遇**する使い方が適切。

馬番14はレース前過去10年で3勝しており、2026年も14番が勝った。

#### 11.6 前走クラス・距離

レース前過去10年では、前走G3組4勝、G1組3勝で重賞組が中心。前走1600m組は勝率21.4%、複勝率42.9%と高く、G1マイルからの短縮も有力。

2026年は、

- 1着サウンドモリアーナ：前走G3北九州記念・1200m・6着
- 2着パンジャタワー：前走G1安田記念・1600m・5着
- 3着ウインカーネリアン：前走G1高松宮記念・1200m・3着

で、前走重賞組の強さがそのまま表れた。

過去10年では同級前走6～9着組が5勝。2026年勝ち馬も前走6着であり、**適度な敗戦からの巻き返し**は重要な買いパターン。

#### 11.7 前走4角位置

netkeibaの過去10年集計では、前走4角10番手以内の馬が大半の勝ち馬・馬券内を占める。2026年馬券内3頭も、前走で極端な後方一辺倒ではなかった。

個人メモの「前走4角9番手以内」は方向性が良いが、過去データとの整合から**前走4角10番手以内**へ修正して運用する。

#### 11.8 脚質・展開

過去10年では中団差しの勝利数が多い一方、好走率は逃げ・先行が高く、後方追込は低調。つまり「前だけ」「差しだけ」ではなく、**勝負所までに射程圏へ入れること**が重要。

2026年は1着2番手、2着6番手、3着逃げ。後方一気ではなく、過去傾向と強く一致した。

#### 11.9 馬場

直近5年は2023年の重を除き4年が良馬場。良馬場では1:07～1:09前半の高速決着が複数あり、高速巡航力を重視する。

ただし重馬場でも2023年ナムラクレアが勝っており、当年の馬場状態が変われば洋芝・道悪適性を別途評価する。過去の平均像で当日馬場を上書きしない。

#### 11.10 騎手

直近5年の勝利騎手は全て異なる。騎手名そのもののリピーター傾向は弱い。

ただし松山弘平は2025年パンジャタワーで勝利し、2026年も同馬で2着。馬・コースとの組み合わせとしては評価可能。

2026年は過去10年の同レース勝利がなかった武豊が勝利し、三浦皇成も3着。**騎手の同レース過去成績を枠・能力・適性より上位の消し条件にしない**。

#### 11.11 調教師・調教国

直近5年勝ち馬の所属は、

- 栗東：4勝（2022、2023、2025、2026）
- 美浦：1勝（2024）

全てJRA国内調教馬。近5年は栗東優勢だが母数5年なので強い消し条件にはしない。

「調教国」については直近5年全て日本調教馬で、海外調教馬の比較母数が乏しい。海外調教馬が出走する年のみ別途検証する。

#### 11.12 血統（父・父系）

レース前過去10年ではロードカナロア産駒が3勝で最多。父系ではサンデーサイレンス系とキングマンボ系が各3勝だった。

直近5年勝ち馬の父は、

- タートルボウル
- ミッキーアイル
- ロードカナロア
- タワーオブロンドン
- ミッキーアイル

ミッキーアイル産駒が2023年・2026年に勝利している。

#### 11.13 5代血統での深掘り

父・母父だけでなく5代血統まで見ると、2026年上位勢には**Danzig系、Mr. Prospector系、Sadler's Wells系、Nureyev、Robertoなどのスピード＋パワー＋持続力要素**が複合している馬が複数いた。

例：

- **サウンドモリアーナ**：父ミッキーアイル。父側にDanzig系・Nureyev、母系にもMr. Prospector系などを持ち、短距離の高速性能とパワーを併せ持つ構成。
- **パンジャタワー**：タワーオブロンドン系のGone West/Mr. Prospector要素に加え、母系のサンデーサイレンス、Machiavellian、Danzig系などが重なる。
- **ロードフォアエース**：ロードカナロア×War Frontで、Danzig、Sadler's Wells、Storm Cat、Mr. Prospectorを内包。2026年12番人気5着で、血統面から大穴評価を補強できた可能性がある。

ただしこれは2026年の単年回顧から見つけた仮説である。**5代内Danzig＋Mr. Prospector等の共存を単独の強い買いルールにはせず、2027年以降も継続検証する。**

### 12. 2026年結果と過去傾向の比較

#### 強く一致した点

1. **3～5歳中心**：1、2着が4歳。勝ち馬は直近5年全て3～5歳。
2. **牝馬の好走**：4歳牝馬サウンドモリアーナが勝利。
3. **外寄りの勝ち馬**：7枠14番が勝利。長期の「内寄りは勝ち切りにくい」と一致。
4. **馬番14**：過去10年でも勝利実績が目立つ馬番から再び勝ち馬。
5. **前走重賞組**：1～3着全馬が前走重賞。
6. **前走6～9着からの巻き返し**：サウンドモリアーナが前走6着から勝利。
7. **前～中団前の位置取り**：上位4頭が4角6番手以内。
8. **父ミッキーアイル**：2023年ナムラクレアに続いて勝利。

#### 部分的に一致した点

1. **上位人気優勢**：1・3人気が2、3着。ただし勝ち馬は5人気。
2. **高速決着**：良馬場で1:07.7。ただし過去10年で多かった「消耗戦」より2026年は後半も速い持続型。
3. **外枠有利**：勝ち馬は7枠だが、2枠3番パンジャタワーも2着。外枠は加点だが内枠消しではない。

#### 過去傾向に逆行した点

1. **9歳ウインカーネリアン3着**：高齢馬不振傾向に反する。直近G1級能力を維持している例外個体。
2. **2枠3番パンジャタワー2着**：内寄り不振傾向を基礎能力で突破。
3. **騎手データ**：武豊・三浦皇成はレース前の同レース過去成績だけなら強くなかったが1、3着。

総合的には2026年は**過去傾向との類似度が高い年**。目安として75～80%程度の一致と評価する。ただし単一項目の一致率を機械的な予想スコアにはしない。

## 8. 次回利用チェックリスト
- [ ] 枠確定前に基礎能力ランキングを作る。
- [ ] 3～5歳と6歳以上を分け、高齢馬は直近G1級能力の有無を確認。
- [ ] 前走4角10番手以内か。
- [ ] 前走の格・距離・着差・敗因を確認。
- [ ] 前走函館・札幌、または北海道芝1200m実績を確認。
- [ ] G1マイル→1200m短縮馬を確認。
- [ ] 外枠有利傾向が当日のBコースでも継続しているか実測。
- [ ] 「外有利」と「前有利」を混同せず、逃げ・番手・好位・中団前を分けて確認。
- [ ] 父・母父＋必要に応じて5代血統表を確認。
- [ ] Danzig/Mr. Prospector/Nureyev/Sadler's Wells/Roberto等の配置は実走とセットで評価。
- [ ] 馬体重・状態・休み明け・斤量変更を確認。
- [ ] 最も勝つ馬と最も買いたい馬を別々に決める。
- [ ] 中穴馬に市場との明確な乖離があれば妙味軸への昇格を検討。
- [ ] 印・3着内率・本線シナリオから自然に生じる組み合わせを一度列挙し、価値軸集中により有力シナリオが消えていないか確認。
- [ ] 購入時点のオッズ・馬場・馬体重・印・確率を固定して保存する。
- [ ] 正式ルールとレース固有仮説を混同していないか
- [ ] 未取得値を0や不該当として補完していないか
