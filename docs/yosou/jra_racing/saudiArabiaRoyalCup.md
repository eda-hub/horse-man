## 4. 過去データ・集計条件

基本窓は直近5開催（2021〜2025年）。本作業では基本窓の全頭独立再集計は未完了であり、以下は2016〜2025年の10開催を用いた補助照合として保存する。10年の反例を5年窓の反例と読み替えない。元メモの集計期間は不明。

- 基準期間は2016〜2025年の10回。2026年の結果は含めない。2026年向けの記事でも、過去結果の集計部分だけを参照した。
- ユーザーのメモには元の集計期間がないため、10年基準での照合とする。「0%」「100%」の成立には、期間・条件・対象馬一覧の指定が必要。
- 「好成績」は主に3着以内で照合。勝率・連対率が別の意味を持つ箇所は明記する。
- 本資料は公表集計の照合と、JRAの個別結果・競走馬履歴による反例確認。全出走馬の5代血統・誕生日・前走データを再構築した独自の完全再集計ではない。複合条件を単独条件の成績で認証しない。
- 少頭数の年では複勝の払戻対象が2着までの場合がある。本資料の「3着内率」は払戻上の的中率とは別。原メモの「複勝率」は変更せず、検証には3着以内という定義を用いた。
- 二次資料の一部で馬番・所属の個別表記にJRAと異なる記載が見つかった。反例の馬番、騎手、生産者、履歴はJRAを優先。二次集計を使用した項目は、その出典と検証限界を残す。


全体母集団は10開催・94頭。所属集計は関東55頭、関西38頭、その他1頭。前走のJRA成績に限定された表は地方前走などにより母数が93頭となる場合がある。各表の欠測・除外内訳の独立確認は未完了で、表間の母数を自動統一しない。

### 事前評価へ渡せる確認項目

### 現時点で裏付けのある材料

1. キャリア1戦・新馬勝ち直行。同一情報として一度だけ扱う。
2. 母父ディープインパクト。5頭という小標本を明示する。
3. 前走の上がり順位。最速をプラス材料として確認するが、最速以外を自動除外しない。
4. 前走の勝ち着差。0.3〜0.5秒差勝ちを材料にする場合も、相手レベル・ペース・馬場を確認する。
5. 新潟・東京など左回りでの実走内容。開催場名だけで能力を決めない。
6. 先行力と末脚。想定展開に照らして確認し、後方馬にも好走余地を残す。

「活用」は自動加点の確定ではなく、個別評価の確認項目として渡す意味。個人メモと既存の予想根拠が同じ特徴を指す場合も重複評価しない。

### 断定条件として採用しないもの

- NF生産・1戦・乗り替わりの100%。
- 2戦・前走指定4場の0%。
- 前走1800m以上の連対ゼロ。
- 前走右回りなら前走1番人気のみ。
- 前走4角5番手以下なら上がり最速必須。

いずれも2016〜2025年の範囲に反例がある。原メモは削除せず、検証結果を別に保持する。元の資料が直近5年など別期間であれば、元期間の事実として再確認する余地はある。

### 検証待ちの複合条件

- 道悪×欧州型ノーザンダンサー。欧州型の分類定義と全該当馬が必要。
- 5代内3血脈。各血脈の保有／非保有別の母数が必要。
- 当日4番人気以下×馬番1〜5。外の馬番との比較母数が必要。
- 追い込み×母父ディープ。追い込みの定義と全該当馬が必要。
- 前走4角4番手以内。前走脚質表で代用せず絶対順位で集計する。
- 前走左回り×上がり1位。
- 前走上がり1位×0.3〜0.5秒差勝ち。
- 当日3番人気以内×1〜2月生まれ。

これらは未確認を好成績や不成績に読み替えない。単独条件で裏付けのある特徴は個別に利用できるが、未検証の組み合わせ固有の加点は付けない。
