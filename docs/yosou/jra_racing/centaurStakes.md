## 4. 過去データ・集計条件
- **2026年の事前比較期間は2025年以前**。JRAのレース前「過去10回」分析は2016～2025年。2026年の結果を加えた2022～2026年表は次年度向けの事後集計であり、第6章の事前根拠には使用しない。
- 2022・2024年は中京、2023・2025年は阪神開催。阪神コース限定のT-008に中京開催を合算しない。旧メモのT-001～005、T-008には出走馬全体を分母にした事前集計が保存されていない。
- JRA事前分析の過去10回では1番人気が7勝、6番人気以下が3着以内に入った年は9回、国内GⅠ組の3着内率は40.0%。これらはT-006の「4歳以上」条件やT-007の海外G1・JpnIを直接検証した数字ではない。
