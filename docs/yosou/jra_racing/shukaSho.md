## 2. レース構造・適用条件

京都芝2000m内回り・右回り。改修後の2023～2025年3開催を主比較群とする。直近5開催の2021～2025年には阪神代替開催2回が入るので、一括した京都適性の根拠にしない。

| 比較群 | 年 | 用途 |
|---|---|---|
| 改修後京都 | 2023～2025 | 現行コースの主比較。3回のみの小標本 |
| 改修前京都 | 2016～2020 | 長期の補助比較。改修後と分離 |
| 阪神代替 | 2021～2022 | 別競馬場の参考。京都の枠・馬番・脚質と単純合算しない |
| 10開催全体 | 2016～2025 | 掲載統計の確認用。開催場混在を明記 |

このノートはProduction基本予想の固定後に比較するレース固有資料。過去傾向へ合わせてProduction順位・確率・印を作り直さない。資料確認の優先順位は、新たな自動加減点ではない。

### 条件の定義

- 好成績・不振はまず3着以内の率で比較し、勝率・連対率を別に示す。着別度数は1着-2着-3着-着外、分母は実出走単位。
- 非サンデーサイレンス系は父系の分類。エピファネイアの母父サンデーサイレンスなど、母系に含むことまで否定する条件ではない。
- 母父キングカメハメハは母父そのもの。「母父キングカメハメハ系」へ無断で広げない。
- 米国系のスピード要素は出生国と同義にしない。母父の系統、現役時の距離・芝ダート実績、産駒の距離実績を分けて記録。分類基準が未確定の間は判定保留。
- 馬番奇数／偶数で集計し、枠番の奇偶と混同しない。
- 「前走4角5番以下」は5番手以下（順位数値5以上）として記録。4番手以内は順位数値4以下。通過順位欠測や非該当は0へ置換しない。
- キャリアは秋華賞前の実出走数。取消・除外を含めず、今回の秋華賞を足さない。
- 前走1or2番人気は前走確定単勝人気が1・2。前走着順1・2着とは別。
- 当日5番人気以内は今回単勝人気1～5。マイナス馬体重は前回計量比で減少。前日・想定人気や調教後馬体重で代用しない。
- 事前の人気判定は取得時刻付き暫定値。最終人気や当該レースの確定脚質を事前に知っていたものとして使わない。

## 4. 過去データ・集計条件

### 範囲・欠測・取得方法

根拠の上限は2025年。取得日2026-10-16。2026年公開ページも2016～2025年の過去成績欄のみ使用し、当年出走馬の推奨を根拠にしない。

S-002の年度別全馬表を読み、数値着順・数値人気の実出走行から馬番奇偶を再集計。改修後51出走、旧京都88出走、阪神32出走、合計171出走。2019年表には数値着順のない行があり、実出走集計から除外。欠測を着外に追加しない。全出走の血統・前走・キャリア・体重を原票から独立復元したものではない。

S-001・S-004の掲載集計は開催場混在、京都のみ等の対象をそのまま明示。母父・キャリア・馬体重等の交差集計の欠測は未取得として保持する。
