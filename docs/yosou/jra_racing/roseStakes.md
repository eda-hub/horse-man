## 5. 回顧

### 5.1 良かった点 — 馬の抽出精度は高かった

最終印の中に1～3着馬をすべて含めた。

- ◎⑦モンローウォーク → 1着
- △②エンネ → 2着
- ▲⑥イクシード → 3着

特に◎⑦は1番人気ながら、2番手から34.1秒でまとめ、3馬身差で完勝。軸馬選定そのものは正しかった。

⑥も最後方近くから34.1秒で3着まで追い上げており、▲として能力上位に残した判断は妥当だった。

**判定：能力上位馬の抽出・◎選定は保護する。**

### 5.2 最大の問題 — 予想順位と購入構造が接続していない

結果だけを見て「②を買うべきだった」と事後的に結論づけることはしない。

ただし、結果前の最終印として②を△に残していた一方、実購入2,900円は次のように集中していた。

- ⑦－⑩へ2,300円（総購入額の79.3%）
- ⑥－⑦へ600円
- ⑦－②は0円

つまり、◎⑦を中心とした印内の組み合わせのうち、○⑩との組み合わせへ大きく依存し、△②を含む自然な組み合わせが実購入から完全に消えていた。

`50_review.md` で既に正式化されている「自然な組み合わせ監査」「万能軸・馬依存監査」「良好部分保全」の観点では、**予想そのものより購入構築を重点検証すべき事例**である。

ただし、発走前の推定確率・組み合わせ別期待値・購入時オッズが保存されていないため、⑦－②を実際に買うべき期待値があったと結果後に断定しない。今回確定できる問題は、**なぜ候補から外したかを後から監査できない記録不足と、印から購入候補への変換根拠が残っていないこと**である。

### 5.3 ○⑩スウィートハピネスの評価

⑩は中団後方8番手から進み、上がり34.8秒で7着。勝ち馬⑦との差は1.1秒だった。

○として⑦－⑩へ79.3%を集中した結果に対しては、次回以降、

- ○にした独立根拠
- ◎との同時好走シナリオ
- ○が崩れた場合の代替シナリオ
- ○依存率を正当化する推定好走確率

を購入前に明示する必要がある。

今回の保存情報だけでは○評価そのものの原因分析に必要な事前根拠が不足するため、**○⑩を7着という結果だけで降格ロジックへ変換しない。**

### 5.4 △②エンネの扱い

②は3番人気5.9倍で2着。4番手から正攻法で伸び、勝ち馬には離されたが秋華賞優先出走権を確保した。

結果論としては⑦－②の馬連550円、ワイド280円が成立したが、重要なのは払戻そのものではない。

**最終印に残した有力馬が買い目候補生成段階で消える場合、消した理由を発走前に保存する**ことが必要である。これにより、合理的な期待値除外だったのか、単なる候補生成漏れだったのかを回顧で分離できる。

### 5.5 ▲⑥イクシードと券種選択

⑥は3着だったため、馬連⑥－⑦は不的中。一方、同じ組み合わせのワイドは260円だった。

これも「結果を見ればワイドにすべきだった」という意味ではない。

ただし、⑥を▲として高く評価しながら馬連だけを600円購入したため、購入前には少なくとも、

- ⑥の2着以内確率
- ⑥の3着以内確率
- 馬連⑥－⑦とワイド⑥－⑦の価格差

を独立評価し、馬連を選ぶ理由を保存する必要がある。

`30_betting.md` / `50_review.md` の「買い目期待値独立評価」に沿い、券種間の比較根拠を残すことを改善点とする。

## 7. 改善判断

### 7.1 共通予想ロジックは変更しない

今回、◎⑦・△②・▲⑥で1～3着を捕捉できているため、能力評価の基本骨格を変更する根拠はない。

また、単発結果を理由に○⑩の評価条件や△②の評価条件を新規ルール化しない。

### 7.2 既存の購入監査ルールを適用対象として再確認する

今回の問題は、`50_review.md` で既に正式化済みの次の監査対象と一致する。

1. 自然な組み合わせ監査
2. 万能軸・馬依存監査
3. 買い目期待値独立評価
4. 良好部分保全 / 非劣化ガード

したがって同目的の新ルールを追加せず、既存ルールの適用証跡を次回から確実に残す。

### 7.3 今回実施する改善

本レースを第2検証サイクルの正式KPIへ後付け算入しないことを `docs/validation/records/2026-09-13.md` に明記する。

今後の同型ケースでは、結果前の重賞記録に最低限、次を保存する。

- `baseline_forecast_id`
- 最終印・順位・推定確率
- 印内から生成した自然な馬連・ワイド候補
- 候補を買わない場合の除外理由（価格 / 相関 / 資金 / 確率）
- 組み合わせ別・券種別の期待値比較
- 1頭・1シナリオへの資金依存率と正当化
- 実購入

これにより「予想で拾えていたのに馬券で落とした」のか、「期待値上合理的に買わなかっただけ」なのかを事後に判別可能にする。
