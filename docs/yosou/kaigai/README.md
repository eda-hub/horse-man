# 海外重賞 年次予想ノート運用

共通境界は `docs/yosou/README.md` をOwnerとする。本ディレクトリは海外重賞固有の補足だけを定義する。

## 海外重賞で追加して残す情報

- 開催地・コース改修・代替開催など、過去傾向の転用性を変える構造差
- 現地主催者・公式情報と海外専門媒体によるレース固有傾向
- 購入市場がJRAか現地市場かという前提差
- 翌年も確認すべき現地ローテ、馬場、コース適性等

## 回顧時

正式なProduction / Shadow回顧、KPI、エラー分類、実購入収支は `docs/validation/` に保存する。

`docs/yosou/kaigai/<race>.md` へは、

- 過去傾向から見て当年予想がどうだったか
- どの傾向が継続 / 弱化 / 新規候補 / 例外となったか
- 翌年に向けたレース固有の予想課題

だけを抽出して更新する。

海外重賞で過去の開催条件と現在のコース構造が異なる場合は、古い傾向を同一母集団として機械的に扱わない。
