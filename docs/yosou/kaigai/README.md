# 海外重賞 `docs/yosou/kaigai/` 記録運用

海外重賞の `docs/yosou/kaigai/` は、**レース固有の年次予想ノート**を保存する場所とする。

## 保存するもの

- 当該レースの過去傾向・コース特性・開催条件の変化
- 当年予想の要約
- 過去傾向・事前仮説と当年予想/結果の照合
- 翌年へ持ち越すレース固有の予想課題
- 翌年予想時のチェックリスト
- 傾向更新に必要な結果要約と参照資料

## 保存しないもの

次は `docs/validation/` を正本とし、`docs/yosou/kaigai/` へ重複保存しない。

- Production / Shadow の正式な発走前snapshot
- KPI適格性・集計値
- エラー分類
- 反実仮想チェック
- 非劣化判定
- 検証中ルールの改善 / 中立 / 悪化判定
- 実購入の詳細、払戻、収支、回収率
- 改善候補の昇格 / 継続検証 / 棄却判断

## 境界

`docs/yosou/kaigai/` で行う「当年予想と過去傾向の照合」は、**翌年の同一レースを予想するためのレース固有知識の更新**である。

`docs/validation/` で行う「回顧・検証」は、**汎用予想ルール、Production / Shadow、購入戦略、KPIの性能評価**である。

同じ内容を両方へ複製せず、レース固有の知識は `yosou/kaigai`、汎用ルールの評価は `validation` に分離する。
