# 競馬予想ルール原本

- **バージョン**: v1.5.5-HF1
- **最終更新日**: 2026-09-12
- **用途**: 中央競馬・海外競馬を含むレース予想の共通ルール原本
- **基本方針**: レース予想と馬券戦略を分離し、まずレースそのものを正しく予測する
- **運用**: v1.5.5の予想生成骨格・正式購入監査・非劣化ガードを保護したまま、2026-09-12の運用点検で確認した重大な境界矛盾だけを緊急修正したHF1。修正対象は、Production（正式予想）とShadow（比較予想）の分離、重賞詳細分析51の役割分割、E-11/E-12比較買い目の正式購入からの遮断、確率変更統制に限定する。能力評価・近走評価・展開分析・適性評価・①/②分類等の既存予想骨格は変更しない。2026-09-12・13・19・20の第2検証サイクルは継続し、基準予想とShadow比較を前向きに保存する
- **用語方針**: 本文は日本語表記を優先し、英字略称は原則使用しない。E-09等の検証番号、WIN5等の固有名詞だけを識別用に残す。

# まず読む用語

- **基本予想**：現在の正式ルールだけで作る予想。検証中の新しい仮説は混ぜない。
- **条件別補正**：重賞、若駒、当日馬場など、該当条件のときだけ追加する分析。
- **検証中ルール**：まだ正式採用していない新しい仮説。結果を比較して採用可否を判断する。
- **基準予想**：実際の正式な予想として保存する側。
- **比較予想**：検証中ルールを試した場合にどう変わるかを見る比較用の予想。
- **予想確信度**：オッズとは切り離した「予想そのものへの自信」。A+〜C-で表す。
- **購入確信度**：オッズ、買い目期待値、資金配分まで含めた「その馬券を買う自信」。A+〜C-で表す。
- **購入優先度**：開催全体の中で、どのレースを優先して最終検討するか。S〜Dで表す。
- **買い目期待値**：その買い目の的中確率とオッズを組み合わせた、価格面の期待度。
- **自然な組み合わせ監査**：印に入っている有力馬同士の自然な馬連・ワイド・三連系を、価格で削る前に一度すべて候補化する確認。
- **万能軸監査**：全買い目が1頭に依存しすぎていないかを確認する。
- **Production（正式系）**：正式な基準予想・基準確率・正式推奨買い目を作る系統。領域Aの正式ルールと領域Bの監査だけが決定権を持つ。
- **Shadow（比較系）**：検証中ルールを試す独立系統。基準予想をコピーして差分を作るが、Productionを上書きしない。
- **51A 重賞情報拡張**：重賞で馬自身の事実データを深く収集し、既存の正式ルールへ渡す情報収集プロトコル。独自の重賞傾向加点は行わない。
- **51B 重賞傾向Shadow**：過去傾向・年齢・ローテ集計・枠傾向・血統集計等の重賞固有モデルを比較用に適用するShadow分析。

# 0. ルール運用の全体構造

## 0.0 本ファイル添付時の自動実行契約

本ファイルは、単なる参考資料ではなく、**競馬予想・回顧・検証を実行するための自己完結型の運用仕様**として扱う。

本ファイルが会話に添付され、ユーザーが競馬予想・最終予想・WIN5・回顧・検証などを依頼した場合、ユーザーから詳細な手順指定がなくても、以下の規約を自動適用する。

### 0.0.0 HF1変更保護宣言 / Production-Shadow完全分離

本HF1は、**中身を変えるのではなく境界を直す緊急修正**である。

#### 保護対象

次の既存骨格は変更しない。

- 事実 → 解釈 → 予測の分離
- 基礎能力と今回発揮能力の分離
- 近走内容・相手レベル・成長・適性の評価
- レース質を先に作り、複数シナリオで考える構造
- 騎手・厩舎・血統を補助適性として扱う原則
- 最も勝つと思う馬 / 最も買いたい馬の分離
- ①期待値型 / ②少額高配当型 / ①＋② / 見送り
- 最終順位保全・確信度保全
- 自然な組み合わせ監査・万能軸監査
- 券種・組み合わせごとの買い目期待値独立評価
- モード7のユーザー指定条件内最適化

#### 決定権の原則

正式な基準予想・基準確率・正式推奨買い目へ直接影響できるのは、**領域Aの正式予想生成 / 正式条件別補正と、領域Bの監査による原因要素への差し戻し**だけとする。

領域C2の検証中ルール、51B、E-09、E-10、E-11、E-12等はShadow系であり、**基準順位・基準確率・正式推奨買い目を上書きしてはならない。**

ただしE-03 / E-08は価格観測・価格予測の共通入力としてProductionとShadowの双方で利用してよい。これらは能力順位・印・勝率を変更せず、価格判断・購入確信度・買い条件だけに作用する。

本文中の「成熟度：検証中」は、それだけでProduction使用禁止を意味しない。**参照権限は本0.0.0と0.0.6の論理領域を優先して決める。** 領域Aに明示的に残された既存ルールは第2サイクル中も保護し、今回のHF1を理由に無効化しない。

#### 逆流禁止

処理順序は、

**Production基準予想固定 → Shadow比較予想固定 → Production基準買い目固定 → Shadow比較買い目固定 → 発走 → 結果比較**

とする。

Shadowで良い案が見つかっても、同レースのProductionへ逆流させない。ユーザーが明示的にShadow案を選択した場合のみ実購入へ採用できるが、その場合も「正式推奨」と「ユーザー選択による実購入」を分離して保存する。

#### 同一レースの基準予想一意性

同一日・同一レースについて、同一バージョンで既に発走前の基準予想が固定されている場合、別チャット・別モードでもその基準予想を再利用する。

新しい非価格情報がないのに別チャットで基準予想をゼロから再生成しない。変更する場合は37.1 / 37.2に従い、変更前後・理由・証拠強度・情報時刻を保存する。

ユーザーの指示が短くても、本ファイルに定義された必須工程を省略してよいとは解釈しない。

例：

- 「札幌11R」
- 「中京7Rお願いします」
- 「最終予想」
- 「今日の全レース」
- 「WIN5」
- 「このレースを回顧」

のような短い依頼でも、対象が特定できる場合は、本ファイル内の該当モード・標準フロー・必須出力を自動的に展開して実行する。

ユーザーが明示的に「簡潔に」「買い目だけ」「確率だけ」など出力範囲を限定した場合のみ、表示量を縮小してよい。ただし内部の基準予想生成・必要条件別補正・監査まで省略したものとして扱わない。

### 0.0.2 実行モードを自動判定する

依頼内容から次のモードを自動判定する。

#### モード1：単一レース・基準予想

以下のように特定の1レースが指定された場合に使用する。

- 日付＋競馬場＋R
- 競馬場＋R
- レース名
- 会話文脈から対象が一意に確定する「このレース」「最終予想」等

実行順序は原則、

**情報取得 → 領域A 基準予想 → 必要な正式条件別補正 → 領域B 監査 → （検証サイクルではモード5比較用予想固定） → 市場比較 → 買い目 → （比較用買い目固定） → 検証記録用サマリー**

とする。

**領域Cの比較用予想を基準予想へ混入させない。** ただし正式検証サイクル中は、0.0.2のモード5自動実行条件に従い、ユーザーの明示がなくても基準予想固定後に比較予想を別系統で自動作成・保存する。

#### モード2：開催全体の選別

以下の依頼で使用する。

- 「今日の全レース」
- 「本日の中央競馬」
- 「買いレース候補」
- 「開催全体を見て」

開催全体を全体選別し、既存ルールに従って、

- ①期待値型
- ②少額高配当型
- ①＋②
- 見送り

へ分類し、買い候補を**購入優先度（S / A / B / C / D）**付きで提示する。

午前中は当日情報を無理に補完せず午前モード、十分な実測サンプルが蓄積した場合のみ午後当日実測補正モードを使用する。

#### モード3：WIN5

「WIN5」の予想・買い目・検証を依頼された場合に使用する。

通常の各対象レース予想を先に作り、その後にWIN5補正を適用する。通常馬券の妙味順位をそのままWIN5候補へ流用しない。

WIN5補正は使用範囲としては正式条件別補正だが成熟度は検証中ルールであるため、結果は継続検証対象として記録する。

#### モード4：回顧・検証

結果確定後に、

- 「回顧」
- 「振り返り」
- 「検証」
- 「反省と改善」

等を依頼された場合に使用する。

発走前に保存された予想を基準とし、結果を知った後の情報を事前判断へ逆輸入しない。

基本予想 / 条件別補正 / 検証中ルール / 価格判断 / 買い目構造 / 資金配分を分離して採点する。

新しい改善案は原則として領域Cへ検証候補として記録し、基準予想を直接変更しない。

#### モード5：基準予想と比較予想の比較

基準予想を基準に検証中ルールの差分価値を検証するモード。

通常時は、ユーザーが、

- 「検証中ルールも試して」
- 「比較予想と比較して」
- 「E-03を適用して比較」

等と明示した場合に使用する。

ただし、**正式な検証サイクルではユーザーの明示依頼を待たず自動実行する。**

第2検証サイクル（2026-09-12・13・19・20）では、次をモード5自動実行対象とする。

- モード1で最終予想を作成する全レース
- モード2で購入候補へ昇格したレース（① / ② / ①＋②）
- 全重賞（重賞詳細分析対象）
- ユーザーが個別に最終予想・買い目を求めたレース

開催全体の選別で「見送り」としたレースは、詳細な比較予想計算を必須としない。ただし、**結果確認前に「見送り／比較予想の詳細比較省略」または該当検証中ルールの有無を記録**し、結果後に都合よく比較予想を再構成しない。

自動モード5では必ず、

1. **先に基準予想・確率・印・予想確信度を完成して保存・固定する**
2. 重賞では51B、その他はE-09 / E-10 / E-04 / E-07等、そのレースに該当するShadow比較予想を適用する
3. 比較予想側では順位・確率を実際に動かしてよいが、基準予想は変更しない
4. 基準予想→比較予想で「何が、なぜ、どの程度動いたか」を結果確認前に保存する
5. Production基準買い目を先に固定した後、E-11 / E-12等のShadow比較買い目を別途生成し、基準買い目と**同一オッズ時点**で評価して各購入確信度を並行保存する。比較結果で正式推奨を差し替えない
6. **基準予想と比較予想の双方を発走前に固定する**
7. 結果後に改善・中立・悪化、確率校正、買い目・回収率を比較する

の順を守る。

**比較予想によって基準予想を上書きしない。** モード5の目的は、その場で正式予想を変更することではなく、次回サイクル終了審査に使える前向き比較データを自動的に蓄積することである。

ユーザーが「今回は比較予想との比較不要」と明示した場合のみ、そのレースの自動モード5を省略してよい。

#### モード6：サイクル終了審査

2週間・最大約144Rの検証サイクル終了時に使用する。

予想精度、確率確率精度の検証、①②別成績、午前午後差、当日実測補正、価格判断、馬券構造、検証中ルール成績を集計し、

- 据え置き
- 継続検証
- 統合
- 昇格候補
- 降格・棄却

を審査する。

サイクル終了を理由に基準予想を必ず改訂しない。


#### モード7：ユーザー選択後の購入最適化

事前予想または最終予想を提示した後、ユーザーが、

- 買いたい馬
- 使用したい券種
- 予算

の全部または一部を指定した場合に使用する。

例：

> ①④⑤を使って、馬連・ワイド・三連複を3,000円買いたい

この場合、最初の予想を作り直すのではなく、**保存済みの基準最終予想・確率・市場評価を固定したまま、ユーザーが指定した購入条件の範囲内で最終買い目を最適化する。**

原則として、

1. 保存済みの最終印・勝率・連対率・3着内率を固定する
2. ユーザーが選んだ馬を「購入対象馬」として抽出する
3. ユーザーが指定した券種だけを「許可券種」とする
4. 最新の取得可能オッズを確認する
5. 購入対象馬 × 許可券種から成立する買い目候補を列挙する
6. 各候補を、予想確率・同時好走確率・価格・相関・本線シナリオとの整合性から比較する
7. 低い期待値・重複性の高い買い目は、ユーザーが指定した券種であっても機械的には採用しない
8. 採用買い目へ予算を100円単位を基本として配分する
9. 最終買い目、金額、役割、本線／押さえ／高配当の区分を提示する

とする。

ユーザーが選択していない馬や券種を、正式な最終買い目へ勝手に追加しない。追加すると明確に改善余地がある場合は、**指定条件内の最適案とは分離して「参考代替案」**として提示する。

「予算3,000円」のような表現は原則として上限予算として扱う。ただし「3,000円分買う」「3,000円使い切る」等、総額使用の意思が明確な場合は指定総額へ合わせる。

ユーザーが選んだ馬の中に基準予想上位馬が含まれていなくても、価格だけを理由に基準予想を変更したり、選択外の上位馬を強制的に買い目へ戻したりしない。予想と購入意思決定を分離する。

### 0.0.2.1 重賞の自動判定と重賞詳細分析起動

対象レースがJRAのGⅠ・GⅡ・GⅢ、または海外のグループ／グレード競走等の**重賞**であると判定できる場合、ユーザーから追加指示がなくても51を自動起動する。

HF1以降、51は次の2系統へ分離する。

- **51A 重賞情報拡張（Production側）**：馬自身の前走内容、同条件実走、5代血統、枠×脚質、騎手、厩舎、当日一次情報等を深く収集する。得た事実は既存の正式ルール1〜37等へ渡して評価する。51A自身は独立した加点表・順位補正を持たない。
- **51B 重賞傾向Shadow（Shadow側）**：過去レース集計、年齢・性別傾向、前走ローテ集計、枠順集計、血統集計、人気構造等の重賞固有傾向を比較用に適用する。51Bは基準順位・基準確率・正式推奨買い目を変更しない。

重賞では必ず、

**基本予想 → 51Aで事実拡張 → 正式条件別補正 → 基準予想固定 → 51B Shadow比較**

の順を守る。

「前走同コース勝ち」のような**当該馬自身の直接証拠**は51Aから既存正式ルールへ渡してProductionで評価できる。一方、「過去10年で3歳馬が強い」のような**集団傾向**は51BとしてShadowだけで評価する。

ユーザーが「通常予想だけ」「重賞詳細分析不要」等と明示した場合は51A / 51Bとも省略できる。

### 0.0.3 対象レースの自動解決

ユーザーが対象を完全には書いていなくても、現在の会話・日付・直前の発言から対象レースを一意に解決できる場合は、再質問せずその対象で実行する。

また、以下のように外部から確認できる情報は、原則としてユーザーへ入力を求めず取得を試みる。

- 発走時刻
- 出馬表・馬柱
- 枠順
- 騎手
- 斤量
- 取消・除外・騎手変更
- 馬体重
- 天候・馬場状態
- オッズ
- 同日同競馬場の既終了レース
- 確定結果・払戻

情報源は可能な限りJRA等の主催者公式・一次情報を優先する。

ただし、ユーザーの予算、購入済み馬券、独自の資金上限など、外部取得できない意思決定情報は推測しない。

予算指定がない場合は、具体的な総額を勝手に仮定せず、原則として**買い目の優先順位または資金配分比率**で提示する。

### 0.0.4 ファイルだけが添付され、対象依頼がない場合

本ファイルだけが添付され、予想対象・回顧対象・作業目的を会話から一意に特定できない場合は、勝手に当日の全レース予想を開始しない。

この場合のみ、必要最小限として**対象レースまたは作業目的**を確認する。

ただし、同一メッセージまたは直前文脈から対象が明確なら確認を挟まず実行する。

### 0.0.5 情報時点を自動判定する

現在時刻と発走時刻から、原則として次を自動判断する。

- 発走前・当日サンプル不足 → 午前／事前モード
- 発走前・関連レースの実測情報が十分 → 午後当日実測補正候補
- 発走直前 → 最終予想として最新の取得可能情報を確認
- 発走後・結果未確定 → 確定前情報と推測を区別
- 結果確定後 → 回顧モード

結果確定後に事前予想を依頼された場合は、結果を混ぜた疑似的な事前予想を正式な前向き検証データとして扱わない。

### 0.0.6 1ファイル内の論理領域と参照権限

本ファイルは物理的には1ファイルで運用するが、内容を以下の4つの論理領域に分離して扱う。

#### 領域A：基準予想

正式な予想生成に使用する基準領域。

対象：

- 本文の基本予想生成ルール
- 0.13で基本予想と定義された項目
- 0.13で条件別補正と定義された既存条件別補正
- 標準予想フロー
- 単一レースモード
- 開催全体の選別
- WIN5依頼時の既存WIN5補正
- 重賞指定時に自動起動する**51A 重賞情報拡張**。51Aで得た馬自身の事実は既存正式ルールへ渡すが、重賞固有の集団傾向は51Bへ分離する

通常の正式予想では必ず領域Aを基準とする。

#### 領域B：監査

基準予想の矛盾・暴走・二重計上・過度な資金集中を検出する監査領域。

対象：

- 0.2「予想生成と監査の分離」
- 0.13の基本監査
- 二重計上
- 印と確率順位の整合性
- 不確実性レンジ
- 情報時刻整合
- 馬依存率・シナリオ依存率
- 反実仮想
- 非劣化確認に関する運用規約

領域Bは通常予想でも使用するが、**独立した加点・減点材料として能力順位を動かさない。**

問題を検出した場合のみ、原因となる領域Aの評価要素へ戻って修正する。

#### 領域C：比較予想・検証中ルール

新しい仮説・馬券構築方法・価格再走査などの検証領域。

対象：

- 「検証中ルール追加記録」のうち未昇格項目
- **51B / E-04 / E-07 / E-09 / E-10 / E-11 / E-12**および次サイクルの比較予想候補。E-03 / E-08は0.0.0の共通価格入力特例に従う
- 検証課題一覧のうち新しい予想・馬券仮説

E-01・E-02・E-05はv1.5.0で正式ルールへ昇格し、E-06は基本運用規約として確立したため、通常の領域C 比較予想としては扱わない。旧節は検証履歴として残す。

通常のモード1・モード2の正式予想では、**領域Cを基準予想生成・基準確率・基準印へ直接反映しない。**

モード5では、基準予想固定後に指定または検証計画で自動指定された検証中ルールだけを比較予想へ差分適用する。第2検証サイクルでは0.0.2のモード5自動実行条件を満たすレースについて、ユーザーの明示依頼なしでE-09 / E-10等の該当比較予想を発走前に保存する。

#### 領域D：検証記録

過去の個別レース結果、ケーススタディ、検証サマリー、検証中ルールの実績を保存する記録領域。

対象：

- 2026-08-29等の具体的な検証記録
- レース固有の成功・失敗例
- 検証中ルール適用結果
- サイクル集計
- 更新履歴

領域Dは、モード4・モード5の結果比較・モード6の集計では参照してよい。

一方、通常の事前予想では、**過去ケースの結果をそのまま新レースの能力評価・印・確率形成の根拠として使用しない。**

必要な一般化がある場合は、領域Cの仮説として明示的に検証する。

### 0.0.7 検証中ルール内の役割分離

領域C内でも、次の2種類を区別する。

#### C1：検証プロトコル

予想内容そのものを変更せず、検証の質を高める仕組み。

v1.5.0では良好部分保全 / 非劣化ガードと基準予想 / 比較予想方式は正式運用規約へ昇格した。

今後C1には、予想内容そのものを変更せず検証品質だけを改善する新しいプロトコル候補を置く。正式運用規約は領域Bおよび0.16.1等に従って常時使用する。

#### C2：予想・馬券比較予想

基準予想とは異なる判断・買い方を試す新仮説。

代表例：

- 最終価格再確認
- 位置取り主導権補助評価
- 高確信度活用
- 最終オッズ予測（実戦検証中ルールとして別途自動適用特例あり）
- その他の条件付き着順・買い目構造の新仮説

C2はモード5または検証計画で指定された場合のみ適用する。

### 0.0.8 通常予想での検証中ルール遮断

通常の正式予想を依頼された場合、以下をデフォルトとする。

> **Productionは領域Aで基準予想を作成し、領域Bで監査する。Shadow系の領域C2は基準順位・基準確率・正式推奨買い目へ逆流させない。領域Dの過去結果は予想生成へ使用しない。**

第2サイクルの扱いは次のとおり。

- **E-03 / E-08**：価格観測・価格予測の共通入力。能力順位・印・勝率へ逆流させず、Productionの価格判断・購入確信度・買い条件に利用できる。
- **51B / E-09 / E-10 / E-04 / E-07**：Shadow比較予想だけを作成する。基準予想を変更しない。
- **E-11 / E-12**：Production基準買い目固定後にShadow比較買い目だけを生成する。比較結果を見て正式推奨を差し替えない。

ユーザーがShadow案を明示的に選択した場合は実購入へ採用できる。その場合も、

- Production正式推奨
- Shadow比較案
- ユーザー選択による実購入

を別々に保存する。

この原則は、本文下位節に「比較して最終決定」「検証中ルール補正」等の旧表現が残る場合より優先する。HF1では該当主要箇所を同時に正規化する。

### 0.0.9 回顧時の参照範囲

回顧・検証時は領域A〜Dを参照してよい。

ただし、

- 基準予想が当時どう判断していたか
- 比較予想なら何が変わったか
- 結果を知った後だけ成立する説明ではないか

を明確に分ける。

回顧結果から領域Aを直接書き換えず、サイクル中は領域Cまたは領域Dへ保存する。

### 0.0.10 自動実行時の最低出力保証

ユーザーから特別な省略指定がない場合、単一レースの正式予想は原則として0.18の標準出力を自動実行する。

開催全体では49-9、WIN5では50およびWIN5標準フロー、回顧では40〜43と標準予想フローEを基準にする。

「最終予想お願いします」など短い依頼であっても、短い依頼であることだけを理由に、

- 基本予想順位
- 3大要因
- 必要条件別補正
- 確率
- 予想確信度
- 購入確信度（市場未取得時は未判定）
- 購入優先度（開催全体モード時）
- 市場比較
- 最も勝つ馬 / 最も買いたい馬
- 買い条件
- 買い目
- 依存率監査
- 情報基準時刻

を無断で省略しない。

### 0.0.11 本自動実行契約の優先順位

実行時の優先順位は、原則として次のとおりとする。

1. ユーザーがその依頼で明示した指示
2. 本0.0「自動実行契約」
3. 領域A 基準予想 / 正式条件別補正
4. 領域B 監査
5. 領域C 検証中ルール
6. 領域D 検証記録

ただし、ユーザーが単に短く依頼したことは「本ファイルの必須工程を省略せよ」という明示指示とは扱わない。

本0.0は**予想ロジックを変更するルールではなく、本ファイルを一貫して実行するための運用契約**である。

本原本は、予想精度を高めるためにルールを無制限に増やすのではなく、**重要な判断を鋭く保ちながら、必要な場面だけ追加情報を使う**ことを目的として、以下の3層で運用する。

## 0.1 基本予想 / 条件別補正 / 検証中ルール の3層構造

### 基本予想 — 全レースで使う固定基盤

基本予想は、原則として全レースで必ず使う予想の骨格である。

主な内容は、

- 事実 → 解釈 → 予測の分離
- 基礎能力と今回発揮能力の分離
- 近走内容・相手レベル・現在地
- 今回要求される能力
- レース質・ペース・位置取り
- 複数シナリオ
- 勝率・連対率・3着内率
- 市場オッズとの比較
- レース予想と馬券戦略の分離
- 回顧時の予想・価格判断・馬券結果の分離

とする。

基本予想の役割は**予想を作ること**であり、毎回の失敗をすべて防ぐことではない。

### 条件別補正 — 条件に該当するときだけ使う補助層

条件別補正は全レースで機械的に適用しない。

代表例：

- **若駒・操縦性条件別補正**：2歳馬、キャリア浅い馬、初回り・初コースなど
- **昇級・未知条件別補正**：クラスアップ、初距離、初条件など
- **当日馬場補正**：当日の複数レースから有効な馬場・位置取り情報が得られた場合
- **情報品質条件別補正**：情報の鮮度・信頼度・時刻整合性に問題がある場合
- **高配当条件別補正**：②少額高配当型、穴軸・妙味軸を検討する場合
- **WIN5補正**：WIN5を購入・検討する場合
- **51A 重賞情報拡張**：GⅠ・GⅡ・GⅢ等の重賞で、当該馬の5代血統・前走・同条件実走・枠×脚質・騎手・厩舎・当日データを深掘りし、既存正式ルールへ事実を供給する。重賞固有の集団傾向は51B Shadowへ分離する

該当しない条件別補正は読み飛ばしてよい。

### 検証中ルール — 新しい仮説の検証層

個別レースの回顧から得た新しい改善は、原則として直ちに基本予想へ追加しない。

まず検証中ルールとして、

- 仮説
- 適用条件
- 期待する改善
- 予想をどう変更したか
- 実戦結果
- 反証例

を記録する。

検証中ルールは**予想を作る中心材料ではなく、基本予想に対する限定的な補正候補**として扱う。

---

## 0.2 「予想生成」と「監査」を分離する

ルール肥大化による予想のフラット化を防ぐため、ルールを次の2種類に分ける。

### 予想生成ルール

馬の能力順位・確率を実際に作る材料。

例：

- 近走内容
- 相手レベル
- 今回要求能力
- 距離・コース適性
- 展開適合
- 成長・状態
- 騎手・厩舎・血統による今回条件への適合補正（単純なブランド加点は禁止）

### 監査ルール

予想が暴走・矛盾していないか確認する材料。

例：

- 二重計上チェック
- 情報の証拠強度
- 不確実性レンジ
- 印と確率順位の整合性
- 馬依存率・シナリオ依存率
- 反実仮想チェック

**監査ルールを独立した加点・減点項目として扱わない。**

監査で問題が発見された場合のみ、原因となる予想生成要素へ戻って修正する。

これにより、確認項目が増えるほど全馬の確率が中央へ寄ることを防ぐ。

---

## 0.3 各レースで「予想を決めた3大要因」を先に固定する

最終評価前に、そのレースの予想を最も左右する要因を**原則3つまで**明示する。

例：

1. 現級での基礎能力
2. 今回の高速巡航適性
3. 好位を取れる確率

3大要因は単なる要約ではなく、**上位馬と中位馬を分ける主要因**とする。

その他の材料は、原則としてこの3大要因を補強・反証するために利用する。

重要度の低い多数の材料を均等に加点し、評価差が消えることを避ける。

ただし、重大な状態情報・取消・馬場急変などがあれば3大要因を更新してよい。その場合は変更理由を記録する。

---

## 0.4 基本予想を先に保存し、ProductionとShadowを分岐する

各レースでは、次の6段階を分けて記録する。

### A. 基本予想

当日バイアス・Shadow仮説を入れる前の基礎予想。

記録するもの：

- 上位評価
- 勝率・連対率・3着内率
- 予想確信度
- 予想を決めた3大要因

### B. 正式条件別補正

領域Aに属する正式条件別補正だけを適用し、基本予想から何を変更したか記録する。

例：

> 基本予想勝率24% → 公式当日馬場の強い補正 +2pt → Production基準26%

51Aは情報収集を深くする工程であり、51Aという名前だけで独立加点しない。

### C. Production基準最終予想固定

Bまでの印・確率・予想確信度を正式な基準予想として保存・固定する。

**ここから先のShadow分析はCを上書きしない。**

### D. Shadow比較予想

51B / E-09 / E-10 / E-04 / E-07等、該当する検証中ルールをCのコピーへ差分適用する。

例：

> Production勝率26% → 51B Shadow +1pt → Shadow勝率27%

この27%をProductionの26%へ戻してはならない。

### E. Production基準買い目固定

市場価格と比較し、35.1・45・48・49等の正式購入ルールでProductionの正式推奨買い目を作成・固定する。E-03 / E-08は価格共通入力として使用できる。

### F. Shadow比較買い目

E-11 / E-12等を使って比較買い目を別途生成し、Eと同一オッズ時点で保存する。Shadow案の方が良く見えても、Production正式推奨へ差し替えない。

結果後にA〜Fを分離して比較することで、

- 基本予想だけの方が良かったか
- 正式条件別補正が精度を上げたか
- Shadow予想が改善 / 中立 / 悪化だったか
- Production買い目とShadow買い目のどちらが優れていたか

を前向きに検証する。

---

## 0.5 午前モードと午後モードを分ける

当日情報の有無によって、予想の重心を変える。

### 午前・当日サンプル不足モード

当日の同条件サンプルが不足している段階では、

**基礎能力 × 近走内容 × 相手レベル × コース適性 × 想定展開**

を中心に基本予想を作る。

当日馬場については、公式馬場状態・天候など確認可能な事実だけを使い、少数レースの結果から強いバイアス補正を行わない。

当日バイアスの信頼度は原則「弱」から開始する。

### 午後・当日実測補正モード

複数の関連レースから、

- 実測時計
- 位置取り
- 4角位置
- 内外
- 上がり
- ペース

に一貫した傾向が確認できた場合のみ当日馬場補正を有効化する。

当日情報は**基本予想を作り直す材料ではなく、原則として基本予想への差分補正**として扱う。

弱い当日情報は、まずシナリオ確率・不確実性レンジ・資金配分を小さく動かす。

---

## 0.6 当日補正の有効性を独立採点する

レース後は最終予想だけでなく、

- 基本予想の順位・確率
- 当日実測補正後の順位・確率
- 最終結果

を比較する。

当日補正について、

- 改善
- ほぼ中立
- 悪化

を記録する。

一定数のレースで、当日補正が本当に精度を上げているかを検証する。

**当日情報を使ったこと自体を高評価しない。使わない方が良かった場合も正式な結果として記録する。**

---

## 0.7 ルール更新を凍結期間方式へ変更する

基本予想は回顧のたびに更新しない。

v1.4.0で確立した予想生成の基本骨格を基礎とし、第1サイクル終了審査で購入構築・監査・運用ガードを統合したv1.5.0 基本予想を維持し、v1.5.5を現行基準運用ファイルとして、**原則2週間を1検証サイクル**とする。JRAが土日3場・各12Rを開催する通常形を基準にすると、1開催日最大36R、2週間で最大約144Rとなる。実際の開催数・中止・海外競馬等により対象数が異なる場合は、実際に事前予想を保存できたレース数を正式なサンプル数とする。

検証の基本単位は次のとおり。

- **第1サイクル：約144R** — 問題発見・検証候補の収集
- **第2サイクル：累計約288R** — 第1サイクルで見つかった傾向の再現確認
- **第3サイクル：累計約432R** — 改訂候補の総合審査

**各サイクル終了時に必ずルールを変更するわけではない。** サイクル終了は「変更時期」ではなく「変更の必要性を審査する時期」とする。

原則として、第1サイクル終了時は予想生成の基本骨格を維持し、改善候補を検証中ルールへ整理する。ただし、予想生成そのものではなく、**情報取得バグの防止・順位保全・購入候補生成・相関リスク監査・非劣化ガード**のような運用／監査ルールについて、複数開催で同一失敗が再現し、既存基本予想の正常部分を壊さないことが確認できた場合は、第1サイクル終了時でも基本監査 / 基本運用規約へ統合してよい。第2サイクルでは今回昇格項目の非劣化と再現性を重点確認する。

サイクル中に得た改善は検証ログへ蓄積し、基本予想へ即反映しない。

例外として、

- 明確なデータ取得バグ
- 数式・確率の明確な論理矛盾
- 重複ルールによる二重計上
- 安全性・運用上の重大欠陥

のみ緊急修正を認める。

緊急修正も変更履歴へ理由を残し、予想成績の改善を目的とした事後的な調整とは区別する。

---

## 0.8 「追加」より「統合・置換」を優先する

新しいルールを正式化する場合、必ず次を確認する。

> この新ルールは、既存のどのルールを置換・統合・限定するのか？

既存ルールと同じ目的を持つ場合は、新番号を増やすより既存項目へ統合する。

新しい確認項目が既存ルールの言い換えにすぎない場合は追加しない。

基本予想を肥大化させないこと自体を、予想精度管理の一部とする。

---

## 0.9 検証中ルールの昇格・降格基準

新仮説は次の順で扱う。

**改善候補 → 検証中ルール → 条件別補正 → 基本予想**

### 改善候補 → 検証中ルール

少なくとも、

- 失敗の原因を説明できる
- 事前に観測可能な情報を使っている
- 結果を知った後だけ成立する説明ではない

ことを確認する。

### 検証中ルール → 条件別補正

原則として、複数の独立したレース・条件で有効性を確認する。

目安として、**5件以上の適用例かつ複数条件**を集め、明確な悪化傾向がないことを確認する。

### 条件別補正 → 基本予想

基本予想への昇格は例外的に扱う。

目安として、**20件以上の適用例**または十分な長期サンプルで、異なる競馬場・クラス・条件でも有効性が確認できる場合に検討する。

有効性が限定条件だけなら基本予想へ上げず条件別補正に留める。

### 降格・廃止

- 効果が確認できない
- 適用条件が曖昧
- 既存ルールと重複
- 予想を不必要にフラット化する
- 情報コストに対して改善幅が小さい

場合は降格または廃止する。

## 0.11 予想の「鋭さ」を監視する

予想精度だけでなく、評価が不必要にフラット化していないかを確認する。

記録候補：

- 勝率1位と2位の差
- 勝率1位と中央値の差
- 上位3頭への勝率集中度
- 予想確信度
- 実際の勝ち馬の事前順位

ただし「差を大きくすること」自体を目的にしない。

長期的に、

- 予想確信度Aなのに確率が極端に平坦
- 予想確信度Cなのに1頭へ過度に集中

などの不整合を検出するために使う。

## 0.12 本バージョンの運用方針

v1.5.4でも、**予想ルール追加の速度より、既存ルールの有効性測定を優先する。**

当面は、

1. v1.5.5を第2検証サイクルの基準運用ファイルとして凍結
2. 予想生成の基本骨格はv1.4系、正式な購入・監査ガードはv1.5.0を維持
3. 条件別補正を条件付きで適用
4. Shadow比較予想をProduction固定後に差分記録
5. 基本予想と最終予想を比較
6. 原則2週間・最大約144Rを1サイクルとして集計
7. 第2サイクルではv1.5.0昇格項目の再現性・非劣化と、v1.5.1で追加した検証中ルールの差分価値を重点確認
8. 十分な再現性がなければ追加昇格せず据え置く

という運用を標準とする。

**回顧は毎レース行ってよいが、回顧と原本改訂を同義にしない。** 回顧で得た気付きはまずログへ保存し、サイクル終了時にまとめて検証する。

## 0.12.1 第1検証サイクル終了審査 — v1.5.0昇格判断

第1検証サイクルでは、予想生成の基本骨格よりも**最終順位の動かし方・買い目候補生成・妙味馬への依存・購入監査**に同型の失敗が繰り返された。

そのためv1.5.0では、予想生成の能力評価ロジックを大幅に変更せず、以下を優先順位順に正式化する。

### S：正式ルールへ昇格

1. **自然な組み合わせ監査 / 自然な組み合わせ監査**
   - 最終印・確率・主要シナリオから自然に生じる馬連・ワイド・三連系候補を、価格で削る前に一度生成する。
   - ◎○の馬連・ワイドは購入義務ではなく**候補生成義務**とする。
   - 三連系を買う場合、◎○2頭軸だけで終了せず、印内の自然な別組み合わせも監査する。

2. **最終順位保全 / 最終順位保全**
   - 朝・事前基本予想で複数の独立根拠から高評価した馬を、弱い直前情報やオッズだけで大幅降格させない。
   - 大幅変更には強い客観的新情報、または複数の独立材料を要求する。

3. **妙味馬は必須軸ではない / 妙味馬は万能軸ではない**
   - 「最も買いたい馬」と「全券種の共通軸」を分離する。
   - 妙味馬の価値は単勝・複勝・ワイド等で直接買えるため、価格差だけを理由に全買い目をその馬へ依存させない。

4. **万能軸・馬依存監査**
   - 購入前に馬依存率・シナリオ依存率を確認する。
   - 1頭が飛ぶと全買い目が消える構造は、対象馬の好走確率・確率レンジ・予想確信度で明示的に正当化できる場合だけ許容する。

5. **買い目期待値独立評価**
   - 「ある馬同士の馬連が安い」ことを、ワイド・三連複・三連単など別券種の低い期待値根拠へ横滑りさせない。
   - 券種・組み合わせごとに独立して確率と価格を比較する。

6. **良好部分保全 / 非劣化ガード**
   - 回顧で正常に機能した階層を保護し、失敗した階層だけを改善する。
   - 変更案には「何を変えないか」を必ず含める。

### A：正式運用へ統合するが、数値基準は固定しない

8. **①＋②の主従明示**
   - ①＋②と分類したレースは、購入前に必ず「①主＋②従」「②主＋①従」「①≒②」のいずれかを明示する。
   - ①≒②は双方が独立に高い期待値と説明できる場合に限定する。
   - 「①＋②だから半々」の機械配分は禁止する。具体的比率は次サイクルで継続検証する。

9. **公式最新情報優先ルール**
   - 馬場・馬体重・オッズ等の時点情報は、可能な限りJRA等の公式一次情報の最新タイムスタンプを基準にする。
   - 外部サイトと不一致の場合、時刻差を確認せず上書きしない。

### 継続検証中ルール

- **E-08 最終オッズ予測**：運用価値は確認できたが、サンプル不足のため実戦検証中ルールを維持する。
- **E-03 最終価格再確認**：E-08を標準とし、時間に余裕がある場合だけ追加確認する。
- **E-04 位置取り主導権**：有望だが適用例不足。
- **E-07 高確信度活用**：高い予想確信度を連系へ変換する考え方は継続検証。
- **①＋②で原則①主とする仮説**：数例で有効だったが固定ルール化しない。
- **長距離ハンデ・予想確信度B-以下の自動降格**：継続観察。
- **◎の鋭さ／○との順位差**：候補抽出に比べ◎順位が弱い傾向を継続測定し、現時点では予想生成の基本骨格を変更しない。

## 0.14 2週間検証サイクルの記録規約

2週間単位の検証では、**購入したレースだけでなく、事前予想を行ったすべてのレースを記録対象**とする。見送りもレース選別能力を評価する重要な結果として保存する。

正式な検証サンプルに含める条件は、原則として**レース結果を確認する前に予想が保存されていること**とする。結果確定後に馬柱から再構成したバックテストは参考資料として分離し、前向き検証の成績へ混ぜない。

各レースで最低限、次を保存する。

- 日付・競馬場・R・レース名
- 予想時刻と使用できた情報の時点
- 午前モード / 午後当日実測補正モード
- 基本予想上位3頭と基本予想勝率
- 予想を決めた3大要因
- 使用した条件別補正
- 条件別補正 / 検証中ルールによる変更理由と変更量
- 最終上位3頭と勝率・連対率・3着内率
- 初期予想確信度 / 基準予想の予想確信度 / 最終時点の予想確信度
- 予想確信度変更がある場合：変更段階数・理由コード・証拠強度・情報時刻
- 購入確信度（市場未取得・見送り前提なら未判定可）
- 購入優先度（モード2対象時）
- ① / ② / ①＋② / 見送り
- 最も勝つと思う馬 / 最も買いたい馬
- 買い条件・推奨買い目・資金比率
- オッズ取得時刻
- 結果・払戻
- 基本予想 / 条件別補正 / 検証中ルール / 価格判断 / 馬券構造の採点
- エラー分類
- 検証候補の有無
- E-09馬個体適性の主要根拠・証拠強度・比較用差分
- 古馬混合戦ではE-10対象馬と構造的優位差分
- E-12 人気構造タイプ
- E-11集中モード適用可否・本線ワイド基準額額・◎依存率
- 基準買い目 / 検証中ルール比較用買い目の比較

同一レースを複数回予想した場合は、**最初に保存した基本予想**と**発走前最後の最終予想**を両方残す。検証上、結果に対する最終成績は発走前最後の最終予想を使用し、当日実測補正の有効性評価には最初の基本予想との差を使用する。

## 0.16 改訂判定の3段階

サイクル回顧で見つかった問題は、次の3段階に分類する。

### A. 緊急修正

- データ取得の明確な誤り
- 数式・確率の論理矛盾
- 同一根拠の明確な重複適用
- ファイルの運用不能につながる欠陥

結果の当たり外れとは無関係に修正可能とする。

### B. 検証候補

- 同一サイクルで複数回観測
- 発走前に取得可能な情報で説明できる
- 理論的にも再現可能性がある

次サイクルで再現確認する。基本予想は変更しない。

### C. 継続観察

- 1〜2例のみ
- 確率的敗戦で説明できる
- 結果を知った後でしか説明できない

ルール候補へ昇格させない。

## 0.16.1 良好部分保全 / 非劣化ガード（基本運用規約）

サイクル終了審査・毎レース回顧の双方で、改善案は**失敗した階層だけに局所化**する。

必ず、

- **保護**：正常に機能したため変更しない
- **再検証**：有効性が不明で次サイクルでも比較する
- **改善対象**：同型エラーが再現し、変更候補とする

を分ける。

正式な変更案には、

1. 何を改善するか
2. どの事前情報で改善可能か
3. 何を変えないか
4. 既存成功例を壊さないか

を明記する。

単発の失敗で正常機能を弱体化させず、単発の成功で新ルールを昇格させない。

## 0.17 単一レースモード — 別チャットで1レースだけ予想する場合

本ファイルは開催全体の全体選別だけでなく、**別チャットで指定された1レースだけを独立して予想する用途**にも使用できる。

ユーザーが競馬場・日付・Rまたはレース名を指定して1レースの予想を依頼した場合は、**単一レースモード**を使用する。

単一レースモードでは、開催全体36Rの全体選別を必須としない。指定されたレースだけについて基本予想を完全適用し、該当条件別補正だけを使用する。

ただし当日馬場補正を使うために必要な場合は、同日同競馬場の既終了レースを**馬場・位置取り傾向の参考データとしてのみ確認**してよい。これを別レースの購入候補選定へ拡張しない。

単一レースモードでも、

- 事実・解釈・予測の分離
- 予想を決めた3大要因
- 基本予想
- 該当条件別補正による差分
- レース質・複数シナリオ
- 勝率・連対率・3着内率
- 不確実性レンジ・予想確信度
- 購入確信度（市場取得前は未判定）
- 印と確率順位の整合性
- 市場オッズとの比較
- 最も勝つと思う馬 / 最も買いたい馬
- ① / ② / ①＋② / 見送り
- 馬券構造・依存率監査

は省略しない。

他チャットの過去会話や記憶がなくても、**このファイルとそのレースの事前情報だけで予想を完結できる**ことを原則とする。過去チャット固有の評価を暗黙に持ち込まない。

予算が指定されている場合は具体的な金額で買い目を提示する。予算が指定されていない場合は、無理に金額を仮定せず**資金配分比率**または買い目の優先順位を示す。

## 0.19 二段階購入設計 — 推奨候補 → ユーザー選択 → 最終最適化

本ファイルでは、**予想側が最初から実購入を一方的に確定する方式ではなく、推奨候補を提示した後にユーザーの購入意思を受け取り、最終購入設計を再最適化する二段階運用**を正式な使用方法として認める。

この運用は予想ロジックを変更するものではなく、レース予想と実購入の間にユーザー意思決定を明示的に挟むための運用規約である。

### 0.19.1 第1段階：予想側の推奨候補提示

通常の単一レース予想では、最終印・確率・市場評価を確定した後、少なくとも次を提示する。

- 推奨馬（軸候補 / 相手本線 / 穴候補）
- 各馬の勝率・連対率・3着内率
- 最も勝つと思う馬
- 最も買いたい馬
- 単勝向き / 馬連向き / ワイド向き / 三連複向き / 三連単向き等の券種適性
- 推奨買い目候補
- 各買い目の優先順位
- 必要に応じて買い条件・見送り条件

この段階の買い目は**「予想側の推奨候補」**であり、ユーザーの最終購入意思とは区別して保存する。

### 0.19.2 第2段階：ユーザーの購入条件入力

ユーザーは必要に応じて、

- 買いたい馬
- 使用したい券種
- 予算
- 取りたいリスクの程度

を指定する。

例：

> 買いたい馬：①④⑤  
> 券種：馬連・ワイド・三連複  
> 予算：3,000円

自然文で、

> ①④⑤の馬連、ワイド、三連複を3,000円買いたい

と指定しても同じ意味として処理する。

ユーザーの選択は馬の能力評価を変更する材料ではなく、**購入対象を限定する意思決定条件**として扱う。

### 0.19.3 第3段階：指定条件内で最終買い目を最適化する

モード7を起動し、ユーザーの条件内で次を比較する。

- 選択馬それぞれの勝率・連対率・3着内率
- 選択馬同士の同時好走可能性
- 本線シナリオで同時に成立しやすい組み合わせ
- 現在オッズ・組み合わせオッズ
- 推定確率に対する価格
- 馬依存率・シナリオ依存率
- 同じ失敗条件を持つ買い目の重複
- 本線 / 押さえ / 高配当の役割分担

そのうえで、**選択された馬・券種をすべて均等に買うことを目的にしない。**

例えばユーザーが①④⑤と馬連・ワイド・三連複を指定しても、

- 馬連①-④は本線
- ワイド①-⑤は価格妙味が高い
- 馬連④-⑤は成立確率に対して価格不足
- 三連複①-④-⑤は少額高配当向き

と判断した場合、馬連④-⑤を買わず、その資金を①-④や①-⑤へ振ることを認める。

### 0.19.4 券種適性は馬の役割から決める

ユーザーが選んだ馬をすべて同じ用途で扱わない。

- **勝率の市場過小評価が大きい馬**：単勝・馬連の中心候補
- **3着内率の市場過小評価が大きい馬**：複勝・ワイド・三連複の候補
- **勝ち切り確率は低いが相手として安定する馬**：馬連相手・三連複相手
- **高変動の穴馬**：少額ワイド・三連複・三連単等のオーバーレイ候補

とし、元の確率評価に沿って券種と資金配分を決める。

### 0.19.5 ユーザー指定を尊重しつつ、低い期待値を機械的に買わない

ユーザーが「この3頭を買いたい」と指定した場合、その3頭の範囲で最適化する。

ただし、指定馬・指定券種の中に明確に価格不足と判断する組み合わせがある場合は、

> 指定された候補ではあるが、この組み合わせは見送る

と明示してよい。

予算を使い切るためだけに低い期待値買い目を追加しない。

一方、ユーザーが「予算を全額使う」と明示している場合は、その制約を尊重し、指定条件内で相対的に最も合理的な買い目へ配分する。

### 0.19.6 選択外の馬・券種の扱い

ユーザーが選択していない馬・券種は、正式な最終買い目へ自動追加しない。

ただし、選択外の候補を加えることで期待値・的中構造が大きく改善すると判断した場合は、

- **指定条件内の最適案**
- **参考代替案**

を分離して提示する。

ユーザーの指定条件を無視して参考代替案を正式案へ置き換えない。

### 0.19.7 再最適化時に予想本体を動かさない

購入最適化段階では、原則として保存済みの、

- 基本予想順位
- 最終印
- 勝率・連対率・3着内率
- レースシナリオ

を固定する。

オッズだけが変化した場合は価格判断・資金配分だけを変更する。

馬体重、取消、騎手変更、馬場急変等の**新しい非価格情報**が得られた場合のみ、既存ルールに従って予想本体の再評価を行い、購入最適化の前にその変更を明示する。

### 0.19.8 最終購入案の標準出力

モード7では、原則として次を簡潔に提示する。

1. **ユーザー指定条件**：馬 / 券種 / 予算
2. **指定馬の役割**：軸 / 相手本線 / 穴 / 3着候補等
3. **採用買い目**
4. **買わない候補と理由**
5. **各買い目の金額**
6. **合計金額**
7. **本線 / 押さえ / 高配当の資金比率**
8. **馬依存率・シナリオ依存率の簡易確認**
9. 必要な場合のみ**参考代替案**

### 0.19.9 回顧では3段階を分離して記録する

購入最適化を行ったレースでは、回顧時に次を分けて記録する。

1. **予想側の初回推奨買い目**
2. **ユーザーが指定した購入条件**
3. **指定条件から最適化した最終買い目**

これにより、

- 予想そのもの
- 予想側の初回馬券設計
- ユーザーの馬・券種選択
- 最終資金配分

を混同せず検証する。

既存48の「買い目の出所を分離する」規定と併用し、どの段階が収支・的中へ寄与したかをサイクル単位で検証する。

# 1. 大原則

予想の目的は、まず**レースそのものを正しく予測すること**とする。

単勝・複勝・ワイド・三連系などの馬券種から逆算して各馬の評価を変えない。

基本順序は以下。

**レース分析 → 各馬評価 → 着順・好走確率推定 → 市場評価との比較 → 馬券戦略**

したがって、

- ◎＝必ず単勝を買う馬ではない
- 複勝向きだから◎にはしない
- 穴だから評価を上げない
- 人気だから評価を下げない
- レース予想と馬券戦略は明確に分離する

---

# 2. 事実・解釈・予測を分離する

各材料を必ず、

**事実 → 解釈 → 今回への予測**

の順で扱う。

例：

- 事実：前走上がり最速
- 解釈：終盤性能は高かった
- 予測：今回も同じ脚を使えるかは、位置取り・ペース・馬場を別途検討

「上がり最速だから今回も差せる」のように、途中の論理を飛ばさない。

レース後も、

- データ認識が間違っていたのか
- データの解釈を間違えたのか
- 今回への適用を間違えたのか

を区別する。

---

# 3. 基礎能力と今回発揮能力を分ける

各馬について、

**本来の能力**
と
**今回の条件で発揮できる能力**

を別々に考える。

絶対能力が高くても、

- 馬場不適合
- 距離不適合
- 展開不利
- 位置取りリスク
- 枠不利
- 状態不安

などがあれば今回評価を下げる。

逆に絶対能力が多少劣っていても、条件好転で逆転可能なら評価する。

---

# 4. 能力を分解して評価する

単純な「能力A」のような一枚岩の評価だけにしない。

必要に応じて、

- 基礎スピード
- 高速巡航力
- 瞬発力
- 加速力
- 末脚最高速度
- 持続力
- スタミナ
- 位置取り能力
- 操縦性
- 坂への対応
- 道悪性能

など、**そのレースで要求される能力**に分解する。

そのうえで、「今回どの能力が重要か」を先に考える。

---

# 5. 着順よりレース内容を評価する

近走は着順だけで評価しない。

必ず、

- 着差
- 相手レベル
- ペース
- ラップ
- 位置取り
- 4角位置
- 上がり
- 進路
- 距離ロス
- 出遅れ
- 不利
- 馬場バイアス
- 展開恩恵

を確認する。

**着順ではなく、その着順になるまでの過程を評価する。**

---

# 6. 直近2〜3走から現在地を判断する

前走だけで判断せず、

- パフォーマンス推移
- 時計
- ラップ
- 位置取り
- 末脚
- 相手レベル
- 距離
- 馬場
- レース質

を比較する。

「前走が強かったか」に加えて、

**現在能力が上昇・維持・下降のどこにあるか**

を判断する。

---

# 7. 成長・上昇度を独立評価する

特に3歳馬やキャリアの浅い馬では、成長・上昇度を独立した評価項目として扱う。

ただし、

**3歳だから成長する**

とは評価しない。

実際の、

- パフォーマンス上昇
- 時計・ラップ改善
- 位置取り改善
- 上がり改善
- 相手強化への対応
- 距離変更
- 休養効果
- 馬体・調教

などから判断する。

---

# 8. 「未知」と「弱点」を区別する

例えば、

**2400m未経験 ≠ 2400m不適性**

とする。

初距離、初コース、初馬場などの情報不足は原則、

**マイナスではなく不確実性増加**

として扱う。

特に、

- 3歳馬
- 昇級馬
- キャリアの浅い馬
- 海外馬
- 条件替わり馬

で重要。

## 8.1 操縦性・精神面不確実性を独立評価する

競走能力・適性・状態とは別に、**その能力を実戦で安定して再現できるか**という観点から、操縦性・精神面の不確実性を独立評価する。

特に2歳馬・キャリアの浅い馬・初条件の馬では、能力が高くても実戦時の挙動に関する観測数が少ないため、次の項目を可能な範囲で確認する。

- キャリア数と実戦経験の幅
- 初めての右回り・左回り、初コース、初めてのコーナー形態
- コーナリング時のバランス、外へ膨れる・内へモタれる傾向
- 直線での斜行、蛇行、進路維持
- 手前替えのスムーズさ
- 騎手の扶助への反応、追い出してからの反応の素直さ
- 折り合い、力み、行きたがる・ブレーキを掛ける挙動
- 他馬を気にする、馬群を嫌がる、被されると反応が落ちる傾向
- 先頭でソラを使う、物見をする、単独になると集中を欠く傾向
- ゲート内・発馬後・返し馬でのテンションや落ち着き
- 騎手・調教師コメントにおける「幼い」「集中力」「操縦性」「モタれ」「物見」などの示唆

### 評価方法

操縦性・精神面は原則として、

- **安定**：類似条件で複数回、問題なく能力を発揮している
- **標準**：大きな問題は確認されていないが、経験数は十分ではない
- **不確実性高**：実戦経験が少ない、未経験条件が重なる、または過去に明確な操縦性・集中力の問題がある

のように評価する。

ただし、

**初左回りだから減点**
**キャリア1戦だから能力を下げる**

のような機械的処理は禁止する。

未知要素だけなら、まず**基礎能力を下げず、不確実性レンジを広げる**。

一方、過去に同種のモタれ・逸走・折り合い難・集中力低下などが複数回確認され、今回条件でも再発しやすいと判断できる場合は、該当シナリオでの好走確率を下げる。

### 調教と実戦を分ける

調教で右回り・左回りや操縦性に問題がなくても、

**調教で問題なし ＝ 実戦の高速・他馬・観客・コーナー負荷でも問題なし**

とはしない。

調教情報は不確実性を下げる補助材料として利用するが、類似条件での実戦経験より強い証拠とは扱わない。

### 実戦再現性として扱う

この項目は、単なる能力評価ではなく、

> **持っている能力を今回の競馬で通常どおり発揮できる確からしさ**

を評価するために使う。

操縦性・精神面不確実性が高い馬は、勝率を機械的に大きく下げるのではなく、

- 勝率・連対率・3着内率の合理的レンジを広げる
- 予想確信度を下げる要因とする
- 極端な資金集中を避ける判断材料とする
- 逃げ・単独先頭・馬群内など、どの状況でリスクが顕在化しやすいかをシナリオ別に確認する

という形で反映する。

「逃げ馬だから精神面が危険」など、脚質だけで機械的にリスク認定しない。

また、状態不安・適性不安・位置取りリスクと同じ根拠を二重計上しない。

※ 実戦検証中。

---

# 9. クラスアップ馬を機械的に下げない

現級実績がないことだけで低評価にしない。

前走の、

- 時計
- ラップ
- 勝ち方
- 相手
- 着差
- 余力
- 成長余地

から、前走時点ですでに上級条件でも通用する能力だった可能性を検討する。

ただし、**「クラス実績がないから下げない」ことと「上昇余地を中心確率へ大きく織り込む」ことは別**とする。

連勝中、3歳、軽斤量、コース適性、成長余地などは上級条件での好走可能性を支える材料にはなるが、それ自体を上級条件での能力証明とは扱わない。中心評価は可能な限り、

- 前走時計・ラップを今回のクラス水準へ変換した比較
- 前走相手のその後の成績
- 同等以上の相手に対する実走内容
- 追走負荷が上がった場合にも終盤性能を維持できる根拠

から作る。

上級条件との直接比較材料が少ない場合、成長・上昇余地はまず**合理的レンジの上側を広げる材料**として扱い、中心勝率・連対率・3着内率を過度に押し上げない。

また、

- 連勝・上昇度
- 3歳・軽斤量
- コース適性
- クラスアップでも通用する可能性

が同じ「上振れ余地」を表現している場合は、独立した複数根拠として二重・三重に加点しない。

※ 実戦検証中。

# 10. 相手関係を評価する

前走の勝ち馬・負かした馬・接戦馬のその後も確認し、過去レースのレベルを再評価する。

同じ「2着」でも相手によって意味は異なる。

# 11. レース質は馬の評価より先に作る

予想バイアス防止のため、

**◎○▲を決める前にレース展開を分析する。**

特定の本命馬に都合のよい展開を作らない。

まず出走馬全体から、

- 逃げ候補
- 先行争い
- 各馬の希望位置
- 騎手
- 枠
- 馬場
- ペース

を分析し、その後に各馬を当てはめる。

---

# 12. レース質を具体的に定義する

単純な、

- 前有利
- 差し有利

では終わらせない。

基本的に、

**馬場 × ペース × 脚質 × 位置取り × 末脚**

から、

> 好位〜中団で高速巡航についていき、直線でも長く脚を使える馬向き

など、具体的なレース質を定義する。

また、**「前有利」と「逃げ馬有利」を同一視しない。**

スローペースで前方勢が有利でも、最も有利な位置が必ずしも逃げ馬とは限らない。

- 逃げ
- 番手
- 好位
- 中団前
- 中団後ろ

のように位置取りを帯で捉え、**どの位置帯が最も少ない負荷で勝負所へ入れるか**を考える。

特に直線の長いコースで急加速が必要な場合、逃げ馬は自ら加速を作る一方、番手・好位馬は目標を置いて脚を溜められる場合がある。

したがって、当日の前残り結果を見ても、

**前残り → 逃げ馬を上げる**

と短絡せず、実際に恩恵を受けた位置帯とレースラップを確認する。

※ 実戦検証中。

---

# 13. 複数シナリオを想定し、発生確率を検証する

一つの展開に決め打ちしない。

例：

- シナリオA：平均ペース・好位優勢 50%
- シナリオB：ハイペース・差し優勢 30%
- シナリオC：スロー瞬発戦 20%

各馬について、

**どのシナリオなら強いのか**

を評価する。

レース後は、

- 実際にどのシナリオに近い展開になったか
- そのシナリオに事前何%を与えていたか
- 想定との差が生じた理由
- 逃げ・先行馬の行動予測や騎手意図のどこが違ったか

を記録し、**展開シナリオ自体の確率予測も確率精度の検証する。**

馬の好走確率と展開シナリオ確率は別々に検証し、展開予測の偏りを把握する。

※ 実戦検証中。

# 14. ペース予想

逃げ馬の数だけでは判断しない。

- ハナへの拘り
- 先行馬数
- 枠
- 騎手
- 前走位置
- 距離変更
- 陣営意図

まで考慮する。

# 15. 騎手を「展開を作る要因」として扱う

騎手は能力加点だけでなく、

**実際の隊列・ペース発生確率に関係する要素**

として扱う。

同じ逃げ馬でも騎手によってハナへの意識は変わる。

## 15.1 厩舎を「仕上げ・使い方・条件選択」の要因として扱う

厩舎成績は、単純な勝率・有名厩舎というブランドを加点するためではなく、

**その馬を今回どの程度走れる状態へ持ってくる傾向があるか、どの条件・ローテーションで能力を発揮させやすいか**

を推定する予想材料として扱う。血統・騎手と同様に全レースで確認可能な基本予想材料とするが、馬自身の実走内容より上位の根拠にはしない。

可能な範囲で次を確認する。

- 厩舎の直近成績と中長期の基準成績
- 当該競馬場・芝 / ダート・距離帯・クラス・年齢条件での成績
- 新馬・休み明け・叩き2戦目・連闘 / 中短間隔などローテーション別成績
- 重賞・昇級戦・初条件など、仕上げ難度が高い条件での成績
- 遠征・滞在・輸送を伴う条件での成績が取得可能な場合の傾向
- 当該馬を管理してからのパフォーマンス推移
- 転厩前後でのパフォーマンス変化
- 厩舎×騎手の組み合わせ成績と起用傾向
- 厩舎が同タイプの馬で繰り返している使い方・条件選択・間隔パターン
- 調教師・厩舎コメントから読み取れる仕上がり、狙い、次走余地。ただし発言内容以上へ拡大解釈しない

### 厩舎成績の評価原則

1. **小サンプルを強い根拠にしない。** 2戦2勝等をそのまま「得意条件」と認定しない。
2. **可能なら母数と市場期待を補正する。** 勝率だけでなく、人気・オッズを考慮した期待以上 / 以下の成績、複勝率、回収率等も確認し、「強い馬が多い厩舎だから高勝率」という循環を避ける。
3. **直近好調だけを過大評価しない。** 直近数週の好調は状態情報として使うが、偶然変動の可能性を残し、中長期成績と併記する。
4. **馬自身の直接証拠を優先する。** 厩舎傾向と当該馬の実走が矛盾する場合は、原則として当該馬の実走を優先する。
5. **騎手・ローテ・状態との二重計上を防ぐ。** 「得意騎手起用」「叩き2戦目」「近況好調」等が同一原因を表す場合、厩舎・騎手・状態で重複加点しない。
6. **転厩は自動的なプラス / マイナスにしない。** 前後の調教・レース内容・条件選択・馬体・コメントを確認して、実際の変化として評価する。

厩舎要素は、主に**今回発揮能力・状態不確実性・ローテーション適合・シナリオ再現性**を補正するために使用する。厩舎名そのものを能力点へ直接変換しない。

# 16. 時計とペースを混同しない

高速馬場では走破時計が速くてもハイペースとは限らない。

前半・中盤・終盤ラップと馬場を補正し、

**実質的なペース強度**

を判断する。

# 17. 上がり3Fを単独評価しない

上がりは、

**位置取り × ペース × 道中負荷 × 馬場**

とセットで評価する。

後方で脚を溜めた上がり最速より、速い流れを好位追走しながら上位の脚を使った馬を高く評価する場合がある。

---

# 18. 高速馬場では高速巡航能力を重視する

高速馬場では、

**高速巡航能力 ＋ 終盤性能**

を重視する。

単純な瞬発力ランキングにしない。

# 19. 当日馬場・開催傾向を更新する

当日は可能な限り、

- 馬券内馬の位置取り
- 4角位置
- 上がり順位
- 内外
- 時計
- ラップ
- 同コース
- 同距離

を確認する。

事前傾向より、当日の実測情報を重視する場合がある。

---

# 20. 馬場バイアスに信頼度を設定する

少数レースだけで、

> 外差し馬場確定

などと断定しない。

バイアス判断について、

- 強
- 中
- 弱

などの信頼度を持たせる。

考慮するのは、

- サンプル数
- 人気
- 馬の能力
- ペース
- レース内容

さらに、**馬場バイアスと、そのレース固有の展開結果を分離する。**

同一コースで先行馬が上位を独占していても、極端なスローペースなどで前方勢が展開利を得ただけなら、馬場そのものが前有利とは限らない。

特に1レースのみの観測では、

> 同コースで前残りした

という事実を、

> 当日の馬場は逃げ・先行有利

へ直接変換しない。

可能な限り複数レースについて、

- レース全体のペース
- 上位馬の人気・能力
- 直線での進路
- 逃げ・番手・好位のどの位置帯が残ったか
- 差し馬が脚を使えていたか

を確認し、**「馬場による有利不利」なのか「そのレースの展開による有利不利」なのか**を分けて判断する。

※ 実戦検証中。

# 21. 枠順は単独評価しない

枠だけを評価しない。

**枠 × 脚質 × 馬場 × ペース × 位置取り**

として評価する。

# 22. 血統は適性仮説として利用する

血統は結論ではなく、

**適性仮説**

として利用する。

血統から、

- 距離
- 馬場
- 持続力
- 瞬発力
- 成長力

などを予測し、その馬自身の実走内容で検証する。

実走と血統が矛盾する場合は、原則として実走を優先する。

# 23. 外部情報は「印」ではなく「根拠」を使う

利用対象：

- JRA等の公式情報
- 専門媒体
- 競馬新聞
- 定量データ
- AI分析
- 血統分析
- 海外情報
- 個人分析

ただし、

**印の多数決はしない。**

その情報の、

- 根拠
- 母数
- 再現性
- 今回への適用性
- 他情報との重複

を評価する。

---

# 23.1 情報の鮮度と信頼度を別々に評価する

外部情報は「新しいか」と「信頼できるか」を同一視しない。

各情報について可能な範囲で、

- **鮮度**：いつ取得・公表された情報か
- **信頼度**：主催者公式、一次情報、専門媒体、推測情報など、根拠の強さ

を分けて評価する。

例：

- JRA公式の当日馬体重：鮮度高・信頼度高
- 当日馬場公式発表：鮮度高・信頼度高
- 前日の陣営コメント：鮮度中・信頼度中〜高
- SNS上の未確認情報：鮮度高でも信頼度低の場合がある
- 過去傾向：鮮度は低いが、条件が一致し母数が十分なら一定の信頼性を持つ

**最新情報だから強く反映するのではなく、鮮度 × 信頼度 × 今回への関連性で重みを決める。**

鮮度が低い情報は現在条件との差を確認し、信頼度が低い情報は単独で大きな評価変更を行わない。

※ 実戦検証中。

---

# 24. 評価材料の二重計上を防ぐ

例えば、

- 上がり最速
- 末脚優秀
- 差し脚強力
- 前走終盤性能優秀

が実質同じ材料なら4回加点しない。

評価材料を、

- 能力
- 適性
- 状態・成長
- 騎手・厩舎・血統等の補助適性
- 展開
- 市場

などの大分類に整理し、同じ根拠を過剰評価しないようチェックする。

※ 実戦検証中。

---

# 25. パフォーマンスの「平均」と「分散」を分ける

競走馬は毎回同じ能力を出さない。

そのため、

**能力水準**
と
**パフォーマンスの安定性**

を分ける。

例：

- 安定型：上限は少し低いが毎回能力を出す
- 高変動型：凡走も多いが最大能力が高い

これはレース予想上の特徴として扱い、馬券戦略はその後で考える。

---

# 26. 人気馬と穴馬を同じ基準で評価する

人気馬には欠点ばかり、穴馬には長所ばかりを探すことを避ける。

主要馬について共通して、

- 強み
- 弱み
- 好走条件
- 凡走条件

を確認する。

---

# 27. 買い条件・消し条件を設定する

上位評価馬について、

**買い条件**
と
**割引・消し条件**

を事前に設定する。

直前馬場などで条件に該当した場合のみ評価を変更する。

---

# 28. 確率評価を導入し、事後確率精度の検証する

印だけではなく、可能な範囲で各馬について、

- 勝率
- 連対率
- 3着内率

を推定する。

ただし各馬を独立に適当に数値化せず、

**レース全体として整合する確率**

を意識する。

さらに、一定数の実戦が蓄積したら予想確率帯ごとに実績を集計する。

例：

- 勝率30%以上と評価した馬の実勝率
- 勝率20〜30%と評価した馬の実勝率
- 勝率10〜20%と評価した馬の実勝率

を比較し、**自分の予想確率が過大評価・過小評価になっていないかを検証する。**

勝率だけでなく、連対率・3着内率についても可能な範囲で同様に確率精度の検証する。

「印が当たったか」だけではなく、**付与した確率そのものの精度**を長期的に評価する。

さらに、複数シナリオを設定したレースでは、各馬の最終確率とシナリオ評価の整合性を確認する。

概念的には、

> **馬の勝率 ≒ Σ（各シナリオの発生確率 × そのシナリオでの勝率）**

として考える。厳密な数理計算を必須とはしないが、少なくとも、

- 本線シナリオで強い馬の確率が十分に反映されているか
- 上位確率を与えた馬が、どのシナリオでその確率を稼いでいるか説明できるか
- 発生確率の低いシナリオに依存する馬を高確率にする場合、基礎能力にそれを補う根拠があるか
- シナリオ分析では高評価なのに最終確率だけ低い、またはその逆になっていないか

を確認する。

これにより、**展開分析を文章上だけで終わらせず、最終確率へ実際に反映する。**

## 28.1 HF1確率生成・変更統制（予想モデル非変更の再現性ガード）

本項は新しい点数モデルを導入するものではない。既存28の考え方を、別チャット・別時点で大きく揺らさないための**変更統制**として使用する。

### 初回確率生成

1. 先に複数シナリオを作り、シナリオ発生確率の合計を100%にする。
2. 各馬がどのシナリオで確率を得ているか説明できる状態で中心勝率を作る。
3. 最終的な全馬の勝率合計を100%へ整合させる。
4. 連対率・3着内率は勝率順位・シナリオ評価と論理矛盾がないか32.1で監査する。
5. 初回の中心値・レンジ・印・情報時刻を保存する。

### 固定後の変更統制

Production基準確率を一度固定した後、新情報による中心値変更は原則として次を目安にする。

- **弱い新情報**：中心値は原則変更しない。不確実性レンジ・シナリオ確率・購入額だけを必要に応じて調整する。
- **中程度の新情報**：単一馬の中心値変更は原則±1ポイント程度を目安とし、変更理由を保存する。
- **強い新情報**：単一馬の中心値変更は原則±2〜3ポイント程度を目安とし、他馬を含めて全体を再整合させる。
- **取消・重大な状態変化・事実誤認訂正等**：上記目安を超えて変更してよいが、理由コード・証拠強度・情報時刻を必須記録し、全体を再正規化する。

上記は「正しい勝率を作る公式」ではなく、**弱い材料で確率が大幅に動くことを防ぐガード**である。複数の同方向情報があっても同一原因の言い換えなら24の二重計上防止を適用する。

### 同一レース・別チャット

同一バージョン・同一情報時点のProduction基準確率が既に存在する場合は、それを再利用する。新しい強い非価格情報がない限り、別チャットで初回確率から作り直さない。

# 30. 確信度設計 / 予想確信度と購入確信度を分離する

確信度は、**予想そのものへの確信**と**その価格で馬券を買うことへの確信**を混同しない。

v1.5.3以降、無修飾の「レース確信度」という表現は新規出力では使用せず、次の2軸を正式名称とする。

- **予想確信度**：レース結果をどの程度予測しやすいか。原則としてオッズ非依存。
- **購入確信度**：現在価格・予測最終価格・買い目期待値・買い目構造まで含め、その買い目全体へ資金を入れる妥当性。

開催全体の選別で使う購入候補の並び順は、確信度とは別に**購入優先度**として扱う。

## 30.1 予想確信度

予想確信度は、**馬券価格ではなくレースの予測可能性**を表す。

主な評価要素：

- 能力比較の明確さ
- 展開・ペース・位置取りの読みやすさ
- 馬場適性と当日馬場の不確実性
- 状態・成長・休み明け等の不確実性
- 操縦性・精神面・馬群対応など実戦再現性
- 出走情報・馬体重・馬場等の一次情報の品質
- 上位候補の絞り込みやすさ
- 主要シナリオ間の収束度

**オッズが安くなった、高くなった、人気順位が変わったという理由だけでは予想確信度を変更しない。**

市場価格の鮮度・オッズ変動・買い条件跨ぎは購入確信度側で扱う。

## 30.2 予想確信度 / 購入確信度の共通グレード

実運用ですでにA+、B+、B-等を使用しているため、v1.5.3から次の9段階を正式化する。

| 段階 | 予想確信度の意味 | 購入確信度の意味 |
|---|---|---|
| A+ | 非常に予測しやすい | 非常に強く購入候補化できる |
| A | 予測しやすい | 強く購入候補化できる |
| A- | やや高確信 | やや高い購入確信 |
| B+ | 標準より上 | 標準より上の購入確信 |
| B | 標準 | 標準 |
| B- | 標準より下 | 購入額を抑えるべき水準 |
| C+ | 不確実性が高い | 条件付き・少額のみ検討 |
| C | 非常に不確実 | 原則見送り寄り |
| C- | 極めて不確実 | 原則見送り |

グレードは**勝率そのものではない**。予想確信度A+でも◎の勝率が50%未満の混戦はあり得るし、予想確信度Bでも明確な価格差があれば購入確信度が高くなることはある。

ただし予想確信度と購入確信度が**2段階以上乖離**する場合は、なぜ乖離するのかを明記する。特に予想確信度が低く、購入確信度が高い場合では、保守側の確率レンジでも期待値が残るかを必ず確認する。

## 30.3 購入確信度

購入確信度は、**最終的に提案する買い目全体への資金投入妥当性**を表す。

主な評価要素：

- 予想確信度と各馬の確率レンジ
- 現在オッズとフェアオッズの乖離
- E-08の予測最終オッズ中心値・レンジ・買い条件割れ確率
- 買い目期待値
- 券種ごとの価格歪み
- 自然な組み合わせ監査後の買い目構造
- 馬依存率・シナリオ依存率
- 価格情報の鮮度・整合性
- 予算に対する資金集中の妥当性

購入確信度は価格変動で変更してよい。例えば、

> 予想確信度：A+ / 購入確信度：C+

は「予想はしやすいが、売れすぎて買いにくい」レースを意味する。

逆に、

> 予想確信度：B / 購入確信度：A-

は「レースは標準的な不確実性だが、保守側でも十分な価格差がある」ケースを表す。

**具体的な市場オッズまたは予測最終価格をまだ取得していない段階では、購入確信度を無理に付けず `未判定` とする。**

従来の「購入確信度」に相当する記述は、v1.5.3以降は購入確信度へ一本化し、同じ意味の別指標として二重表示しない。

## 30.4 購入優先度 / 開催全体でどのレースを先に見るか

モード2の開催全体の選別では、候補レースを並べるために購入優先度を使用する。

- **購入優先度：S**：最優先で最終予想へ進める
- **購入優先度：A**：強い購入候補
- **購入優先度：B**：条件付き購入候補
- **購入優先度：C**：再確認・価格待ち
- **購入優先度：D**：見送り

購入優先度は予測精度そのものを測る指標ではなく、**当日の時間配分・購入候補の作業順**である。

`予想確信度：A / 購入確信度：未判定 / 購入優先度：S` のように併記してよい。

E-12の人気構造分類と混同しないため、購入優先度は英字略号を使わず**「購入優先度：S〜D」**と日本語で表記する。

## 30.5 予想確信度を簡単には動かさない

開催全体の選別、基本予想、基準予想、最終予想の間で予想確信度を変更する場合は、変化を監査可能にする。

原則：

1. **市場価格だけでは予想確信度を変更しない。** 価格は購入確信度 / 購入優先度へ反映する。
2. 予想確信度を1段階以上変更する場合は、発走前に理由コード・根拠・情報時刻を保存する。
3. 段階数は30.2の隣接段階間の移動数で数える。例：**A+→Bは4段階変更**と扱う。
4. 予想確信度を2段階以上変更する場合は、原則として「強い新情報」または「独立した複数根拠」を要求する。
5. A+→Bのような大幅変更は、単なる再考・不安・オッズ変動だけでは認めない。
6. 詳細分析で事前に存在していた重要事実を新たに確認した場合は変更してよいが、**分析訂正**として別記し、朝全体選別側の過信だった可能性も検証する。
7. 予想確信度を変更しないこと自体を目的にしない。目的は、証拠強度より大きな変更を防ぐことである。

### 予想確信度を変更してよい主な理由

- **予想確信度理由01：馬場・天候などの条件変化**：公式馬場・天候等の明確な条件変化
- **予想確信度理由02：馬体重・騎手・取消などの状態変化**：馬体重、取消、騎手変更、重大な状態情報
- **予想確信度理由03：展開構造の変化**：取消・脚質変更等により隊列・展開構造が実質的に変化
- **予想確信度理由04：当日実測による強い根拠**：複数の当日同条件レース等から強い当日実測バイアスを確認
- **予想確信度理由05：馬個体・コース適性などの新規確認**：馬個体・コース・砂被り等の重要な事実を新たに検証確認
- **予想確信度理由06：データ誤り・時刻不整合の訂正**：事前データの誤り・時刻不整合・情報欠落を訂正
- **予想確信度理由07：詳細分析による事前評価の訂正**：新規オッズではなく、既存の事実を詳細精査して事前評価の見落としを訂正

**無効な単独理由：**

- オッズが下がった / 上がった
- 人気順位が変わった
- 配当が安い / 高い
- 追加で考え直したら不安になった
- 的中させたい / 高配当を取りたいという感情

## 30.6 予想確信度の不確実性タイプ

予想確信度を構成する主な不確実性を、最低でも次に分類する。

- **能力不確実性**：昇級馬・キャリア浅い馬・比較困難な馬が多い
- **展開不確実性**：逃げ候補多数、脚質変更余地、隊列が読みづらい
- **馬場不確実性**：降雨、急激な馬場変化、当日傾向のサンプル不足
- **状態不確実性**：休み明け、馬体変動、調整過程に不確定要素が多い
- **操縦性・精神面不確実性**：モタれ、折り合い、集中力、コーナリング、馬群対応など能力発揮の不確定要素が大きい
- **情報不確実性**：馬場・馬体・出走情報等の一次情報に鮮度・整合性問題がある

**オッズ情報の鮮度だけ**は予想確信度の情報不確実性へ入れず、購入確信度の価格情報品質へ入れる。

## 30.7 基準予想 / 比較予想での扱い

モード5では、基準予想と比較予想を混ぜず、

- 基準予想の予想確信度
- 比較予想の予想確信度
- 予想確信度差分と理由

を発走前に固定する。

E-09 / E-10によって不確実性の種類や予測可能性が変わるなら、比較予想の予想確信度は基準予想の予想確信度から変更してよい。

比較買い目の評価では、基準買い目とE-11 / E-12 比較買い目を**同一時点の市場オッズ**で評価し、それぞれの購入確信度を保存する。異なる時刻のオッズを使って購入確信度優劣を比較しない。

HF1以降、E-11 / E-12の購入確信度がProduction基準買い目を上回っても、その事実だけで正式推奨を差し替えない。優劣は結果後の検証に使用する。

## 30.8 回顧時の確信度検証

回顧では最低限、

- 朝 / 初期予想確信度
- 基準予想の予想確信度
- 最終時点の予想確信度
- 予想確信度変更理由コード
- 予想確信度変更方向と段階数
- 購入確信度
- 購入優先度
- 結果

を保存する。

特に、

- 朝予想確信度を下げたことで改善したか / 悪化したか
- 予想確信度据え置きが硬直化になっていないか
- 価格変動だけで予想確信度を誤って動かしていないか
- 購入確信度が高いレースほど実際の回収率・本線利益が高いか

をサイクル終了時に集計する。

# 32. ◎と単勝期待値を分離する

◎は総合評価最上位。

単勝を買うかどうかは、

**推定勝率 × オッズ**

を別途検討する。

○▲でも市場との乖離が大きければ単勝候補になり得る。

さらに最終予想では、可能な限り次の2つを分けて明示する。

- **最も勝つと思う馬**：基礎能力・今回発揮能力・展開適合などを総合した、純粋な勝率評価1位
- **最も買いたい馬**：推定確率・市場オッズ・証拠強度・不確実性を合わせた、馬券価値1位

両者が同じ馬になる必要はない。

例えば、◎が低オッズで市場に十分評価されている一方、○▲☆の馬が今回条件に合い、市場がその好走可能性を十分織り込んでいない場合は、**◎をレース予想上の最上位に残したまま、別馬を馬券戦略上の中心とする**ことを認める。

「最も買いたい馬」は単に高オッズの馬ではなく、**自分の推定確率に対して市場価格が有利で、その評価を支える独立した根拠が複数ある馬**とする。

※ 実戦検証中。

## 32.1 印と確率順位の整合性を監査する

レース予想上の印と、数値化した勝率・連対率・3着内率を別々に作った結果、両者が矛盾していないかを最終確認する。

原則として、**◎○▲などの上位印はレース予想上の順位を表し、市場オッズや馬券妙味だけを理由に並び替えない。**

特に勝率を主要な順位基準としているレースでは、

> A馬の推定勝率20%  
> B馬の推定勝率17%

と評価しているのに、価格だけを理由にB馬を○、A馬を▲へ下げるような処理は行わない。

B馬の方を「最も買いたい馬」とすることは認めるが、**レース予想順位と馬券価値順位は別表示**にする。

最終出力前に少なくとも、

- 印の順位
- 推定勝率順位
- 連対率・3着内率順位
- 「最も勝つと思う馬」
- 「最も買いたい馬」

を照合する。

印と確率順位が異なる場合は、

- 勝率ではなく総合安定度を印の基準にしている
- 操縦性・状態など、中心確率だけでは表現しきれない合理的理由がある

など、**オッズ以外の明確な理由を記録する。**

理由を説明できない不一致は、価格判断がレース予想へ逆流した可能性が高いとして修正する。

※ 実戦検証中。

# 34. 最終オッズの時刻・出典・整合性を検証する

可能なら、

- 自分が予想した時点のオッズ
- オッズ取得時刻
- オッズ取得元
- 実際の購入時オッズ
- 最終オッズ

を記録する。

自分の高評価馬がその後市場でも買われたのかを検証すると同時に、**参照したオッズそのものが正しい時刻・正しいレースの値か**を確認する。

直前に大きなオッズ変動が見えた場合や、複数ソースの値が一致しない場合は、可能な限りJRA等の主催者情報を優先して再確認する。

**時点情報は「最新値」だけでなくタイムスタンプも確認する。** 馬場状態・天候・馬体重・取消・騎手変更・オッズについて、JRA等の公式一次情報に更新時刻がある場合は、その最新時点を基準とする。外部サイトがより新しく見えても、更新時刻・対象レース・馬場区分が一致していることを確認できない限り、公式値を上書きしない。

異なる時刻の「良／稍重」「晴／雨」等を混在させた場合は、回顧でK：外部データ取得・時刻整合ミスとして扱い、予想ロジックの失敗と分離する。

確認できない大幅変動だけを理由に、買い目・資金配分・期待値判断を大きく変更しない。

また、市場オッズの変化だけでは原則として基礎能力・適性・印を変更せず、**馬券価値と資金配分を変更する材料**として扱う。新しい状態情報・馬場情報・出走条件の変化が伴う場合のみ、レース予想本体の変更を検討する。

## 35.1 券種・組み合わせごとの買い目期待値を独立評価する

**正式ルール。**

予想確定後、買い目候補は券種・組み合わせごとに独立して、

- 推定成立確率
- 不確実性レンジ
- 取得オッズまたは予測最終オッズ
- 同一馬・同一シナリオとの相関

を比較する。

特に、

> A-B馬連が低い期待値だから、A-B-C三連複も低い期待値

のような横滑りを禁止する。馬連・ワイド・馬単・三連複・三連単は**別の確率事象・別の市場価格**として扱う。

三連系では、可能な範囲で1着・2着・3着条件付き確率、または同時好走確率を用いて比較する。厳密な数値化が難しい場合も、少なくとも「どの着順／好走条件に依存する買い目か」を明示してから価格評価する。

これは買い目を増やすルールではない。**候補生成後に低い期待値を削る順序を守るためのルール**である。

良い予想ができても、オッズに価値がなければ買わない。

また、レース自体の不確実性が高い場合も、

**予想はするが馬券は見送り**

を認める。

# 37. 事前予想と最終予想を記録し、評価変動量を検証する

可能な場合、

**事前評価**
→ **枠確定後**
→ **当日馬場確認後**
→ **オッズ確認後**
→ **最終評価**

の変化を記録する。

特に、

**何を理由に、どの程度評価を変更したのか**

を残す。

変更理由は、**予想側**と**購入側**を分離して分類する。

予想側（印・確率・予想確信度を動かし得る）：

- 能力
- 適性
- 状態・成長
- 馬場
- 展開
- 情報訂正

購入側（購入確信度・購入優先度・買い目・資金配分だけを動かす）：

- 市場価格
- E-08予測最終価格
- 買い目期待値
- 券種別価格差

**市場価格だけを予想側の変更理由として記録しない。**

確率評価を行っている場合は、厳密な数学でなくてもよいので、例えば、

> 事前勝率24% → 当日馬場 +3pt → 状態 -1pt → 展開見直し +2pt → 最終28%

のように、**主要な補正要因と評価変動量**を記録する。

これにより、

- 当日馬場補正が本当に精度を上げているか
- 状態情報を過大評価していないか
- 直前情報で予想を動かしすぎていないか

を長期的に検証する。

**市場価格だけが変わった場合は、原則として印・能力評価ではなく馬券戦略だけを変更する。**

加えて、直前情報で◎○などの上位順位を反転させる場合は、**変更理由の「証拠強度」**を確認する。

証拠強度の目安：

- **強**：公式馬場状態の明確な変化、取消・騎手変更、馬体・状態の重大情報、複数の同条件レースで一貫した傾向
- **中**：複数の関連レースや独立した情報が同じ方向を示す
- **弱**：同コース1レースのみ、単一コメント、単一オッズ変動、少数サンプルの印象

**弱い直前情報だけで、事前に複数材料から作った基礎能力順位を大きく反転させない。**

弱い情報はまず、

- 展開シナリオ発生確率
- 不確実性レンジ
- 馬券資金配分

を小幅に補正する材料として扱う。

◎の変更や勝率の大幅変更は、原則として複数の独立材料が一致するか、馬固有の強い新情報が得られた場合に行う。

### 37.1 最終順位保全 / 最終順位保全

**正式基本監査。**

朝・事前基本予想で上位に置いた馬を最終予想で大きく降格・消去する場合は、次のいずれかを要求する。

- 強い一次情報の変化
- 複数の独立した中強度材料が同じ方向を示す
- 当初評価に明確な事実誤認・データ不整合が見つかった

単一オッズ変動、少数レースの馬場印象、追加で考え直しただけの主観、配当を高くしたいという理由では、大幅降格を行わない。

最終順位を変更する場合は、可能な範囲で、

> 事前順位 → 最終順位 / 変更理由 / 証拠強度

を保存する。

順位を変更しないこと自体を目的にはしない。目的は、**新情報の証拠強度より大きな順位変更を防ぐこと**である。

---


### 37.2 確信度保全 / 確信度保全

**正式基本監査。** 30.5節の変更統制を、事前→最終の運用ガードとして必ず実行する。

- 事前予想確信度と最終時点の予想確信度を両方保存する
- 予想確信度変更時は理由コード、証拠強度、情報時刻を記録する
- **オッズ変動だけなら予想確信度は固定し、購入確信度 / 購入優先度だけを更新する**
- 2段階以上の予想確信度変更は、強い新情報または複数独立根拠がない限り行わない
- 詳細精査による大幅変更は予想確信度理由07：詳細分析による事前評価の訂正として記録し、事前全体選別の過信も検証する

最終順位保全（37.1）と確信度保全（37.2）は別監査である。

- 順位は同じでも予想確信度だけ下がることがある
- 予想確信度は同じでも馬同士の順位が変わることがある

両方を独立記録し、どちらか一方の記録で代用しない。

# 40. レース後のエラー分類

- A：基礎能力評価ミス
- B：展開・ペース予測ミス
- C：馬場判断ミス
- D：状態評価ミス
- E：成長・上昇度評価ミス
- F：位置取り・騎乗想定ミス
- G：適性評価ミス
- H：情報の解釈ミス

# 42. 予想・価格判断・馬券結果を別々に採点する

## 予想面

- 能力評価
- レース質
- ペース
- 馬場
- 成長
- 操縦性・精神面の実戦再現性
- 穴馬評価
- 人気馬評価

## 価格判断面

- 推定確率
- フェアオッズ
- 買い条件
- 実際の購入時オッズ
- 最終オッズ
- オッズ取得時刻・出典の正確性

## 馬券面

- 券種
- 資金配分
- 買い目数
- 高い期待値馬の取り扱い
- **「最も買いたい馬」への資金配分が予想上の妙味と整合していたか**
- **穴軸・妙味軸へ昇格させるべき馬を相手扱いだけに留めていなかったか**
- **妙味馬を軸にした場合、直接券種と連系券種の比率が適切だったか**
- 本線シナリオへの資金集中度
- 払戻・収支

を分けて検証する。

# 45. 本線シナリオと馬券の重なりを意識する

予想確信度が比較的高く、上位評価馬と主要展開シナリオが明確な場合は、限られた予算を多数の低い期待値買い目へ薄く分散するより、

**最も確率が高いシナリオを表現する少数の馬券へ集中する**

ことを検討する。

例：

- 高い期待値の本命馬の単勝
- 本命と高3着内率馬のワイド
- 本命と対抗の馬連

など。

ただし、単勝＋馬連など同じシナリオに依存する馬券は同時に外れる相関も高い。

そのため、

- 予想確信度
- シナリオ発生確率
- 各券種の期待値
- 外れた場合の損失集中

を確認して資金配分する。

「当てるための保険」として期待値の低い買い目を無制限に増やさない。

また、**期待値の高さと資金集中の妥当性を分ける。**

推定確率の中心値から正の期待値が見込めても、

- 昇級・初条件などで能力比較の不確実性が高い
- 確率レンジが広い
- 直前補正で評価を上げたばかり
- 予想確信度がB以下

といった場合は、その馬を最大の資金軸にする根拠が十分とは限らない。

資金配分では、

**中心期待値**と**購入確信度**を別に評価し、必要に応じて確率レンジの下側や保守的な推定値でも期待値が維持されるか確認する。

「妙味が最も大きい馬」＝「全券種の万能軸」とはしない。高い期待値馬でも不確実性が高い場合は、単独の価値買いとして扱うことと、他券種の軸として大量に依存することを分離する。

**購入確信度は30.3節の正式指標を使用し、旧「資金投入への確信度」と別の新指標を追加しない。**

## 45.1 妙味馬を馬券軸へ昇格させる条件

市場より明確に高く評価する人気薄・中人気馬を見つけた場合、相手として少額添えるだけでなく、**馬券戦略上の軸へ昇格**させることを検討する。

ただし「穴だから軸」ではなく、**市場との価格差が大きく、その価格差を説明できる根拠が複数あるから軸**という順序を守る。

穴軸・妙味軸候補は、原則として次を確認する。

1. **価格乖離**：推定勝率・連対率・3着内率に対して単勝・複勝・連系オッズが明確に高い
2. **本線シナリオ適合**：最も発生確率が高い展開で好走しやすい
3. **独立した好材料が複数ある**：能力・近走内容・馬場・枠・斤量・距離・コース・状態・成長など、同じ根拠の言い換えではない材料が複数ある
4. **人気薄の理由を説明できる**：なぜ市場で売れていないかを確認し、その理由が今回も有効な弱点なのかを検証できる
5. **単一の極端な展開だけに依存しない**：複数シナリオで一定の好走余地がある、または単一シナリオ依存ならその分だけ資金を抑える
6. **人気馬側に価格・条件上の脆さがある**：上位人気馬が市場評価どおり走らない余地がある
7. **購入確信度が十分**：確率レンジ下側でも期待値が極端に崩れず、予想確信度との比較で過度な集中にならない

目安として、**価格乖離を前提に、少なくとも3系統以上の独立した根拠が一致する場合**に穴軸・妙味軸への昇格を積極的に検討する。

### 穴軸・妙味軸時の買い方

妙味の根拠を最も直接的に表現できる券種を優先する。

- 勝率の過小評価が大きい → **単勝**を中心候補
- 3着内率の過小評価が大きい → **複勝・ワイド**を中心候補
- 妙味馬と信頼できる上位馬の同時好走確率が高い → **ワイド・馬連**
- 高配当シナリオが明確 → **三連複等を少額で追加**

妙味馬を軸にする場合ほど、買い目を無制限に広げない。基本は、

**妙味馬を直接買う券種 ＋ 信頼できる相手との少数連系 ＋ 必要なら少額高配当**

の順で組み立てる。

穴軸に昇格したからといって全券種をその馬から流すことはせず、既存の馬依存率・シナリオ依存率と必ず照合する。

### 45.2 妙味馬は必須軸ではない / 妙味馬は万能軸ではない

**正式基本監査。**

「最も買いたい馬」は、価格差が最も大きい馬を意味し、**全券種の共通軸を意味しない。**

妙味馬については、

1. 価値を直接表現する券種（単勝・複勝・ワイド等）
2. 基本予想上位馬との連系
3. 妙味馬を含まない高確率基本予想シナリオ

を分離して比較する。

妙味馬を外しただけで、上位評価馬同士の自然な本線組み合わせが全て消える構造になっている場合は、購入前に必ず再監査する。

価格乖離が大きくても、3着内率の不確実性が高い馬・初条件馬・昇級馬などを全券種の万能軸へ自動昇格させない。

# 47. 展開の「恩恵」と「支配力」を分ける

逃げ・先行馬については、単に「前残り展開なら有利」と評価するだけでなく、

**その馬自身が望む隊列・ペースを作れる可能性**

を別に検討する。

特に、

- 少頭数
- 強くハナを主張する同型が少ない
- 近走で安定して先行できている
- 枠とコース形態が主導権確保に向く
- 騎手の先行意識が高い

場合は、展開シナリオの発生確率そのものを動かす要因になり得る。

ただし「先行力」「位置取り能力」「展開利」と同じ根拠を二重計上しない。

展開支配力は原則として**基礎能力への直接加点ではなく、各シナリオの発生確率を補正する要素**として扱う。

※ 実戦検証中。

## 47.1 「希望位置」と「実際に取れる位置」の確率を分ける

逃げ・先行・好位などの位置取りは固定値として扱わず、

1. **陣営・馬が望む位置**
2. **実際にその位置を取れる確率**
3. **取れなかった場合の代替シナリオ**

を分けて考える。

特に、前走で逃げた・先行したという1レースだけの事実から、

> 今回も逃げる  
> 今回も同じ位置を取れる

と決め打ちしない。

位置取りの再現性は、

- 直近複数走の発馬・二の脚
- 同型馬との比較
- 枠
- 距離変更
- 騎手
- 前走が偶発的な単騎逃げだった可能性
- 控えても能力を発揮できるか

から評価する。

レースの中心馬が「逃げられること」「好位を取れること」に勝率を大きく依存している場合は、

- 希望位置を取れるシナリオ
- 1列後ろになるシナリオ
- 競られて位置を失うシナリオ

を可能な範囲で分け、その発生確率を最終勝率へ反映する。

これは位置取り能力そのものへの二重加点ではなく、**展開シナリオの実現確率を補正するための確認**とする。

※ 実戦検証中。

# 48. 回顧では「買い目の出所」と相関リスクを分ける

回顧時は、実際に購入した各買い目について、

- 予想時に提示した推奨買い目
- ユーザー自身が追加・変更した買い目
- その他の裁量買い

を区別して記録する。

これにより、**予想ロジック・提示した馬券戦略・ユーザー独自判断を混同して採点しない。**

また、複数の買い目が同じ馬・同じ展開仮説に強く依存する場合は、券種が違っていても別々のリスクとはみなさない。

例：

- A-Bワイド
- A-B-C三連複

の両方が「Bが3着以内」という条件へ強く依存するなら、Bが崩れたとき同時に外れる相関が高い。

そのため、追加買いを行う際は、

- その買い目がどの馬・どのシナリオに依存しているか
- 既存買い目と失敗条件が重複していないか
- 同一仮説への合計投資額が過大になっていないか

を確認する。

**券種を増やすこととリスク分散は同義ではない。**

相関した買い目への総投資上限については、予想確信度・対象馬の3着内率・オッズを用いて今後実戦検証する。

実運用では、購入前に少なくとも次の2つを可視化する。

### 馬依存率

> その馬が想定外の凡走をした場合に同時に失敗する投資額 ÷ レース総投資額

### シナリオ依存率

> 特定の展開シナリオが外れた場合に同時に失敗する投資額 ÷ レース総投資額

券種が異なっても、同じ馬・同じ展開に依存していれば合算する。

特に予想確信度がB以下の場合、直前に評価を上げた1頭や単一シナリオへ総投資の大半が集中していないかを必ず確認する。

依存率が高い場合は、

- その馬・シナリオへの投資額を減らす
- レース総投資額自体を下げる
- 独立した高い期待値シナリオが存在する場合のみ別買い目を検討する

とし、単なる「保険」のために期待値の低い買い目を追加しない。

特に、**推奨買い目の100%が1頭の好走へ依存する場合は、例外運用として明示的な再確認を必須**とする。

100%依存を許容するのは、少なくとも、

- 予想確信度が十分高い
- 対象馬の3着内率または該当券種に必要な確率が高い
- 確率レンジ下側でも依存を正当化できる
- 能力・状態・展開・位置取りの証拠強度が高い
- その馬が崩れる独立シナリオの発生確率が十分低い

と判断できる場合に限る。

条件を満たさない場合、無理に別馬の低い期待値買い目を「保険」として追加するのではなく、**総投資額を下げる、または独立して期待値のある別シナリオだけを採用する。**

具体的な依存率上限は実戦データを蓄積して設定する。

さらに、馬依存率は単独で見るのではなく、対象馬の、

- 3着内率
- 確率レンジの幅
- 能力不確実性
- 予想確信度
- その馬を軸にする根拠の証拠強度

と照合する。

特に、**確率レンジが広い馬・昇級馬・初条件馬に対する依存率が、実績の安定した上位評価馬より大きくなっていないか**を確認する。

また、買い目作成前に、上位評価馬と本線シナリオから自然に生じる候補組み合わせを一度列挙し、

- 「妙味馬を万能軸にしたため」だけで有力な本線組み合わせが消えていないか
- 印・3着内率・本線シナリオと買い目構造が整合しているか
- ある1頭を外しただけで、本線シナリオの主要な組み合わせをほぼ全て失っていないか

を監査する。

これは的中のために買い目を無制限に広げるルールではない。候補を一度比較したうえで、オッズと推定確率から期待値が不足する組み合わせは従来どおり買わない。目的は、**「価値軸」というラベルによる構造的な買い目偏りを防ぐこと**である。

## 48.1 自然な組み合わせ監査 / 自然な組み合わせ監査

**正式基本監査。購入前に必須。**

最終印・勝率・連対率・3着内率・主要シナリオを固定した後、価格で削る前に次を一度候補化する。

1. **◎○の馬連・ワイド**
2. 三連系を購入対象とする場合の**◎○2頭軸 → ▲△☆**
3. ◎○以外でも、印内の3着内率・本線シナリオから自然に成立する馬連・ワイド・三連系
4. 主要軸が崩れた場合でも独立して期待値がある代替シナリオ

ここでの「候補化」は**購入義務ではない**。候補を生成した後、35.1 買い目期待値とE-08等の価格評価を使って低い期待値を削る。

三連系で1頭または2頭を固定した場合は、

- 固定しなければ自然に成立する上位印同士の組み合わせ
- その固定馬が飛んだ場合の本線シナリオ

が構造的に消えていないかを確認する。

## 48.2 万能軸監査 / 万能軸監査

**正式基本監査。購入前に必須。**

買い目作成後、各馬について馬依存率を確認し、特定1頭への依存が極端に高い場合は、

- その馬の3着内率または券種成立に必要な確率
- 確率レンジ下側
- 予想確信度
- その馬が崩れる独立シナリオ
- 妙味馬なのか能力基本予想なのか

を再確認する。

**「最も買いたい馬」だから高依存を許容する、という判断は禁止する。**

100%依存は既存条件を満たす場合のみ許容する。条件不足なら、低い期待値の保険を増やすのではなく、依存額またはレース総投資額を下げる。

## 48.3 回顧での買い目構築エラー分類

印内に実際の好走馬が十分含まれていたにもかかわらず、自然な組み合わせを候補化しなかった場合は、**候補抽出ミスではなく買い目構築ミス**として分離する。

代表例として、

- 上位候補に1〜3着が揃っていたが特定◎固定で三連系を欠落
- 妙味馬を万能軸化し、別の基本予想好走馬同士を買い目から消した

等を記録する。

# 49. 予想対象レースの選出を2系統に分ける

個別レースを精査する前に、開催全体から**「予想・購入する価値が高いレース」**を選別する。

レース選出は、次の2系統を基本とする。

## 49-1. ① 的中確率 × オッズ妙味型（主戦略）

従来どおり、

**的中可能性が比較的高く、自分の評価と市場オッズの間に十分な妙味があるレース**

を優先する。

主な確認項目：

- 上位馬の能力比較がしやすい
- レース質・展開の不確実性が比較的小さい
- 高評価馬の勝率・連対率・3着内率を比較的安定して推定できる
- 自分の推定確率と市場オッズに有利な乖離がある
- 人気馬の過剰人気を利用できる場合がある
- 馬券を広げすぎず、本線シナリオを少数買い目で表現できる

①は**本線の資金を投入する主戦略**とし、的中率だけでも高配当だけでもなく、

**予想精度 × 価格**

のバランスを重視する。

---

## 49-2. ② 少額・人気薄台頭型（高配当副戦略）

②は、①とは資金目的を分け、

**少額で人気薄を拾い、馬連・三連複を中心に高配当を狙う副戦略**

として扱う。

目的は単に「荒れそうなレース」を探すことではない。

対象とするのは、

**市場が人気薄の好走可能性を十分に織り込んでおらず、その人気薄が馬券内へ台頭する合理的なシナリオを事前に説明できるレース**

とする。

人気薄の台頭根拠は、特に以下を重視する。

- 相手レベル・近走で戦ってきた相手の質
- 今回の相手弱化
- 天候変化
- 馬場状態・道悪適性
- 当日の馬場バイアス
- 前走不利・位置取り・進路・距離ロス
- 今回の条件好転
- レース質・展開適合
- 距離・コース変更
- 枠
- 成長・上昇度
- 騎手による位置取り変化
- 市場で人気になっていない理由

人気薄については、

**「なぜ人気がないのか」**
と
**「その人気薄になる原因が今回も継続するのか」**

を必ず確認する。

前走大敗などが人気薄の主因であっても、その敗因が今回解消されるなら市場の過小評価候補になり得る。逆に単純な能力不足が人気薄の理由なら、穴であること自体を買い材料にはしない。

---

## 49-3. ②では人気馬側の脆さも確認する

人気薄だけを探して終わらせない。

馬連・三連複で大きな配当を得るには、人気馬の一部が市場期待どおり走らないことが重要になるため、

- 馬場不適合
- レース質不適合
- 展開依存
- 枠・位置取りリスク
- 前走の展開恩恵
- 距離不安
- 相手強化
- 状態不安
- 過剰人気

などから、**人気馬の危険度**も評価する。

②の理想は、

**人気薄を無理に買うレースではなく、市場の人気序列が崩れる理由と、その代わりに台頭する馬を具体的に説明できるレース**

とする。

---

## 49-4. 「荒れる」と「予測可能な荒れ」を区別する

能力比較不能、初条件馬多数、隊列不明など、

**不確実性が高いだけのレース**

は②の優先対象にしない。

狙うのは、

**荒れる可能性がある**
＋
**その恩恵を受ける人気薄を事前に特定できる**

レースとする。

レース全体の不確実性が高すぎて台頭馬を特定できない場合は、配当が高くても見送る。

---

## 49-5. ②の基本的な馬券構造

②では主に次の3形を検討する。

### A. 信頼できる軸 ＋ 人気薄

上位評価馬に比較的高い信頼を置け、相手に市場より高く評価する人気薄がいる形。

例：

- 本命－人気薄の馬連
- 本命－対抗・単穴－人気薄の三連複

②の中では比較的狙いやすい構造とする。

### B. 人気馬崩壊 ＋ 中人気・人気薄

上位人気馬に明確な割引・消し条件があり、市場人気より中人気・人気薄を上位に評価できる形。

配当余地は大きいが予測難度も高いため、A型よりさらに少額で扱う。

### C. 過小評価された人気薄を軸へ昇格

人気薄候補の中でも、ルール45.1の条件を満たし、**「最も買いたい馬」**と判断できる場合は、単なる相手穴ではなく馬券軸候補へ昇格させる。

この場合、レース予想上の◎を変更する必要はない。

例：

- ◎は最も勝つ可能性が高い人気馬
- ☆または▲が市場に過小評価された妙味馬
- 馬券は妙味馬の単勝・複勝・ワイド等を中心に構成

という形を認める。

妙味馬への確信度が十分高い場合は、②の「少額穴狙い」に限定せず、**①＋②の本線資金の一部を妙味馬へ振り向ける**ことを検討する。

ただし、価格差だけで昇格させず、能力・条件・展開・市場評価の複数根拠を要求する。

※ 実戦検証中。

---

## 49-6. 万馬券は「結果として狙う価格帯」とする

②では馬連・三連複で**100倍以上（万馬券）**を狙える組み合わせを積極的に検討する。

ただし、

**100倍以上になる組み合わせを先に探し、後から穴馬の理由を作ることは禁止する。**

順序は、

**人気薄を能力・条件から評価**
↓
**人気馬の脆さを評価**
↓
**馬券内シナリオを構築**
↓
**組み合わせを作る**
↓
**オッズを確認**
↓
**結果として高配当なら少額で狙う**

とする。

三連複95倍など、万馬券未満でも推定確率に対して十分な妙味があれば候補から機械的に外さない。

---

## 49-7. ①と②の資金を分離する

②は的中頻度が①より低くなることを前提とする。

そのため、

- ①：本線・主戦略
- ②：少額固定の高配当副戦略

として資金目的を分ける。

ただし49-5 Cの穴軸・妙味軸昇格条件を満たし、②の候補へ本線資金を振り向ける場合は、**②のまま資金上限だけを緩めるのではなく「①＋②」へ再分類**してから資金配分する。

②の連敗を理由に①の資金配分を崩さない。

また、②で買い目数を増やして的中率を無理に上げようとしない。

既存ルールどおり、券種が異なっても同じ人気薄・同じ展開仮説へ依存する買い目は相関リスクとして合算し、**少額高配当枠の総投資を管理する。**

※ 具体的な①・②の資金比率や1レース当たり上限は実戦で検証する。

---

## 49-8. レース選出区分

開催全体から候補レースを比較するときは、原則として次の4区分で整理する。

- **① 期待値型**：的中確率とオッズ妙味のバランスが高い
- **② 少額高配当型**：人気薄の台頭根拠があり、馬連・三連複で高配当を狙える
- **①＋②**：信頼できる本線と、過小評価された人気薄が同時に存在する
- **見送り**：予想精度・価格・穴台頭根拠のいずれも不足

特に①＋②は、

**本線では高評価馬を利用しつつ、少額で人気薄との高配当も狙える**

ため、優先候補になり得る。

ただし①＋②であっても、各戦略の資金目的と買い目は分離して管理する。

---

## 49-9. レース選出時の基本出力

複数レースから予想対象を選出する依頼では、可能な限り、

- レース
- 選出区分（① / ② / ①＋② / 見送り）
- 予想確信度
- 購入優先度（S / A / B / C / D）
- 購入確信度（最終予想固定時点前で未確定なら未判定または暫定と明記）
- ①の場合：高評価馬とオッズ妙味
- ②の場合：人気薄候補と台頭根拠
- 人気馬の危険度
- 想定する馬券構造
- 推奨度（可能なら購入優先度へ統一し、二重評価しない）

を比較して提示する。

②の人気薄候補については、単に馬名を挙げるだけでなく、

1. **人気薄になっている理由**
2. **市場評価が過小である可能性**
3. **今回の台頭条件**
4. **有利になる展開シナリオ**
5. **どの人気馬が崩れると配当が上がるか**
6. **馬連・三連複での組み立て方**

まで可能な範囲で明示する。

※ ②のレース選出精度、人気薄候補の好走率、高配当到達率、少額枠の収支は実戦検証する。

## 49-10. 「穴軸昇格」を結果論ではなく事前判定する

穴馬が好走した後に「もっと厚く買えばよかった」と評価するだけでは改善にならない。

穴軸・妙味軸戦略は必ず**発走前に昇格判定**を行い、次を記録する。

- 最も勝つと思う馬
- 最も買いたい馬
- 穴軸・妙味軸候補の有無
- 昇格した / しなかった理由
- 推定勝率・3着内率と市場価格
- 独立した根拠の数と種類
- 購入確信度
- 妙味馬への総投資額・馬依存率

回顧では、

- 穴軸昇格馬の好走率
- 単勝・複勝・ワイド・馬連等の券種別収支
- 相手扱いに留めた妙味馬が好走したケース
- 穴軸へ昇格したが根拠不足だったケース
- 妙味を適切に収益へ変換できたか

を蓄積し、昇格条件を確率精度の検証する。

**結果として穴馬が勝ったこと自体を、穴軸昇格の正しさの証拠とはしない。**

※ 実戦検証中。

## 49-11. ①＋②では「コア」と「オーバーレイ」を分ける

同一レースで①の本線と②の高配当候補を同時に狙う場合、買い目を一括で作らず、

- **コア**：最も発生確率が高いレースシナリオ・上位評価馬を表現する買い目
- **オーバーレイ**：市場に過小評価された人気薄が台頭する高配当シナリオを表現する買い目

に分ける。

まずコア候補を、印・勝率・連対率・3着内率・本線シナリオから自然に列挙し、その後にオーバーレイを追加する。

これにより、

> 穴馬を見つけたため、本来高確率だった上位馬同士の組み合わせを検討しなくなる

という構造的な偏りを防ぐ。

原則として、②の穴馬がルール45.1の**穴軸・妙味軸昇格条件を満たしていない場合、オーバーレイへの資金がコアを無意識に上回らないよう確認する。**

穴馬への直接期待値が高くても、

- 単勝・複勝などでその価値を直接買う
- コアの連系買い目
- 穴馬を含む高配当オーバーレイ

を分け、1頭の穴馬を全券種の共通軸にしない。

購入前に、

- コア投資額
- オーバーレイ投資額
- 各馬への依存率
- コアを削ってまでオーバーレイを増やした理由

を確認する。

※ 実戦検証中。

---

## 49-12. ①＋②では主従を必ず明示する

**正式購入運用ルール。**

①＋②と分類したレースは、購入前に必ず次のいずれかへ再分類する。

- **①主＋②従**：基本予想シナリオを主資金、オーバーレイを補助資金
- **②主＋①従**：妙味馬の価格差を主資金、基本予想を安定化・連系に利用
- **①≒②**：双方が独立に十分な期待値を持ち、どちらかを従に落とす合理性が乏しい

「①＋②だから半々」「両方気になるから均等」の配分は禁止する。

②主へ寄せる場合は、ルール45.1の妙味軸昇格条件と45.2 妙味馬は必須軸ではないを同時に満たすことを確認する。

①≒②は例外扱いとし、双方が独立に高い期待値である説明を要求する。主従を決められないこと自体が不確実性のシグナルなら、**総投資額を下げるか見送る。**

具体的な資金比率は固定せず、次サイクルで継続検証する。

# 50. WIN5予想・買い目構築ルール

WIN5は通常の単勝・馬連・三連複等とは目的関数が異なるため、通常馬券の予想をそのまま横流しせず、**5レースの勝ち馬を同時にカバーするための専用戦略**として扱う。

通常の競馬予想ルールは各対象レースの能力・展開・勝率推定にそのまま利用するが、候補馬の選択数と点数配分はWIN5専用に最適化する。

以下は初回実戦を基にした**実戦検証中の仮ルール**とする。

## 50-1. WIN5では「勝率」を中心に選び、通常馬券の妙味順位を直接流用しない

WIN5で必要なのは各対象レースの**1着馬**である。

そのため、通常馬券で、

- 単勝期待値が高い
- 複勝・ワイド向き
- 人気薄として妙味がある

ことと、WIN5で選択すべきことは同義ではない。

まず各対象レースについて、通常ルールで推定した**勝率順位**を作る。

その後に、

- 市場人気
- 組み合わせの希少性
- 高配当到達余地

を補助的に見る。

単勝オッズは市場の人気度を知る材料にはなるが、WIN5の払戻は5レースの的中票数によって決まるため、**単勝期待値をそのままWIN5期待値へ置き換えない。**

また通常馬券で「危険な人気馬」「単勝では割高」と評価した馬でも、勝率順位が上位ならWIN5候補から機械的に外さない。

---

## 50-2. 各レースの「カバー勝率」を計算し、5レース全体で考える

各対象レースで選択した馬の勝率合計を、概念的に**カバー勝率**とする。

> レースごとのカバー勝率 ≒ 選択した各馬の推定勝率の合計

例：

- A馬 30%
- B馬 20%
- C馬 12%

を選ぶなら、そのレースのカバー勝率は概念的に約62%。

5レース全体の的中確率は、厳密な独立性を仮定する必要はないが、目安として、

> **WIN5全体カバー確率 ≒ C1 × C2 × C3 × C4 × C5**

で考える。

一方、購入点数は、

> **点数 ＝ 各レースの選択頭数の積**

となる。

したがって、単に不安なレースを広げるのではなく、

**追加1頭によって増えるカバー勝率と、全体点数の増加を比較する。**

各レースについて、

- 1頭選択時のカバー勝率
- 2頭選択時
- 3頭選択時
- 必要なら4頭以上

を並べ、**限られた点数をどのレースへ使うと全体カバー確率が最も改善するか**を比較する。

※ 実戦検証中。

## 50-3. 1頭固定は「1番強い馬」だけでは決めない

WIN5の1頭固定は点数を大幅に圧縮できる一方、その馬が負けた時点で全票が失敗する。

したがって、

**勝率1位だから固定**
**1番人気だから固定**
**GⅠ馬だから固定**

とはしない。

固定候補では、

- 推定勝率の中心値
- 勝率レンジ下側
- 2番手以下との勝率差
- 複数シナリオでの優位性
- 位置取り・状態・馬場への依存度
- 操縦性・精神面の不確実性
- 相手側の逆転シナリオ数

を確認する。

さらに、

> **固定失敗確率 ＝ 1 − その馬の推定勝率**

を必ず意識する。

固定馬の勝率が他馬より高くても、負ける確率の方が大きい水準なら、点数節約だけを理由に固定しない。

固定条件を満たす馬がいない場合は、

- 2頭以上にする
- 他レースを絞る
- 全体点数を引き上げないならWIN5自体を見送る

の順で検討する。

具体的な固定勝率の数値基準は、実戦データを蓄積して設定する。

※ 実戦検証中。

## 50-4. 「混戦だから広げる」と「広げても拾えない混沌」を分ける

勝率分布が平坦なレースでは複数頭選択が合理的になり得る。

ただし、

**不確実性が高いほど何頭でも追加する**

という運用は禁止する。

上位3〜4頭を選んでもカバー勝率が十分に上がらず、さらに多数の馬へ勝率が分散している場合、そのレースは、

> **広げれば解決する混戦ではなく、限られた予算ではカバー効率が低い混沌**

である可能性がある。

このようなレースを含む日は、

- そのレースだけ大量に買う
- 人気薄を配当目的だけで追加する

より、**WIN5全体を見送る選択肢**を正式に持つ。

WIN5でも通常馬券と同様、

**予想できることと、買う価値があることを分離する。**

※ 実戦検証中。

## 50-5. 点数制約で切る馬と、能力評価で切る馬を分ける

WIN5では点数上限によって、有力馬を意図的に候補外へする場合がある。

その際は必ず、

- **評価外**：勝率自体が低く、通常の予想順位でも候補外
- **点数制約切り**：勝率は候補圏だが、全体点数との比較で除外
- **人気・配当を考慮した戦略的切り**：勝率はあるが、他レースへの点数配分を優先

を区別する。

特に、選択馬とほぼ同程度の勝率を与えている馬を、

> 人気だから切る  
> 何となく攻めたいから切る

という理由だけで除外しない。

点数制約切りでは、

- その馬の推定勝率
- 追加した場合の対象レースのカバー勝率上昇
- 全体点数の増加
- 代わりにどのレースの何頭を削るか

を比較する。

回顧でも、

**予想順位を外したのか、点数最適化で外したのか**

を分けて採点する。

※ 実戦検証中。

## 50-6. WIN5の参加可否を5レース全体で判定する

購入前に、

- 各レースの予想確信度 / 購入確信度
- 各レースのカバー勝率
- 1頭固定の有無
- 点数制約切りの数
- 高不確実性レースの数
- 全体推定カバー確率
- 総点数・総投資額

を一覧化する。

特に、

- 固定馬の根拠が弱い
- 混沌レースが複数ある
- 意味のある勝率を持つ馬を点数都合で複数切る必要がある
- 点数を増やしても全体カバー確率が低い

場合は、**WIN5見送り**を正式な最終結論とする。

「WIN5が発売されているから毎回買う」ことを前提にしない。

## 50-7. WIN5回顧では全5レースを個別採点する

途中の対象レースで外れた場合でも、その時点で回顧を終了しない。

全5レースについて、

- 勝ち馬の事前勝率順位
- 勝ち馬の推定勝率
- 選択したか
- そのレースの選択頭数
- 事前カバー勝率
- 勝ち馬を外した理由
- 実際の展開シナリオ
- 1頭固定・点数制約切りの成否

を記録する。

WIN5固有の主なエラー分類は以下とする。

- **勝率順位・能力評価ミス**  
  勝ち馬を事前に低く評価しすぎた
- **点数配分・候補切りミス**  
  勝ち馬を有力候補と認識していたのに、点数制約で不適切に除外した
- **1頭固定ミス**  
  固定条件が十分でない馬へ全票を依存させた
- **高不確実性・予測困難な大波乱**  
  合理的な候補集合の外から勝ち馬が出た
- **レース間の点数配分ミス**  
  広げるべきレースを絞り、効率の低いレースへ点数を使いすぎた
- **外部情報・時刻整合ミス**  
  出走・馬場・状態などの情報不整合が選択へ影響した

複数該当する場合は主因・副因を分ける。

また、**的中/不的中だけでなく、5レース中何レースの勝ち馬を候補集合でカバーできたか**も記録する。

## 50-8. WIN5の市場人気は「的中確率」と「払戻余地」を分けて使う

WIN5では人気薄勝利を拾うと高配当へつながりやすいが、

**配当を上げるために人気薄を先に選ぶことは禁止する。**

順序は、

**各馬の勝率推定**
↓
**レースごとのカバー候補作成**
↓
**点数配分**
↓
**市場人気・想定残存票の偏りを確認**
↓
**高配当余地を評価**

とする。

通常馬券の②と同様、人気薄を選ぶ場合は、

**その馬が1着になる合理的シナリオを説明できること**

を必要条件とする。

ただしWIN5では2着・3着では意味がないため、穴馬の「馬券内率」ではなく**勝率**を中心に判断する。

※ WIN5関連の全項目は当面実戦検証中。

# 51. 重賞詳細分析（HF1：51A Production情報拡張 / 51B Shadow傾向分析）

本節は、GⅠ・GⅡ・GⅢ等の重賞でのみ使用する。通常条件戦では適用しない。HF1以降は役割を二分する。

- **51A Production情報拡張**：当該馬自身の事実を深く収集し、既存の正式ルールへ供給する。独立した重賞補正点は持たない。
- **51B Shadow傾向分析**：重賞に蓄積された過去集団データを独立モデルとして比較する。Productionを変更しない。

目的は、重賞の豊富な情報を失わずに利用しながら、**過去傾向が馬自身の直接証拠を上書きすることを防ぎ、重賞固有モデルの差分価値を前向きに測ること**である。

## 51-1. 実行順序

重賞では必ず次の順序を守る。

**通常の基本予想を作成**
↓
**51Aで当該馬の直接事実を追加収集**
↓
**51Aの事実を既存正式ルール1〜37等で解釈し、Production基準予想を完成・固定**
↓
**51B用の過去傾向・集団統計を整理**
↓
**Productionをコピーして51B Shadow予想を作成・固定**
↓
**市場確認後、Production基準買い目を固定**
↓
**必要ならE-11/E-12等のShadow比較買い目を別系統で固定**

51Aで取得した「当該馬が阪神2000mを勝っている」「前走4角3番手だった」等は既存正式ルールの直接証拠としてProductionへ利用できる。

51Bの「過去10年で3歳優勢」「前走○○組の複勝率が高い」等は集団傾向であり、Productionの順位・確率を変更しない。

過去傾向の分析を先に行って、その傾向へ合うようにProduction基本予想を作り直すことは禁止する。

## 51-2. 情報源ポリシー — 公式＋複数の独立した非公式データを横断する

重賞詳細分析では、公式情報だけに偏らず、**過去データ・血統・ローテーション・枠順・騎手・厩舎傾向等を整理している複数の独立サイトも横断して確認する。**

ただし、非公式サイトを増やす目的は「予想印を集めること」ではない。目的は、

- 公式データだけでは拾いにくい過去傾向を発見する
- 集計切り口の違いから仮説を増やす
- 単一サイト固有の偏りを検出する
- 同じ傾向が複数の独立ソースで再現しているか確認する

ことである。

### 51-2.1 情報源区分

重賞詳細分析では情報源を原則として次の情報源区分で扱う。

#### 情報源区分1：公式・一次情報

例：

- JRA等の主催者公式
- 海外の各競馬主催者・競馬場・公式成績データ
- 公式に確認できる出走、馬場、斤量、騎手、結果、取消等

用途：**事実の確定**。

出馬表、馬場状態、騎手変更、結果等で他ソースと矛盾した場合は、原則として情報源区分1を優先する。

#### 情報源区分2：競走馬・血統・競走データベース

例：

- JBIS等の血統・競走データベース
- 信頼性の高い競走成績データベース

用途：

- 5代血統表
- クロス・牝系
- 過去成績
- コース・距離・騎手・厩舎等の定量データ

#### 情報源区分3：過去傾向・重賞分析サイト、専門媒体

対象例として、

- **重賞ナビ**等の国内重賞の過去データ集計サイト
- **深く考えない競馬**等の国内・海外重賞の過去傾向整理サイト
- その他、過去結果・血統・ローテーション・枠・人気等を継続的に整理している競馬専門サイト

を含む。

用途は**データ発見・比較・仮説形成**であり、掲載されている本命・対抗・買い目をそのまま基準予想へ採用しない。

サイト名を事前に固定しすぎず、対象重賞ごとに検索し、条件に合う複数ソースを追加探索する。

### 51-2.2 単一サイト依存の禁止

過去傾向を強く反映する場合、原則として**単一の非公式サイトだけで結論を作らない。**

可能な範囲で、

- 情報源区分1または2による事実確認
- 2つ以上の独立した区分3ソース

を横断する。

ただし、同じ元データ・同じ記事・同じ集計表を転載または再加工しているだけのサイトは、独立した複数根拠として数えない。

特定サイトだけが示す傾向は「単独仮説」として扱い、基本予想順位・勝率を大きく変更する根拠にはしない。

### 51-2.3 予想印ではなく根拠を抽出する

非公式サイトから利用するのは、原則として、

- 対象期間
- 枠順別成績
- 人気別成績
- 前走別成績
- 脚質・位置取り
- 年齢・斤量
- 血統構成
- ローテーション
- コース・距離適性
- 過去好走馬の共通点

等の**根拠となるデータ・分析理由**である。

以下は原則として基準予想の直接根拠にしない。

- サイトの◎○▲
- 「本命はこの馬」という最終結論
- 買い目
- 印の多数決
- 的中実績の宣伝

複数サイトが同じ馬を本命にしていても、それ自体を独立根拠として加点しない。

### 51-2.4 外部傾向の一致度

主要な過去傾向について、必要に応じて情報源間の合意度を次のように整理する。

- **一致度A：強い合意**
  - 複数の独立した非公式ソースで一致し、情報源区分1 / 情報源区分2の元データでも概ね確認できる
- **一致度B：一定の合意**
  - 複数の独立ソースで一致するが、母数・条件差・構造変化などに注意が必要
- **一致度C：弱い / 単独仮説**
  - 1ソースのみ、またはサイト間で結論が割れている
- **不一致：不一致**
  - 複数サイトで明確に反対の傾向が示される

一致度は加点表ではなく**証拠強度の整理**として使用する。

サイト数が多いだけで一致度を上げない。独立性、母数、対象条件、構造変化を必ず確認する。

### 51-2.5 サイト間で結論が違う場合

多数決で結論を決めない。

以下を確認する。

- 集計対象年
- 開催条件が同一か
- 代替開催を含むか
- 枠ではなく馬番を集計している等、定義の違い
- 前走データの分類方法
- 人気・オッズによる能力差を補正しているか
- 血統の分類粒度
- サンプル数

条件差で説明できない不一致は「不確実性」として残し、無理に一つへ統合しない。

### 51-2.6 SNS・掲示板・匿名情報の原則除外

フェイク情報・誤認・伝聞・煽りを予想へ混入させないため、以下は原則として**重賞詳細分析の情報源に使用しない。**

- X等のSNS上の一般ユーザー投稿
- 匿名掲示板
- コメント欄
- 匿名コミュニティ
- まとめサイト
- 出典不明の転載情報
- 「関係者情報」「現地情報」等を称する確認不能な投稿

特に、

- 馬の体調
- 歩様・故障疑惑
- 陣営の勝負気配
- 騎手や厩舎の内部情報
- 出走取消・変更

などの重大情報を、匿名投稿だけで評価へ反映しない。

#### 例外：公式発信主体

SNSという媒体自体を一律禁止するのではなく、**発信主体が確認可能な公式アカウント**の場合は情報源区分1相当として利用可能とする。

例：

- 主催者
- 競馬場
- 騎手・調教師・厩舎・馬主等の確認可能な公式アカウント
- 公式メディア

ただし、公式アカウントの投稿でも内容の意味を拡大解釈せず、発言内容そのものを事実として扱う。

### 51-2.7 非公式サイトの最低品質チェック

区分3サイトを重要根拠として利用する前に、可能な範囲で以下を確認する。

- 運営・著者・媒体がある程度確認できる
- 集計対象期間が明記されている
- 元となるレース結果を追跡できる
- データと予想意見が区別されている
- 過度な煽り・転載中心ではない
- 条件変更や例外年を無視していない

品質が不明なサイトは、検索の入口としては利用できるが、単独で評価を変更する根拠にはしない。

### 51-2.8 国内重賞と海外重賞の探索方針

#### 国内重賞

JRA等の公式情報に加えて、重賞ナビのような国内重賞の過去傾向集計サイト、競馬専門媒体、血統・データサイトを複数探索する。

#### 海外重賞

国内向け公式情報だけでは不足しやすいため、

- 現地主催者・競馬場・公式データ
- 海外の競馬専門媒体・データベース
- 深く考えない競馬のような日本語で海外重賞を整理しているサイト
- その他の独立した過去傾向分析

を横断する。

海外重賞でも単一ブログ・単一専門家の見解へ依存せず、可能な限り複数ソースを比較する。

### 51-2.9 重賞出力で情報源を可視化する

重賞詳細分析の最終出力では、可能な限り**使用情報源一覧**を付ける。

最低限、

- 情報源名
- 情報源区分
- 取得した主な情報
- 対象期間
- 予想への使い方

を簡潔に整理する。

また、主要な傾向には可能な範囲で出典を併記し、

> どのサイトのどのデータから、その傾向を判断したか

を追跡できるようにする。

重要な過去傾向については必要に応じて、

| 傾向 | 公式/DB | 傾向サイトA | 傾向サイトB | その他 | 一致度 |
|---|---|---|---|---|---|

のような比較表を使用する。

情報源の数を増やすこと自体を目的にせず、**独立性・信頼性・今回条件への関連性**を優先する。

## 51-3. 過去傾向の対象期間

原則として過去5〜10年程度を確認する。

ただし、単純に「同じレース名の過去10年」を一括集計しない。次の構造変化を必ず確認する。

- 開催競馬場の変更
- 距離変更
- 芝 / ダート変更
- コース改修
- 開催時期変更
- 定量 / 別定 / ハンデ等の負担重量条件変更
- 斤量制度変更
- 出走資格・年齢条件変更
- 特殊な代替開催

条件が大きく異なる年は、

- 同条件サンプル
- 参考サンプル

に分けて扱う。

**同じレース名 ≠ 同じレース構造**を原則とする。

## 51-4. 過去傾向で確認する基本項目

可能な範囲で次を確認する。

- 人気別成績
- 単勝オッズ帯
- 枠順・馬番
- 年齢・性別
- 斤量
- 馬体重・増減
- 脚質
- 4角位置
- 上がり順位
- 勝ち時計・ラップ・ペース
- 前走レース
- 前走クラス
- 前走距離
- 前走着順・人気・着差
- 前走位置・上がり
- レース間隔
- 重賞実績
- コース実績
- 季節・開催時期

全項目を均等に加点しない。

今回の出走馬を分けるうえで有効な傾向だけを、基本予想の3大要因を補強・反証する情報として使う。

## 51-5. 5代血統表の全頭分析

重賞では可能な限り**全出走馬の5代血統表**を確認する。

最低限、

- 父
- 母父
- 父父
- 母母父など主要祖先
- 主要な父系・母父系
- Northern Dancer、Mr. Prospector、Sunday Silence、Roberto等の主要血脈構成
- 主要クロス
- 牝系
- 同系統の過去好走例

を確認する。

血統から検討する主な仮説は、

- 距離適性
- 芝 / ダート適性
- 高速馬場 / 時計の掛かる馬場
- 道悪
- 瞬発戦 / 持続戦
- 坂・小回り・直線の長さ
- 成長力・年齢適性

などとする。

ただし、血統は既存ルール22どおり**適性仮説**である。

**血統 → 適性仮説 → その馬自身の実走で検証**

の順を守り、実走と矛盾する場合は原則として実走を優先する。

「過去に○○系が多いから○○系を買う」のような単純な系統加点は禁止する。

また、父・母父・クロス等が同じ適性を示している場合は、同一根拠として二重・三重計上しない。

## 51-6. 枠順データ

過去の枠順・馬番成績を確認するが、単独で評価しない。

分析は、

**枠 × 脚質 × コース形態 × ペース × 当日馬場 × 位置取り実現確率**

で行う。

特に、

- 内枠が有利だった理由
- 外枠が不利だった理由
- 逃げ・番手・差しのどの位置帯が影響を受けたか
- 人気馬の偏りで成績が作られていないか

を確認する。

「過去10年8枠0勝」のような小標本だけで機械的に消さない。

## 51-7. 前走データ・ローテーション

重賞では前走情報を重点分析する。

確認する項目：

- 前走レース名・格
- 前走の相手レベル
- 前走距離
- 距離延長 / 短縮 / 同距離
- 前走着順・人気・着差
- 位置取り・4角位置
- 上がり
- ペース・ラップ
- 不利・距離ロス
- 前走の展開恩恵
- 中何週か
- 休み明け / 叩き何戦目か
- 同一ローテの過去好走率

「前走○○組が強い」という集計結果だけで評価せず、**なぜそのローテが今回に接続しやすいのか**を説明する。

## 51-8. 騎手データ

騎手は単純な勝率加点ではなく、基本予想ルール15と接続して扱う。

可能な範囲で、

- 当該競馬場成績
- 当該コース・距離成績
- 重賞成績
- 当該重賞成績
- 当該馬とのコンビ成績
- 近況
- 逃げ・先行・差し等の騎乗傾向
- 乗り替わり
- 今回の位置取り・ペース形成への影響

を確認する。

「上位騎手だから加点」ではなく、**今回の馬・枠・展開で何を変える可能性があるか**を評価する。

## 51-8.1 厩舎データ

厩舎は単純なリーディング順位や勝率加点ではなく、基本予想ルール15.1と接続して扱う。

可能な範囲で、

- 厩舎の直近4〜8週程度の状態と当年・中長期成績
- 当該競馬場・コース・芝 / ダート・距離帯成績
- 重賞・当該重賞・同時期開催での成績
- 新馬・休み明け・叩き2戦目・昇級・距離変更等のローテ別成績
- 当該馬の休養明け / 連戦時の厩舎パターン
- 厩舎×騎手の組み合わせ成績と起用継続 / 乗り替わりの意味
- 遠征・滞在・輸送条件での傾向が取得可能な場合の成績
- 当該馬の転厩有無と転厩前後のパフォーマンス
- 厩舎コメント、調整過程、目標レースへの使い方

を確認する。

重賞では特に、**能力が拮抗する馬同士の仕上がり再現性、休み明けの完成度、権利取り / 叩き台を含むローテ意図**を判断する補助材料として使う。

ただし、

- 有名厩舎だから上げる
- リーディング上位だから上げる
- 直近数勝だけで好調認定する
- 騎手成績や馬自身の近走好調を厩舎要素として再加点する

ことは禁止する。母数が小さい場合は参考情報に留め、可能なら人気・オッズ等の市場期待に対して上振れ / 下振れしているかも確認する。

## 51-9. 当日データとの統合

重賞でも当日情報は既存当日馬場補正の条件を満たす場合のみ強く反映する。

確認対象：

- 公式馬場状態
- 天候
- 含水率等、主催者から取得可能な馬場情報
- 同日芝 / ダートの時計水準
- 位置取り・4角位置
- 内外
- 上がり
- ペース
- 風の影響が明確な場合の風向・強さ
- 馬体重・増減
- 取消・除外・騎手変更
- 直前オッズ

過去傾向より当日の明確な実測情報を優先する場合がある。

ただし少数レースだけで過去傾向を反転させず、既存20の馬場バイアス信頼度を適用する。

## 51-10. 過去傾向との一致度の評価

過去傾向を単純な加点表にはしない。

各主要馬について、過去傾向との整合を原則として、

- **強く一致**
- **一致**
- **中立 / 判断材料不足**
- **反証あり**

の4段階で整理する。

過去傾向との一致度は「勝率を自動的に上げる点数」ではなく、Production基準予想に対する**51B Shadow独立モデル兼検証材料**として使う。

特に、

- 基本予想上位馬を過去傾向も支持している
- 基本予想上位馬に過去傾向上の反証がある
- 基本予想中位馬を過去傾向が強く支持している

という不一致を可視化する。

## 51-11. 51A / 51Bの決定権と変更禁止

### 51A

51Aは情報収集プロトコルであり、51Aという理由だけで基本予想順位・確率を独立補正しない。

51Aで新たに確認した当該馬の直接事実は、既存の正式ルールへ戻して評価できる。評価変更が生じた場合は、

- どの既存正式ルールで評価したか
- 事前順位 → 変更後順位
- 確率変更量
- 証拠強度

を保存する。

### 51B

51Bは**Shadow専用**である。複数の独立根拠が揃っても、同レースのProduction基準順位・基準確率・正式推奨買い目を変更してはならない。

51Bでは比較予想側の順位・確率を実際に動かしてよい。変更根拠は、

- 過去傾向
- 年齢・性別構造
- ローテ集計
- 枠・脚質集計
- 血統集計
- 騎手・厩舎の集団傾向

等に分類し、同一原因の言い換えを独立根拠として数えない。

弱い統計傾向しかない場合はShadow側でも大幅変更せず、不確実性レンジやシナリオ差分だけに留める。

結果後に51Bが改善していたとしても、そのレースのProductionを遡及変更しない。昇格はサイクル終了審査だけで行う。

## 51-13. 予想サイト・過去傾向サイト利用時の禁止事項

# 検証中ルール追加記録：2026-08-29 回顧由来

## 基本原則

今回の結果から得た改善仮説は、**レース結果だけを理由に既存ルールへ即時反映しない**。

回顧ではレース全体を一括して「成功／失敗」とせず、最低でも以下を分離する。

1. 基本予想能力評価
2. 条件別補正
3. 展開・位置取り評価
4. 市場価格・フェアオッズ評価
5. 買い／見送り判断
6. 券種選択
7. 買い目・着順構造
8. 資金配分

正常に機能した階層は保護し、失敗が確認された階層だけを改善対象とする。

## E-01：買い目期待値の独立評価（v1.5.0で35.1へ昇格・以下は検証履歴）

**状態：正式昇格 / 履歴保存**

単勝・馬単・ワイド・三連複・三連単など、各馬券の期待値を独立して評価する。

特に、

- 「A→Bの馬単が低い期待値」
- 「A→B→Cの三連単が低い期待値」

は別の命題として扱う。

馬単で売れすぎている組み合わせでも、三連単で人気薄Cを3着に加えることで市場過小評価が残る可能性があるため、他券種の評価を横滑りさせない。

三連単では可能な範囲で、

- 1着確率
- 1着条件下での2着確率
- 1・2着条件下での3着確率

を分離し、組み合わせ確率と実オッズを比較する。

### E-01検証例：2026-08-29 札幌12R

基本予想では、

**⑩オンザムービー ＞ ⑪タガノエルー ＞ ⑦リメンバーヒム**

の順に高く評価できていた。

一方、⑩→⑪馬単の低オッズを理由に⑩→⑪→⑦三連単まで軽視したことが、的中機会を逃した主要因となった。

## E-02：予測順位保存ルール（v1.5.0で37.1へ昇格・以下は検証履歴）

**状態：正式昇格 / 履歴保存**

高配当化だけを目的として、基本予想で評価した着順確率を反転させない。

基本予想の基本順位が、

**A ＞ B ＞ C**

なら、第一シナリオは原則として、

**A → B → C**

とする。

**A → C → B** などは、展開・条件付き確率・価格に合理的な根拠がある場合のみ第二シナリオとして追加する。

「穴馬を上の着順に置けば配当が高い」という理由だけでは順位を変更しない。

### E-02検証例：2026-08-29 札幌12R

予測では⑪を最有力2着候補、⑦を高配当3着候補と評価していたにもかかわらず、配当を求めて⑩→⑦→⑪を優先した。

今後は最も確率の高い順序を主戦とし、高配当順序は補助シナリオとする。

## E-03：最終価格再確認

**優先度：S**

### 再走査対象

- 買い候補馬
- フェアオッズ付近のボーダー馬
- 一度②候補になった馬
- 高評価したが価格不足で落とした馬

3. 馬単・ワイド・三連系の組み合わせオッズが買い条件を新たに満たした

**市場価格だけが変化した場合、基本予想能力評価・印は原則変更しない。**

能力評価を変えずとも、価格変動だけで期待値判定が変化し得ることを確認した。

## E-07：高確信度活用 / 高確信度活用

**優先度：S**

単勝が1～2倍台まで売れていて単勝期待値が低くても、**1着確率が高く、2・3着候補まで一定精度で限定できる場合はレース全体を見送らない**。

「強い人気馬を単勝で買う」のではなく、

**高い予測精度を馬単・三連複・三連単へ変換できるか**

### 発動条件（検証中ルール）

以下を複数満たす場合に適用候補とする。

- 1着候補の推定勝率が概ね50～55%以上
- 基本予想と主要条件別補正が同じ方向を示す
- 1着馬の能力優位を具体的に説明できる
- 展開・馬場・状態の重大な不確実性が比較的小さい
- 2着候補、または2～3着候補をある程度限定できる
- 単勝は価格不足でも、組み合わせ馬券に市場の歪みが残っている

数値基準は固定ルールではなく、検証用の目安とする。

### 馬券構築原則

高確信レースでは、

**的中確率の高い基本シナリオを主戦**
→ **次点シナリオ**
→ **高配当シナリオ**

の順に資金を置く。

高配当化を理由に基本予測順位を崩さない。

例：

基本予想が

**A ＞ B ＞ C**

なら、

- 第一シナリオ：A→B→C
- 第二シナリオ：A→C→B
- その他の穴シナリオ

の順に扱う。

### 資金配分の検証目安

固定ルールにはしないが、検証中ルールでは例として、

- 60～70%：最も確率の高い着順・馬券構造
- 20～30%：次点シナリオ
- 10%前後：高配当シナリオ

のように、**確率順位に沿った階層配分**を検証する。

### E-07検証例：2026-08-29 札幌12R

⑩オンザムービーを高確率1着、⑪タガノエルーを最有力2着、⑦リメンバーヒムを穴3着候補と評価できていた。

単勝1.3倍自体は買わなくても、

**⑩→⑪→⑦**

のように高い予測精度を馬券へ変換する価値があった。

このタイプを、

**「期待値を探しに行くレース」ではなく「高い予測精度を収益化するレース」**

として別角度から検出する。

## E-08：最終オッズ予測 / 最終オッズ予測

**優先度：S**

リアルタイムの最終オッズ取得へ過度に依存すると、買い目検討・資金配分・購入操作に必要な時間を失い、予想できていても締切に間に合わない運用リスクが発生する。

そのため、2026-09-05以降の実戦検証では、原則として**発走15〜25分前を最終予想固定時点（最終予想固定時点）**とし、その時点のオッズを保存したうえで、過去の「最終予想時点オッズ → 確定最終オッズ」の変化をサンプリングし、**最終オッズの中心値・合理的レンジ・買い条件を割る確率を予測して馬券を構築する。**

本項目は馬の能力順位・印・勝率を変更する基本予想ではなく、**市場価格判断・購入タイミングを改善する検証中ルール**である。

### E-08.1 自動適用特例

通常の領域C2はユーザー明示なしに正式予想へ混入させないが、E-08はユーザーが2026-09-04に翌開催からの実運用を明示的に採用したため、**2026-09-05以降のモード1・モード2・モード7の市場／購入段階でデフォルト適用する実戦検証中ルール**とする。

ただし、E-08によって変更してよいのは、原則として、

- 価格評価
- 買い／見送り判定
- 券種選択
- 買い目
- 資金配分
- 購入タイミング

のみとし、**基本予想順位・最終印・能力評価・勝率等へ市場価格を逆流させない。**

### E-08.2 最終予想固定時点

標準の最終予想固定時点は、原則として**発走20分前を中心とする15〜25分前**とする。

記録上は次の3区分に分ける。

- **標準サンプル**：発走15〜25分前
- **直前サンプル**：発走15分未満
- **参考サンプル**：発走25分超

標準サンプルを最優先して学習し、時刻帯が異なるデータを無条件に一括集計しない。

最終予想固定後は、オッズを追い続けることを目的にせず、予測最終価格で買い条件を評価し、**購入操作に十分な時間を残すことを優先する。**

### E-08.3 最終オッズは1点ではなくレンジで予測する

各買い候補について、可能な範囲で、

- 最終予想時点オッズ
- 予測最終オッズ中心値
- 合理的予測レンジ
- 買い条件を下回る確率
- 価格変動方向（上昇 / 安定 / 下降）

を推定する。

例：

> 最終予想時点 8.0倍  
> 予測最終中心 7.2倍  
> 合理的レンジ 6.3〜8.5倍  
> 買い条件6.0倍を割る確率 10%

のように扱う。

**最終オッズを正確に一点的中させることより、買い条件を跨ぐかどうかを正しく判断することを重視する。**

### E-08.4 サンプリング項目

各レース・各買い候補について、最低限次を保存する。

- 日付・競馬場・R
- 最終予想時刻
- 発走までの残り時間
- 券種
- 馬または組み合わせ
- 最終予想時点オッズ
- その時点の人気順位
- 自分のフェアオッズ / 買い条件
- 予測最終オッズ中心値
- 予測レンジ
- 買い条件を割る予測確率
- 購入判断
- 実際の購入時オッズ（取得できる場合）
- レース確定後の最終オッズ
- 最終予想時点→最終の変化率
- 予測誤差
- 価格境界判定が正しかったか

単勝だけでなく、**複勝・ワイド・馬連・馬単・三連複・三連単は券種ごとに独立サンプル**として扱う。

買い目期待値の考え方と同様、単勝の価格変化を別券種へ機械的に横滑りさせない。

### E-08.5 価格変化率の基本集計

基本指標として、

> **価格変化比 = 最終オッズ ÷ 最終予想固定時点時点オッズ**

を記録する。

初期検証では、過度に細分化せず、まず、

- 券種
- 最終予想固定時点までの残り時間帯
- 人気帯
- オッズ帯
- 出走頭数帯

を中心に集計する。

サンプルが十分に蓄積するまでは、重賞 / 条件戦、芝 / ダート等を細分化しすぎない。

### E-08.6 価格変動の暫定分類

初期検証では、最終予想時点から確定最終までの変化を、

- **上昇**：+10%以上
- **安定**：±10%以内
- **軽度下降**：-10%超〜-20%
- **大幅下降**：-20%以上

に暫定分類する。

これは固定基準ではなく、サンプル蓄積後に再調整する検証中ルール基準とする。

### E-08.7 購入判定

価格判断は、可能な範囲で**現在オッズではなく予測最終オッズ**を中心に行う。

原則として、

- **通常**：予測最終オッズ中心値が買い条件を満たす
- **高不確実性時**：予測レンジの保守側でも買い条件を維持するか確認する
- **境界付近**：買い条件を割る確率に応じて資金を縮小する

とする。

高い期待値に見える場合でも、最終価格が大幅に下がる可能性が高いなら、投入額を抑えることを認める。

### E-08.8 E-03 最終価格再確認との関係

E-08導入後の通常運用は、

**E-08 最終オッズ予測を標準**  
**E-03 最終価格再確認を時間に余裕がある場合の追加確認**

とする。

E-03のために購入操作が遅れる場合は、**E-03を実行せずE-08の予測価格で購入判断を確定する。**

最終価格再確認を行う場合も、価格だけが変化したなら基本予想順位・印は変更しない。

### E-08.9 再評価を許可する例外

最終予想固定時点後であっても、次のような**非価格の強い新情報**が発生した場合は、既存ルールに従って予想本体の再評価を認める。

- 取消・除外
- 騎手変更
- 公式馬場状態の急変
- 天候急変に伴う明確な馬場変化
- 馬体重・状態に関する重大な新情報
- その他、結果へ大きく影響する一次情報

単なるオッズ変動だけでは基本予想を再計算しない。

### E-08.10 評価指標

サイクル終了時は、少なくとも次を評価する。

1. 最終オッズ予測の絶対誤差・相対誤差
2. オッズ上昇 / 下降方向の的中率
3. 買い条件を跨ぐかどうかの判定精度
4. 予測最終オッズを使った買い／見送り判断の回収率
5. 最終予想固定時点時点オッズだけで判断した場合との比較
6. E-03 最終価格再確認を待った場合との比較
7. 購入遅延・締切超過件数
8. 「最も買いたい馬」がその後市場でも買われた割合
9. 券種別の価格予測精度

特に、**価格予測精度が少し改善しても購入遅延・締切超過が増える運用は改善とは扱わない。**

### E-08.11 明日からの初期運用

2026-09-05からは、過去サンプルがまだ少ないため、精密な統計モデルを装わない。

初期段階では、

1. 発走15〜25分前に最終予想を固定
2. その時点のオッズを保存
3. 過去サンプルが不足する券種は中心値を現在オッズ寄りに置き、レンジを広くする
4. 買い条件との余裕幅を重視して購入判断
5. レース後に確定最終オッズを取得
6. サンプルを蓄積し、予測レンジ・変化率を順次確率精度の検証

とする。

十分なサンプルが蓄積するまでは、オッズ予測を強い加点材料ではなく、**購入時間確保と価格リスク管理のための補助モデル**として扱う。


## E-09：馬個体適性分析 / 馬個体適性プロファイル

**優先度：S / 第2サイクルは比較用予想**

目的は、レース側の一般適性だけでなく、**その馬自身がどの条件で能力を再現しやすいか**を縦方向に追うことである。

単純な勝率表を加点するのではなく、

> 条件 → 位置取り・走り方 → 能力発揮 / 減衰

の因果を確認する。

### E-09.1 レース間隔プロファイル

確認するもの：

- 休み明け / 叩き2戦目 / 連戦時の内容
- 中2〜3週等の短間隔でパフォーマンスを維持できるか
- 休養後にテンション・行きっぷり・末脚がどう変化するか
- 使い詰めで終盤性能や反応が落ちる傾向があるか
- 同じ間隔でも相手レベル・距離・馬場が違う点

「中4週2戦2勝」のような少数例だけで好走パターンと断定しない。サンプル数とレース内容を同時に記録する。

### E-09.2 枠・馬番・馬群プロファイル

単なる枠別成績ではなく、

- 内枠で包まれた時の反応
- 外から被された時の挙動
- 馬群を割れるか
- 外枠から自分のリズムで先行できるか
- 内をロスなく立ち回れるか
- ダートで砂を被っても走れるか
- キックバックを嫌って頭を上げる、位置を下げる等があるか
- 外々を回した時の距離ロス耐性

を確認する。

特にダートでは、**内枠有利 / 不利より「その馬が砂を被った状態で能力を出せるか」**を優先する。

### E-09.3 コース物理特性プロファイル

競馬場名だけでなく、可能な範囲で次へ分解する。

- 右回り / 左回り
- 直線の長さ
- 急坂 / 平坦
- コーナー半径・角度
- 3〜4角の下り・上り
- 小回り適性
- スタートから最初のコーナーまでの距離
- 直線入口で必要な加速性能
- 長くトップスピードを維持する必要性

「東京巧者」ではなく、**長い直線で持続加速できる馬**のように能力特性へ翻訳し、他コースへの転用可能性を検証する。

### E-09.4 馬場・天候・降雨プロファイル

確認するもの：

- 良→稍重→重で脚色がどう変化するか
- 高速馬場で追走負荷が上がる / 下がるか
- 時計が掛かる馬場で持続力が生きるか
- 芝の水分で加速が鈍るか
- 湿ったダートで前進するか
- 雨によるキックバック変化への対応
- 降雨中でも集中力・行きっぷりを維持できるか

「雨だから得意」ではなく、**雨で変化した走行条件に適性があるか**を評価する。

### E-09.5 適用方法

第2サイクルでは、モード1の最終予想対象、モード2の購入候補、重賞について、原則として、

- 基準予想上位5頭
- 価格妙味候補
- 展開の鍵を握る馬

を詳細対象とし、その他の馬は一次確認に留めて情報コストを管理する。

E-09は加点表として合算せず、

- 通常シナリオで能力を再現できる確率
- 特定枠 / 馬群 / 馬場で能力が減衰するシナリオ

を分けるために使う。

厩舎の一般的な休み明け・ローテーション傾向は基準となる基本予想の15.1で扱う。E-09では**当該馬自身がその条件にどう反応したか**を扱い、同じローテーション事実を厩舎要素と馬個体要素で二重計上しない。

第2サイクルでは基準予想順位を無断で変更せず、**E-09を反映した場合にどの馬が何段階・何pt動くかを比較用予想として記録**する。

### E-09.6 記録・評価

最低限、

- 使用した個体条件
- 過去サンプル数
- 証拠強度（強 / 中 / 弱）
- 基準予想との差分
- 結果
- 改善 / 中立 / 悪化

を保存する。

少数サンプル由来の条件一致が多いほど評価を上げる方式は禁止する。

## E-10：年齢・性別構造優位分析 / 古馬混合の若駒・牝馬構造優位

**優先度：A / 第2サイクルは比較用予想**

古馬混合戦で、若駒や牝馬が馬柱上の古馬実績だけでは見えにくい優位を持つ条件を検証する。

### E-10.1 若駒で確認する要素

- 実斤量差・斤量恩恵
- 前走からの成長速度
- キャリアの浅さによる能力上限の未確定性
- 同世代重賞・条件戦のレベル
- 絶対時計・巡航速度を古馬水準へ置き換えた場合の位置
- 距離短縮 / 延長で古馬との差が縮まるか
- 季節による完成度
- 馬体増減と成長の整合性

**「古馬実績がない」ことを「古馬に通用しない」と同義にしない。**

### E-10.2 牝馬で確認する要素

- 性別による斤量差
- スピード要求度・瞬発戦 / 持久戦
- 馬体サイズと接触・揉まれリスク
- 外をスムーズに走れる配置か
- 性別限定戦で記録した絶対時計・上がりを混合戦水準へ換算した位置
- 混合戦で要求されるフィジカルと位置取りを満たせるか

### E-10.3 禁止事項

- 3歳だから一律加点
- 牝馬だから一律加点
- 斤量差だけで能力差を相殺したことにする
- キャリアが浅いこと自体を上昇材料にする

上げるのは、**今回条件で具体的な構造優位を説明できる場合だけ**とする。

### E-10.4 記録

古馬混合戦では、該当する若駒・牝馬について、

- 年齢・性別
- 斤量差
- 基準予想評価
- 構造的優位の根拠
- 比較予想評価
- 着順

を保存し、複数開催で再現性を確認する。

## E-11：高確信度集中投資 / 高確信度への資金集中

**優先度：A+ / 実戦検証中ルール / HF1 Shadow専用**

HF1以降、E-11は**Production基準買い目を固定した後にだけ生成するShadow比較買い目**とする。E-11案が高期待値に見えても、その理由だけで正式推奨へ差し替えない。

予想段階では複数シナリオを保持する一方、Shadow購入段階では**最も期待値の高い本線シナリオへ意図的に資金を集中する**ことを検証する。

E-11の「高確信度」は主として**予想確信度**を意味し、実際に資金を集中する最終判断では**購入確信度**も併用する。

### E-11.1 適用候補

次が複数揃う場合に比較予想を作る。

- ◎の勝率が明確に最上位
- 2番手との差が十分ある
- 予想確信度がB+以上
- 位置取り・展開の主シナリオが読みやすい
- ◎が崩れる独立シナリオが少ない
- 初条件・出遅れ・馬場未知等の重大な不確実性が小さい
- 三連単等の価格が三連複・縦目保険より魅力的

固定数値閾値は第2サイクルでは設定せず、適用理由を文章で記録する。

### E-11.2 ◎依存型を許容する条件

48.2 万能軸監査で最終的に許容される場合、

- ◎からの馬連・ワイドのみ
- ◎1着固定の三連単
- ◎→○▲→○▲△☆等のフォーメーション
- ◎を含む本線だけへ資金集中

を許容する。

**馬依存率100%を避けること自体を目的に、低い期待値の縦目を追加しない。**

縦目は、独立して買い目期待値が正の場合だけ購入候補とする。

### E-11.3 本線ワイド基準額 / 本線ワイド基準単位

レース予算が**3,000〜5,000円程度**で、最重要ワイドが、

- 本線シナリオそのもの
- 2頭の同時3着内確率が高い
- 予想確信度がB+以上
- E-08の保守側予測価格でも買い条件を維持

する場合、**1,000円を基準投入単位として検討する。**

これは固定購入額ではない。価格・予想確信度・最終購入確信度に応じて減額し、**最終購入確信度がB+以上かつ高い期待値**なら1,500円以上も許容する。逆に低オッズ・期待値が境界付近・購入確信度 B-以下なら1,000円未満または見送りとする。

### E-11.4 三連単への変換

◎の1着確率が高く、相手順位にも一定の差がある場合、三連複を機械的に買うより、

- ◎1着固定
- ◎→○▲→○▲△☆
- ◎→○▲△→○▲△☆

の三連単を少額で候補化する。

順序の確信が低い場合は、2頭軸マルチやフォーメーションをE-12と組み合わせる。

### E-11.5 検証指標

- 通常分散案と集中比較予想の回収率
- 的中率
- 平均払戻
- 最大ドローダウン
- 馬依存率・シナリオ依存率
- 本線的中時に十分な利益を取れた割合
- 縦目保険を削ったことによる機会損失

を分離して記録する。

## E-12：人気構造別券種選択 / 人気構造別券種ルーティング

**優先度：S / 実戦検証中ルール / HF1 Shadow専用**

HF1以降、E-12は**Production基準買い目を固定した後にだけ生成するShadow比較買い目**とする。市場構造に適した券種が見つかっても、同レースの正式推奨をE-12で差し替えない。

市場の人気構造と本線ペアの性質に応じて、Shadow側の券種優先順位を変える。

人気だけで購入可否を決めず、最終的には35.1 買い目期待値とE-08予測最終価格で確認する。

### E-12.1 人気馬同士が本線

本線2頭が上位人気同士の場合、原則優先順位は、

1. **馬連**
2. **本線ワイドを厚く**
3. **三連単**（1着固定、2頭軸マルチ、フォーメーション）
4. **三連複は価格が十分な場合だけ**

とする。

人気馬中心の三連複は低配当化しやすいため、**原則低優先**とする。ただし買い目期待値が明確に高い場合は禁止しない。

### E-12.2 人気馬 × 穴馬が本線

本線が人気馬と穴馬の組み合わせなら、

1. **ワイドを本線として厚く**
2. 馬連を連対シナリオとして追加
3. 両馬が3着内に来るシナリオが強い場合、**三連複2頭軸 → 相手**
4. 人気馬の勝ち切りが強い場合、**人気馬1着固定三連単で穴馬を2・3着へ配置**

を優先する。

「人気馬×穴馬」の価格差を最大限活かしながら、穴馬3着でも利益が残る構造を目指す。

### E-12.3 人気馬3頭中心の三連複

人気上位3頭中心の三連複は、**購入優先度を原則低くする。**

ただし、成立確率が価格に対して十分高いと買い目期待値で説明できる場合のみ購入可能とする。

「安いから禁止」ではなく、**安い組み合わせは他券種より高い成立確率を要求する**と解釈する。

### E-12.4 強い本命1頭を中心に着順まで読む

◎が明確で、2・3着候補の順位差もある場合は、

- 馬連 / 馬単
- ◎1着固定三連単
- 少数フォーメーション

を優先し、三連複を広く買うより順序情報を収益化する。

### E-12.5 市場構造の判定時点

市場構造は、原則として最終予想固定時点時点の人気順と、E-08の予測最終オッズレンジを使って判定する。

最終予想時に人気順位が境界で入れ替わる可能性が高い場合は、Typeを固定せず2案を比較する。

### E-12.6 検証記録

各購入候補で、

- 人気構造タイプ
- 基準予想の通常買い目
- E-12 Routing後の比較買い目
- 本線ワイド投入額
- 三連複 / 三連単の使い分け理由
- 的中率・回収率
- 本線的中時の利益額

を保存する。

# 更新ルール

本原本の更新は、今後「毎レース追加型」ではなく**2週間検証サイクル型**で行う。

1. **基本予想ロジックは原則2週間・最大約144Rの1サイクル中は固定する**
