# 51B 重賞傾向Shadow

51Aの情報源ポリシー・直接事実収集カテゴリは `20_conditional.md` を参照する。ここでは集団傾向をProductionから分離して比較する51Bだけを所有する。

## 51-3. 過去傾向の対象期間

原則として過去5〜10年程度を確認する。

ただし、単純に「同じレース名の過去10年」を一括集計しない。次の構造変化を必ず確認する。

- 開催競馬場の変更
- 距離変更
- 芝 / ダート変更
- コース改修
- 開催時期変更
- 定量 / 別定 / ハンデ等の負担重量条件変更
- 斤量制度変更
- 出走資格・年齢条件変更
- 特殊な代替開催

条件が大きく異なる年は、

- 同条件サンプル
- 参考サンプル

に分けて扱う。

**同じレース名 ≠ 同じレース構造**を原則とする。

## 51-4. 過去傾向で確認する基本項目

可能な範囲で次を確認する。

- 人気別成績
- 単勝オッズ帯
- 枠順・馬番
- 年齢・性別
- 斤量
- 馬体重・増減
- 脚質
- 4角位置
- 上がり順位
- 勝ち時計・ラップ・ペース
- 前走レース
- 前走クラス
- 前走距離
- 前走着順・人気・着差
- 前走位置・上がり
- レース間隔
- 重賞実績
- コース実績
- 季節・開催時期

全項目を均等に加点しない。

今回の出走馬を分けるうえで有効な傾向だけを、基本予想の3大要因を補強・反証する情報として使う。

## 51-10. 過去傾向との一致度の評価

過去傾向を単純な加点表にはしない。

各主要馬について、過去傾向との整合を原則として、

- **強く一致**
- **一致**
- **中立 / 判断材料不足**
- **反証あり**

の4段階で整理する。

過去傾向との一致度は「勝率を自動的に上げる点数」ではなく、Production基準予想に対する**51B Shadow独立モデル兼検証材料**として使う。

特に、

- 基本予想上位馬を過去傾向も支持している
- 基本予想上位馬に過去傾向上の反証がある
- 基本予想中位馬を過去傾向が強く支持している

という不一致を可視化する。

## 51-11（Shadow側）

### 51B

51Bは**Shadow専用**である。複数の独立根拠が揃っても、同レースのProduction基準順位・基準確率・正式推奨買い目を変更してはならない。

51Bでは比較予想側の順位・確率を実際に動かしてよい。変更根拠は、

- 過去傾向
- 年齢・性別構造
- ローテ集計
- 枠・脚質集計
- 血統集計
- 騎手・厩舎の集団傾向

等に分類し、同一原因の言い換えを独立根拠として数えない。

弱い統計傾向しかない場合はShadow側でも大幅変更せず、不確実性レンジやシナリオ差分だけに留める。

結果後に51Bが改善していたとしても、そのレースのProductionを遡及変更しない。昇格はサイクル終了審査だけで行う。

## 51-14. 検証記録

本条件別補正は成熟度検証中ルールであるため、重賞ごとに最低限次を記録する。

- Production基準予想上位3頭
- 51B Shadow比較予想上位3頭
- Shadow側で順位・確率が変わった馬
- 変更根拠の分類（血統 / 枠 / 前走 / 騎手 / 厩舎 / 過去傾向 / 当日）
- 過去傾向との一致度
- 51B ShadowがProduction基準予想を**改善 / 中立 / 悪化**させたか
- 使用した区分3ソース数と独立性
- 主要傾向の一致度判定
- 単一サイトへの依存がなかったか
- SNS・掲示板・匿名情報を根拠に使用していないか
- 過去傾向だけで過剰補正しなかったか
- 最終結果

一定数の重賞で、Production基準予想と51B Shadow比較予想を前向きに比較する。

単発の的中・不的中で正式な基本予想へ昇格させない。

# 検証中ルール追加記録：2026-08-29 回顧由来

## 基本原則

今回の結果から得た改善仮説は、**レース結果だけを理由に既存ルールへ即時反映しない**。

回顧ではレース全体を一括して「成功／失敗」とせず、最低でも以下を分離する。

1. 基本予想能力評価
2. 条件別補正
3. 展開・位置取り評価
4. 市場価格・フェアオッズ評価
5. 買い／見送り判断
6. 券種選択
7. 買い目・着順構造
8. 資金配分

正常に機能した階層は保護し、失敗が確認された階層だけを改善対象とする。

## E-01：買い目期待値の独立評価（v1.5.0で35.1へ昇格・以下は検証履歴）

**状態：正式昇格 / 履歴保存**

単勝・馬単・ワイド・三連複・三連単など、各馬券の期待値を独立して評価する。

特に、

- 「A→Bの馬単が低い期待値」
- 「A→B→Cの三連単が低い期待値」

は別の命題として扱う。

馬単で売れすぎている組み合わせでも、三連単で人気薄Cを3着に加えることで市場過小評価が残る可能性があるため、他券種の評価を横滑りさせない。

三連単では可能な範囲で、

- 1着確率
- 1着条件下での2着確率
- 1・2着条件下での3着確率

を分離し、組み合わせ確率と実オッズを比較する。

### E-01検証例：2026-08-29 札幌12R

基本予想では、

**⑩オンザムービー ＞ ⑪タガノエルー ＞ ⑦リメンバーヒム**

の順に高く評価できていた。

一方、⑩→⑪馬単の低オッズを理由に⑩→⑪→⑦三連単まで軽視したことが、的中機会を逃した主要因となった。

## E-02：予測順位保存ルール（v1.5.0で37.1へ昇格・以下は検証履歴）

**状態：正式昇格 / 履歴保存**

高配当化だけを目的として、基本予想で評価した着順確率を反転させない。

基本予想の基本順位が、

**A ＞ B ＞ C**

なら、第一シナリオは原則として、

**A → B → C**

とする。

**A → C → B** などは、展開・条件付き確率・価格に合理的な根拠がある場合のみ第二シナリオとして追加する。

「穴馬を上の着順に置けば配当が高い」という理由だけでは順位を変更しない。

### E-02検証例：2026-08-29 札幌12R

予測では⑪を最有力2着候補、⑦を高配当3着候補と評価していたにもかかわらず、配当を求めて⑩→⑦→⑪を優先した。

今後は最も確率の高い順序を主戦とし、高配当順序は補助シナリオとする。

## E-03：最終価格再確認

**優先度：S**

一度分析を完了した後は、基本予想を不用意に再計算せず、締切前に**価格だけを再走査**する。

### 再走査対象

- 買い候補馬
- フェアオッズ付近のボーダー馬
- 一度②候補になった馬
- 高評価したが価格不足で落とした馬
- 組み合わせ馬券の候補になった馬

### 購入判定を更新する条件

以下のいずれかを満たす場合のみ、価格面の購入判定を更新する。

1. 実オッズが設定したフェア／買い条件の境界を跨いだ
2. 前回確認値から約20%以上の相対変動が発生した
3. 馬単・ワイド・三連系の組み合わせオッズが買い条件を新たに満たした

**市場価格だけが変化した場合、基本予想能力評価・印は原則変更しない。**

### E-03検証例：2026-08-29

- 中京7R ④ブルクトーア：途中約17倍 → 最終23.0倍
- 札幌11R ⑧レジェンドシップ：途中評価時より最終価格が上昇

能力評価を変えずとも、価格変動だけで期待値判定が変化し得ることを確認した。

## E-05：良好部分保全 / 非劣化ガード（v1.5.0で0.16.1へ昇格・以下は検証履歴）

**状態：正式昇格 / 履歴保存**

改善によって既存の良い判断を壊さないための保護ルール。

回顧では各階層について、

- **保護（正常に機能）**
- **再検証**
- **改善対象**

を付与する。

### 原則

1. 正常に機能した階層は、そのレースの他部分が失敗していても変更対象にしない
2. 単発の失敗だけで既存の有効ルールを弱体化しない
3. 単発の成功だけで検証中ルールを基本予想へ昇格させない
4. 改善は失敗原因が存在する階層に局所化する
5. 新しい改善案には「何を変えないか」も明記する

### 2026-08-29適用

#### 札幌12R

- ⑩1着固定という発想：**保護**
- ⑪・⑦の相手評価：**保護**

#### 札幌11R

- ⑫バルティカの同条件適性評価：**保護**
- ⑫の価格評価：**保護**
- ⑧レジェンドシップの最終格下げ：**再検証**
- 最終価格更新：**改善対象**

#### 新潟8R

- 価格不足による見送り判断：**保護**
- ③・⑥を無理に購入しなかったこと：**保護**
- ⑦の展開・斤量・左回り評価：**再検証**

#### 中京7R

- 「最も勝つ馬」と「最も買いたい馬」の分離：**保護**
- ⑭ガンマジーティーピの条件替わり評価：**大幅変更しない**
- ④ブルクトーアの最終価格再評価：**改善対象**

## E-06：基準予想 / 比較予想方式（v1.5.0で基本運用規約として確立・以下は検証履歴）

v1.5.0を**基準予想（基準モデル）**として固定する。

- 買い目期待値
- 馬券収支

## E-07：高確信度活用 / 高確信度活用

**優先度：S**

単勝が1～2倍台まで売れていて単勝期待値が低くても、**1着確率が高く、2・3着候補まで一定精度で限定できる場合はレース全体を見送らない**。

「強い人気馬を単勝で買う」のではなく、

**高い予測精度を馬単・三連複・三連単へ変換できるか**

を独立して評価する。

### 発動条件（検証中ルール）

以下を複数満たす場合に適用候補とする。

- 1着候補の推定勝率が概ね50～55%以上
- 基本予想と主要条件別補正が同じ方向を示す
- 1着馬の能力優位を具体的に説明できる
- 展開・馬場・状態の重大な不確実性が比較的小さい
- 2着候補、または2～3着候補をある程度限定できる
- 単勝は価格不足でも、組み合わせ馬券に市場の歪みが残っている

数値基準は固定ルールではなく、検証用の目安とする。

### 馬券構築原則

高確信レースでは、

**的中確率の高い基本シナリオを主戦**
→ **次点シナリオ**
→ **高配当シナリオ**

の順に資金を置く。

高配当化を理由に基本予測順位を崩さない。

例：

基本予想が

**A ＞ B ＞ C**

なら、

- 第一シナリオ：A→B→C
- 第二シナリオ：A→C→B
- その他の穴シナリオ

の順に扱う。

### 資金配分の検証目安

固定ルールにはしないが、検証中ルールでは例として、

- 60～70%：最も確率の高い着順・馬券構造
- 20～30%：次点シナリオ
- 10%前後：高配当シナリオ

のように、**確率順位に沿った階層配分**を検証する。

### E-07検証例：2026-08-29 札幌12R

⑩オンザムービーを高確率1着、⑪タガノエルーを最有力2着、⑦リメンバーヒムを穴3着候補と評価できていた。

単勝1.3倍自体は買わなくても、

**⑩→⑪→⑦**

のように高い予測精度を馬券へ変換する価値があった。

このタイプを、

**「期待値を探しに行くレース」ではなく「高い予測精度を収益化するレース」**

として別角度から検出する。

## E-08：最終オッズ予測 / 最終オッズ予測

**優先度：S**

リアルタイムの最終オッズ取得へ過度に依存すると、買い目検討・資金配分・購入操作に必要な時間を失い、予想できていても締切に間に合わない運用リスクが発生する。

そのため、2026-09-05以降の実戦検証では、原則として**発走15〜25分前を最終予想固定時点（最終予想固定時点）**とし、その時点のオッズを保存したうえで、過去の「最終予想時点オッズ → 確定最終オッズ」の変化をサンプリングし、**最終オッズの中心値・合理的レンジ・買い条件を割る確率を予測して馬券を構築する。**

本項目は馬の能力順位・印・勝率を変更する基本予想ではなく、**市場価格判断・購入タイミングを改善する検証中ルール**である。

### E-08.1 自動適用特例

通常の領域C2はユーザー明示なしに正式予想へ混入させないが、E-08はユーザーが2026-09-04に翌開催からの実運用を明示的に採用したため、**2026-09-05以降のモード1・モード2・モード7の市場／購入段階でデフォルト適用する実戦検証中ルール**とする。

ただし、E-08によって変更してよいのは、原則として、

- 価格評価
- 買い／見送り判定
- 券種選択
- 買い目
- 資金配分
- 購入タイミング

のみとし、**基本予想順位・最終印・能力評価・勝率等へ市場価格を逆流させない。**

### E-08.2 最終予想固定時点

標準の最終予想固定時点は、原則として**発走20分前を中心とする15〜25分前**とする。

記録上は次の3区分に分ける。

- **標準サンプル**：発走15〜25分前
- **直前サンプル**：発走15分未満
- **参考サンプル**：発走25分超

標準サンプルを最優先して学習し、時刻帯が異なるデータを無条件に一括集計しない。

最終予想固定後は、オッズを追い続けることを目的にせず、予測最終価格で買い条件を評価し、**購入操作に十分な時間を残すことを優先する。**

### E-08.3 最終オッズは1点ではなくレンジで予測する

各買い候補について、可能な範囲で、

- 最終予想時点オッズ
- 予測最終オッズ中心値
- 合理的予測レンジ
- 買い条件を下回る確率
- 価格変動方向（上昇 / 安定 / 下降）

を推定する。

例：

> 最終予想時点 8.0倍  
> 予測最終中心 7.2倍  
> 合理的レンジ 6.3〜8.5倍  
> 買い条件6.0倍を割る確率 10%

のように扱う。

**最終オッズを正確に一点的中させることより、買い条件を跨ぐかどうかを正しく判断することを重視する。**

### E-08.4 サンプリング項目

各レース・各買い候補について、最低限次を保存する。

- 日付・競馬場・R
- 最終予想時刻
- 発走までの残り時間
- 券種
- 馬または組み合わせ
- 最終予想時点オッズ
- その時点の人気順位
- 自分のフェアオッズ / 買い条件
- 予測最終オッズ中心値
- 予測レンジ
- 買い条件を割る予測確率
- 購入判断
- 実際の購入時オッズ（取得できる場合）
- レース確定後の最終オッズ
- 最終予想時点→最終の変化率
- 予測誤差
- 価格境界判定が正しかったか

単勝だけでなく、**複勝・ワイド・馬連・馬単・三連複・三連単は券種ごとに独立サンプル**として扱う。

買い目期待値の考え方と同様、単勝の価格変化を別券種へ機械的に横滑りさせない。

### E-08.5 価格変化率の基本集計

基本指標として、

> **価格変化比 = 最終オッズ ÷ 最終予想固定時点時点オッズ**

を記録する。

初期検証では、過度に細分化せず、まず、

- 券種
- 最終予想固定時点までの残り時間帯
- 人気帯
- オッズ帯
- 出走頭数帯

を中心に集計する。

サンプルが十分に蓄積するまでは、重賞 / 条件戦、芝 / ダート等を細分化しすぎない。

### E-08.6 価格変動の暫定分類

初期検証では、最終予想時点から確定最終までの変化を、

- **上昇**：+10%以上
- **安定**：±10%以内
- **軽度下降**：-10%超〜-20%
- **大幅下降**：-20%以上

に暫定分類する。

これは固定基準ではなく、サンプル蓄積後に再調整する検証中ルール基準とする。

### E-08.7 購入判定

価格判断は、可能な範囲で**現在オッズではなく予測最終オッズ**を中心に行う。

原則として、

- **通常**：予測最終オッズ中心値が買い条件を満たす
- **高不確実性時**：予測レンジの保守側でも買い条件を維持するか確認する
- **境界付近**：買い条件を割る確率に応じて資金を縮小する

とする。

高い期待値に見える場合でも、最終価格が大幅に下がる可能性が高いなら、投入額を抑えることを認める。

### E-08.8 E-03 最終価格再確認との関係

E-08導入後の通常運用は、

**E-08 最終オッズ予測を標準**  
**E-03 最終価格再確認を時間に余裕がある場合の追加確認**

とする。

E-03のために購入操作が遅れる場合は、**E-03を実行せずE-08の予測価格で購入判断を確定する。**

最終価格再確認を行う場合も、価格だけが変化したなら基本予想順位・印は変更しない。

### E-08.9 再評価を許可する例外

最終予想固定時点後であっても、次のような**非価格の強い新情報**が発生した場合は、既存ルールに従って予想本体の再評価を認める。

- 取消・除外
- 騎手変更
- 公式馬場状態の急変
- 天候急変に伴う明確な馬場変化
- 馬体重・状態に関する重大な新情報
- その他、結果へ大きく影響する一次情報

単なるオッズ変動だけでは基本予想を再計算しない。

### E-08.10 評価指標

サイクル終了時は、少なくとも次を評価する。

1. 最終オッズ予測の絶対誤差・相対誤差
2. オッズ上昇 / 下降方向の的中率
3. 買い条件を跨ぐかどうかの判定精度
4. 予測最終オッズを使った買い／見送り判断の回収率
5. 最終予想固定時点時点オッズだけで判断した場合との比較
6. E-03 最終価格再確認を待った場合との比較
7. 購入遅延・締切超過件数
8. 「最も買いたい馬」がその後市場でも買われた割合
9. 券種別の価格予測精度

特に、**価格予測精度が少し改善しても購入遅延・締切超過が増える運用は改善とは扱わない。**

### E-08.11 明日からの初期運用

2026-09-05からは、過去サンプルがまだ少ないため、精密な統計モデルを装わない。

初期段階では、

1. 発走15〜25分前に最終予想を固定
2. その時点のオッズを保存
3. 過去サンプルが不足する券種は中心値を現在オッズ寄りに置き、レンジを広くする
4. 買い条件との余裕幅を重視して購入判断
5. レース後に確定最終オッズを取得
6. サンプルを蓄積し、予測レンジ・変化率を順次確率精度の検証

とする。

十分なサンプルが蓄積するまでは、オッズ予測を強い加点材料ではなく、**購入時間確保と価格リスク管理のための補助モデル**として扱う。


## E-09：馬個体適性分析 / 馬個体適性プロファイル

**優先度：S / 第2サイクルは比較用予想**

目的は、レース側の一般適性だけでなく、**その馬自身がどの条件で能力を再現しやすいか**を縦方向に追うことである。

単純な勝率表を加点するのではなく、

> 条件 → 位置取り・走り方 → 能力発揮 / 減衰

の因果を確認する。

### E-09.1 レース間隔プロファイル

確認するもの：

- 休み明け / 叩き2戦目 / 連戦時の内容
- 中2〜3週等の短間隔でパフォーマンスを維持できるか
- 休養後にテンション・行きっぷり・末脚がどう変化するか
- 使い詰めで終盤性能や反応が落ちる傾向があるか
- 同じ間隔でも相手レベル・距離・馬場が違う点

「中4週2戦2勝」のような少数例だけで好走パターンと断定しない。サンプル数とレース内容を同時に記録する。

### E-09.2 枠・馬番・馬群プロファイル

単なる枠別成績ではなく、

- 内枠で包まれた時の反応
- 外から被された時の挙動
- 馬群を割れるか
- 外枠から自分のリズムで先行できるか
- 内をロスなく立ち回れるか
- ダートで砂を被っても走れるか
- キックバックを嫌って頭を上げる、位置を下げる等があるか
- 外々を回した時の距離ロス耐性

を確認する。

特にダートでは、**内枠有利 / 不利より「その馬が砂を被った状態で能力を出せるか」**を優先する。

### E-09.3 コース物理特性プロファイル

競馬場名だけでなく、可能な範囲で次へ分解する。

- 右回り / 左回り
- 直線の長さ
- 急坂 / 平坦
- コーナー半径・角度
- 3〜4角の下り・上り
- 小回り適性
- スタートから最初のコーナーまでの距離
- 直線入口で必要な加速性能
- 長くトップスピードを維持する必要性

「東京巧者」ではなく、**長い直線で持続加速できる馬**のように能力特性へ翻訳し、他コースへの転用可能性を検証する。

### E-09.4 馬場・天候・降雨プロファイル

確認するもの：

- 良→稍重→重で脚色がどう変化するか
- 高速馬場で追走負荷が上がる / 下がるか
- 時計が掛かる馬場で持続力が生きるか
- 芝の水分で加速が鈍るか
- 湿ったダートで前進するか
- 雨によるキックバック変化への対応
- 降雨中でも集中力・行きっぷりを維持できるか

「雨だから得意」ではなく、**雨で変化した走行条件に適性があるか**を評価する。

### E-09.5 適用方法

第2サイクルでは、モード1の最終予想対象、モード2の購入候補、重賞について、原則として、

- 基準予想上位5頭
- 価格妙味候補
- 展開の鍵を握る馬

を詳細対象とし、その他の馬は一次確認に留めて情報コストを管理する。

E-09は加点表として合算せず、

- 通常シナリオで能力を再現できる確率
- 特定枠 / 馬群 / 馬場で能力が減衰するシナリオ

を分けるために使う。

厩舎の一般的な休み明け・ローテーション傾向は基準となる基本予想の15.1で扱う。E-09では**当該馬自身がその条件にどう反応したか**を扱い、同じローテーション事実を厩舎要素と馬個体要素で二重計上しない。

第2サイクルでは基準予想順位を無断で変更せず、**E-09を反映した場合にどの馬が何段階・何pt動くかを比較用予想として記録**する。

### E-09.6 記録・評価

最低限、

- 使用した個体条件
- 過去サンプル数
- 証拠強度（強 / 中 / 弱）
- 基準予想との差分
- 結果
- 改善 / 中立 / 悪化

を保存する。

少数サンプル由来の条件一致が多いほど評価を上げる方式は禁止する。

## E-10：年齢・性別構造優位分析 / 古馬混合の若駒・牝馬構造優位

**優先度：A / 第2サイクルは比較用予想**

古馬混合戦で、若駒や牝馬が馬柱上の古馬実績だけでは見えにくい優位を持つ条件を検証する。

### E-10.1 若駒で確認する要素

- 実斤量差・斤量恩恵
- 前走からの成長速度
- キャリアの浅さによる能力上限の未確定性
- 同世代重賞・条件戦のレベル
- 絶対時計・巡航速度を古馬水準へ置き換えた場合の位置
- 距離短縮 / 延長で古馬との差が縮まるか
- 季節による完成度
- 馬体増減と成長の整合性

**「古馬実績がない」ことを「古馬に通用しない」と同義にしない。**

### E-10.2 牝馬で確認する要素

- 性別による斤量差
- スピード要求度・瞬発戦 / 持久戦
- 馬体サイズと接触・揉まれリスク
- 外をスムーズに走れる配置か
- 性別限定戦で記録した絶対時計・上がりを混合戦水準へ換算した位置
- 混合戦で要求されるフィジカルと位置取りを満たせるか

### E-10.3 禁止事項

- 3歳だから一律加点
- 牝馬だから一律加点
- 斤量差だけで能力差を相殺したことにする
- キャリアが浅いこと自体を上昇材料にする

上げるのは、**今回条件で具体的な構造優位を説明できる場合だけ**とする。

### E-10.4 記録

古馬混合戦では、該当する若駒・牝馬について、

- 年齢・性別
- 斤量差
- 基準予想評価
- 構造的優位の根拠
- 比較予想評価
- 着順

を保存し、複数開催で再現性を確認する。

## E-11：高確信度集中投資 / 高確信度への資金集中

**優先度：A+ / 実戦検証中ルール / HF1 Shadow専用**

HF1以降、E-11は**Production基準買い目を固定した後にだけ生成するShadow比較買い目**とする。E-11案が高期待値に見えても、その理由だけで正式推奨へ差し替えない。

予想段階では複数シナリオを保持する一方、Shadow購入段階では**最も期待値の高い本線シナリオへ意図的に資金を集中する**ことを検証する。

E-11の「高確信度」は主として**予想確信度**を意味し、実際に資金を集中する最終判断では**購入確信度**も併用する。

### E-11.1 適用候補

次が複数揃う場合に比較予想を作る。

- ◎の勝率が明確に最上位
- 2番手との差が十分ある
- 予想確信度がB+以上
- 位置取り・展開の主シナリオが読みやすい
- ◎が崩れる独立シナリオが少ない
- 初条件・出遅れ・馬場未知等の重大な不確実性が小さい
- 三連単等の価格が三連複・縦目保険より魅力的

固定数値閾値は第2サイクルでは設定せず、適用理由を文章で記録する。

### E-11.2 ◎依存型を許容する条件

48.2 万能軸監査で最終的に許容される場合、

- ◎からの馬連・ワイドのみ
- ◎1着固定の三連単
- ◎→○▲→○▲△☆等のフォーメーション
- ◎を含む本線だけへ資金集中

を許容する。

**馬依存率100%を避けること自体を目的に、低い期待値の縦目を追加しない。**

縦目は、独立して買い目期待値が正の場合だけ購入候補とする。

### E-11.3 本線ワイド基準額 / 本線ワイド基準単位

レース予算が**3,000〜5,000円程度**で、最重要ワイドが、

- 本線シナリオそのもの
- 2頭の同時3着内確率が高い
- 予想確信度がB+以上
- E-08の保守側予測価格でも買い条件を維持

する場合、**1,000円を基準投入単位として検討する。**

これは固定購入額ではない。価格・予想確信度・最終購入確信度に応じて減額し、**最終購入確信度がB+以上かつ高い期待値**なら1,500円以上も許容する。逆に低オッズ・期待値が境界付近・購入確信度 B-以下なら1,000円未満または見送りとする。

### E-11.4 三連単への変換

◎の1着確率が高く、相手順位にも一定の差がある場合、三連複を機械的に買うより、

- ◎1着固定
- ◎→○▲→○▲△☆
- ◎→○▲△→○▲△☆

の三連単を少額で候補化する。

順序の確信が低い場合は、2頭軸マルチやフォーメーションをE-12と組み合わせる。

### E-11.5 検証指標

- 通常分散案と集中比較予想の回収率
- 的中率
- 平均払戻
- 最大ドローダウン
- 馬依存率・シナリオ依存率
- 本線的中時に十分な利益を取れた割合
- 縦目保険を削ったことによる機会損失

を分離して記録する。

## E-12：人気構造別券種選択 / 人気構造別券種ルーティング

**優先度：S / 実戦検証中ルール / HF1 Shadow専用**

HF1以降、E-12は**Production基準買い目を固定した後にだけ生成するShadow比較買い目**とする。市場構造に適した券種が見つかっても、同レースの正式推奨をE-12で差し替えない。

市場の人気構造と本線ペアの性質に応じて、Shadow側の券種優先順位を変える。

人気だけで購入可否を決めず、最終的には35.1 買い目期待値とE-08予測最終価格で確認する。

### E-12.1 人気馬同士が本線

本線2頭が上位人気同士の場合、原則優先順位は、

1. **馬連**
2. **本線ワイドを厚く**
3. **三連単**（1着固定、2頭軸マルチ、フォーメーション）
4. **三連複は価格が十分な場合だけ**

とする。

人気馬中心の三連複は低配当化しやすいため、**原則低優先**とする。ただし買い目期待値が明確に高い場合は禁止しない。

### E-12.2 人気馬 × 穴馬が本線

本線が人気馬と穴馬の組み合わせなら、

1. **ワイドを本線として厚く**
2. 馬連を連対シナリオとして追加
3. 両馬が3着内に来るシナリオが強い場合、**三連複2頭軸 → 相手**
4. 人気馬の勝ち切りが強い場合、**人気馬1着固定三連単で穴馬を2・3着へ配置**

を優先する。

「人気馬×穴馬」の価格差を最大限活かしながら、穴馬3着でも利益が残る構造を目指す。

### E-12.3 人気馬3頭中心の三連複

人気上位3頭中心の三連複は、**購入優先度を原則低くする。**

ただし、成立確率が価格に対して十分高いと買い目期待値で説明できる場合のみ購入可能とする。

「安いから禁止」ではなく、**安い組み合わせは他券種より高い成立確率を要求する**と解釈する。

### E-12.4 強い本命1頭を中心に着順まで読む

◎が明確で、2・3着候補の順位差もある場合は、

- 馬連 / 馬単
- ◎1着固定三連単
- 少数フォーメーション

を優先し、三連複を広く買うより順序情報を収益化する。

### E-12.5 市場構造の判定時点

市場構造は、原則として最終予想固定時点時点の人気順と、E-08の予測最終オッズレンジを使って判定する。

最終予想時に人気順位が境界で入れ替わる可能性が高い場合は、Typeを固定せず2案を比較する。

### E-12.6 検証記録

各購入候補で、

- 人気構造タイプ
- 基準予想の通常買い目
- E-12 Routing後の比較買い目
- 本線ワイド投入額
- 三連複 / 三連単の使い分け理由
- 的中率・回収率
- 本線的中時の利益額

を保存する。

# 検証課題一覧 — v1.5.4 第2サイクル重点項目

以下は基本予想へ自動適用する加点表ではない。**v1.5.5-HF1 Production基準予想との差分を測る検証課題**として扱う。v1.5.0で継続対象だった検証項目は削除せず保持し、E-09〜E-12を追加して優先順位を再整理する。

## S：最優先（詳細検証項目）

1. **E-09 馬個体適性分析**
   - モード1最終予想、モード2購入候補、重賞で上位5頭＋価格候補＋展開キー馬を詳細確認する。
   - レース間隔 / 枠・馬番 / 馬群・砂被り / コース物理特性 / 馬場・降雨の5系統を記録する。
   - 少数サンプルを加点表にせず、証拠強度と基準予想との差分を保存する。

2. **E-12 人気構造別券種選択**
   - 「人気馬同士／人気馬×穴馬／人気馬3頭中心／強い本命1頭」ごとに券種構成・投入額・回収率を比較する。
   - 人気馬中心の低配当三連複を見送った機会損失も必ず記録する。

3. **E-08 最終オッズ予測の確率精度の検証**
   - JRA公式の取得時刻、発走までの残り時間、券種別オッズ、確定最終値をセット保存する。
   - 中心値より、予測レンジと「買い条件を跨ぐか」の精度を優先して評価する。
   - 購入遅延・締切超過が減っているかも同時に採点する。

4. **自然な組み合わせ監査の非劣化検証**
   - 印内に1〜3着が揃っているのに自然な組み合わせを欠落する買い目構築ミスが減少したか測る。
   - 候補生成増加によって低い期待値馬券の購入点数が不必要に増えていないかも確認する。

5. **万能軸監査の損失集中抑制効果**
   - 馬依存率・シナリオ依存率と損失率を記録する。
   - 低い期待値の「保険」を増やさず、依存額または総投資額の調整で改善できているか確認する。

6. **最終順位保全の改善／悪化率**
   - 事前基本予想上位馬を維持した場合と、強い新情報で変更した場合を分離する。
   - 変更しなかったことによる機会損失も記録し、順位保全が硬直化になっていないか確認する。

7. **確信度保全 / 予想確信度・購入確信度分離の非劣化検証**
   - 初期予想確信度→最終時点の予想確信度の変更段階数、予想確信度理由01〜予想確信度理由07などの理由コード、改善 / 中立 / 悪化を保存する。
   - オッズ変動だけで予想確信度を変更したケースを0件にする。
   - 購入確信度グレード別回収率と、予想確信度 / 購入確信度乖離が大きいレースの成績を確認する。
   - モード2では購入優先度と予想確信度を混同していないか監査する。
