- 対象リポジトリ: eda-hub/horse-man
- 調査基準: main commit `d262aa69e255d7a6a7a2c82338c04ce9c943f3c3`（PR #38マージ後）
- 状態: 運用総括・次サイクル計画。第2サイクルの正式KPI確定・昇格審査は未完了。
- 第3サイクル実施計画: [cycle_03.md](../validation/cycle_03.md)

## 1. 総括

第2サイクル最大の問題は、**予想モデルの性能を比較する以前に、検証サイクルを自動で成立させる運用が実際には動いていなかったこと**である。

「モード5を自動実行する」「保存する」「監査する」という規定は存在した。しかし、対象判定から比較予想・比較買い目の発走前固定、保存・読戻し、別チャットでの再利用、結果後のKPI集計までの一巡を、追加指示なしで継続できていなかった。主要Shadowの有効比較0件は、仮説に効果がなかった証拠ではなく、効果を測れる実行証跡が不足していたことを示す。

第1サイクルでは順位変更・自然な組み合わせ・万能軸等の監査を正式化した。第2サイクルではその非劣化とShadowの追加価値を測る予定だったが、既存監査の実行・記録不足が再発した。第3サイクルでは、運用成立性と予想性能を別々に判定し、運用が成立した比較集合から性能を評価する。

既存日別recordの「適格」はその記録の主張として扱う。今回、全保存commit・当時の契約・読戻し証跡を再監査したものではない。PR #38のreceipt契約をそれ以前へ遡及適用することも、古い記載だけで現在の厳格な適格性を保証することも行わない。

### 第2サイクル終了処理の残件

1. 日別の期待race_id集合を確定し、KPIごとの対象・適格・不適格・保留を1レース単位で照合する。
2. 各記録に適用されたmanual commitと契約開始時点を確認し、当時の必須項目・保存証跡と突合する。存在した証拠の転記訂正と、結果後の新設を区別する。
3. 6R / 18R / 9/22追加分、購入4R / 9/22追加3Rの差を説明し、cycle_02の冒頭・表・日別recordを同じ集計範囲へ揃える。
4. 国内開催上限96Rと、集計に含まれる海外のジョッキークラブゴールドカップを区分する。海外例を含む分子を国内96Rで割らない。
5. 第2サイクルのデータ・未判定事項を確定commitで固定する。最終KPIが保留でも運用総括と次サイクル準備は進めるが、終了審査済み・昇格済みとはしない。

## 4. 第3サイクルへ繰り越す検証

優先度は検証・是正の順序を示す。現行必須工程の省略許可ではない。

| 優先度 | 繰越対象 | 不十分な点 | 第3サイクルで得る証拠・判定 |
|---|---|---|---|
| P0 | 検証サイクル自動成立 | 追加指示なしで一巡した実績なし | 起動から保存・比較・回顧・集計までの連続証跡と介入回数 |
| P0 | 日次ブランチ・receipt・時刻・復旧 | 主に静的/机上確認 | 実I/O・安全な障害模擬・別コンテキスト読戻し |
| P1 | 自然な組み合わせ・48.2・単勝整合 | 監査ラベルと判断根拠の接続不足 | 候補生成、券種別確率レンジ/価格、採否理由、監査後判断 |
| P1 | E-09、51B、E-10 | 有効比較0件または少数 | 同じProductionとの発走前ペア。非該当根拠と未実行理由 |
| P1 | E-11/E-12、E-08 | 比較買い目・価格時点の不足 | 固定仮想資金、共通価格、最終価格、通常案との差分 |
| P1 | E-04、U-01、U-01Q | 低評価馬の事前固定なし | pace_key、未知度、primary候補、U-01Q発動/非発動の事前記録 |
| P1 | 確信度・順位保全・市場独立性 | 順位は一部追跡可能、確率/変更根拠不足 | 市場前の固定、変更理由、確率帯別実績、午前→最終差分 |
| P2 | U-02 | 取得率・期間・母数・コスト未測定 | 指標×期間別の取得率/追加価値。取得不能はUNAVAILABLE |
| P2 | E-13 | P/A/B共通適格0件 | 同一入力、3分上限、有効衝突/NO_DELTA、8R運用・20R参考精度 |
| P2 | E-03/E-07、①＋②主従、券種集中、長距離ハンデ、詳細分析差分 | 条件別の再現例不足 | 条件該当時の前向き比較。旧版の確信度表記等は現行Ownerと照合して開始 |

U-01/U-01Q/U-02とE-13の「第2サイクル限定」適用は、次サイクルへ自動延長されたと解釈しない。第3サイクル開始準備で継続対象・条件を正式登録する。E-13の8R/20Rは既存パイロットの運用/参考比較目安であり、全仮説共通の昇格基準ではない。

### 今回追加する診断観点

- 上位馬同士の先行競合を共通シナリオとして事前記録し、E-04・当日馬場・E-09を別採点する。
- ◎-○に加え、◎-▲等の自然な券種候補を落とした理由を監査する。結果を見て全ワイド購入へ変えない。
- 予想確信度Cの購入候補化/見送り理由を、順位収束・価格・情報不足と分離して記録する。単発の反実仮想利益で閾値を緩めない。
- 開催場が中山/阪神から東京/京都へ変わった際の静的資料・当日バイアスの取り違えと、3日間連続開催での時刻・branch・scopeの持越しミスを検査する。

## 5. 終了判断

- **保護**: Productionの能力評価骨格、市場/Shadow逆流禁止、見送り、固定仮想資金と実購入の分離。
- **改善対象**: 実行・保存・時刻・引継ぎ・監査・集計の接続。
- **継続検証**: 証拠不足の仮説・非劣化確認。未実行0件を効果ゼロとして棄却しない。
- **昇格判断**: 本総括では新たな昇格なし。正式KPIと非劣化・複数条件の再現性を確認して別PRで審査する。
