# ☆印廃止と印体系単純化 — 次回サイクル向け変更案

- 作成日：2026-09-20
- 状態：**次回サイクル開始時の正式変更候補**
- 現行基準：v1.6.1
- 適用予定：**第2検証サイクル終了後、次回サイクル開始時**
- 対象Owner候補：`docs/manual/10_prediction.md` / `docs/manual/30_betting.md` / `docs/manual/40_shadow.md` / `docs/manual/50_review.md`
- **第2検証サイクル中は適用しない。**
- **2026-09-20以前のProduction印・snapshot・回顧を遡及変換しない。**

## 1. 背景

現行の印体系は、

- ◎：中心馬
- ○：対抗
- ▲：次位有力馬
- ☆：人気薄になりやすく、合理的な勝利シナリオを持つ一発候補
- △：主に2〜3着候補

としている。

しかし☆だけが、

- 能力順位
- 勝利シナリオ
- 市場人気
- 妙味
- 買い目での昇格

を同時に表しており、他の印より役割が多い。

さらに現行Productionは「市場価格だけで能力順位・印を変更しない」原則を持つため、**「人気薄」という市場属性を印そのものへ内包する☆は、Productionの市場独立性と相性が悪い。**

このため、次回サイクルでは☆を廃止し、能力順位と価格妙味を完全分離する案を正式変更候補とする。

## 2. 変更案

新しい基本印体系を、

> **◎ / ○ / ▲ / △1 / △2 / △3**

とする。

6頭を選択する場合のProduction順位との対応は、

| Production順位 | 印 |
|---:|---|
| 1位 | ◎ |
| 2位 | ○ |
| 3位 | ▲ |
| 4位 | △1 |
| 5位 | △2 |
| 6位 | △3 |

とする。

選択頭数が6頭未満の場合は、存在する順位まで使用する。頭数を埋めるためだけに△を追加しない。

## 3. 各印の役割案

### ◎

レース全体で最も勝つ可能性が高く、最も信頼する中心馬。

- Production順位1位
- 原則として単勝対象
- 連系の中心候補

### ○

◎に最も近い対抗。

- Production順位2位
- ◎を現実的に逆転できる
- ◎とは別の万能軸へ自動昇格しない

### ▲

3番手評価の**主要勝ち候補**。

「特殊な低確率条件を複数要求しなくても、主要シナリオのどれかで◎・○を逆転して勝つ現実的可能性がある馬」を置く。

現行☆が持っていた「合理的な勝利シナリオ」が本当に強い場合は、今後は☆ではなく▲として評価する。

### △1〜△3

Production4〜6位のヒモ候補。

- 基本役割は2〜3着
- 勝つ可能性をゼロとはしない
- ただしProduction上の主要勝ち候補には含めない
- 市場価格が高いことだけで▲へ昇格させない

△内でも購入構築用に、

- **2着まである△**
- **3着寄りの△**

を内部属性として持つことを認める。

この属性は新しい印を増やすためではなく、馬連・三連系の列判断に使う。

## 4. ▲と△の境界

次回サイクルで最も重要な判定点とする。

### ▲に置く条件

少なくとも、

- 主要シナリオで勝利まで届く
- ◎・○を逆転するために極端な事故・展開待ちを必要としない
- 勝率・能力評価が上位3頭として妥当
- 市場人気を見なくても3番手以内に置ける

ことを基本とする。

### △に置く条件

- 主な価値は2〜3着
- 勝つには複数条件の好転が必要
- 勝利シナリオは存在しても低確率
- Production上では上位3頭より明確に下

とする。

「穴だから▲」「人気だから△」のような市場ベースの印変更は禁止する。

## 5. 妙味・人気薄の扱い

☆廃止後、妙味は**印とは別レイヤー**で扱う。

候補表現：

- 市場より過小評価
- 適正価格
- 市場より過大評価
- 妙味あり / なし

例：

> △1 ⑧○○ — 市場より過小評価

と表現してよい。

ただし、妙味評価だけで△1を▲へ上げない。

これにより、

- Production印 = 能力・適性・状態・展開
- 購入判断 = 市場価格との比較

を明確に分離する。

## 6. 「最も買いたい馬」と印の分離

☆廃止後も、

- 最も勝つと思う馬
- 最も買いたい馬

は分離する。

最も買いたい馬が△1であってもよい。

ただし、

> 最も買いたい馬 = 単勝対象  
> 最も買いたい馬 = 万能軸

とはしない。

単勝は現行35.2の原則どおり◎のみを基本とする。

△の妙味は、

- 複勝
- ◎との連系
- 三連系3列目
- 2着まである△なら馬連相手

など、既存の券種成立条件と価格を通じて表現する。

## 7. 買い目ルールへの影響

☆廃止に伴い、`30_betting.md` の☆専用処理を整理する必要がある。

### 馬連

変更後の基本：

- ◎-○：本線
- ◎-▲：主要相手
- ◎-△：**2着まである△**だけ候補
- 3着寄り△は馬連相手にしない

### ワイド

基本：

- ◎-○
- 条件が合えば◎-▲

現行の「◎-☆ワイド」は廃止する。

△とのワイドを機械的に禁止する必要はないが、価格だけを理由に下位△へ広げる運用は採らない。もし△とのワイドが主要買い目になるほど同時好走確率が高いなら、Production順位自体が妥当か再確認する。

### 複勝

現行☆専用ではなく、

- 市場より過小評価された▲
- 2〜3着価値が高い△

を対象に、独立して期待値を評価する。

### 三連複

基本形候補：

> ◎ - ○▲ - ○▲△1△2△3

ただし全△を自動採用しない。

2着まである△・3着寄り△を区別し、価格と成立確率から点数を削る。

### 三連単

基本形：

> ◎ → ○▲ → ○▲△

◎の逆転候補は原則○▲まで。

△を1着列へ入れたいほど勝利評価が高い場合は、まずProductionで▲へ上げるべきかを再確認する。

## 9. 過去データとの互換性

過去Productionは変更しない。

- 過去の☆を△へ書き換えない
- 過去snapshotを新体系へ変換しない
- 過去回顧の☆表記を修正しない

サイクル横断比較では印記号そのものより、

- Production順位1位
- Production順位2位
- Production順位3位
- 上位3頭勝ち馬捕捉率
- 上位6頭勝ち馬捕捉率

旧☆は「旧体系の4番手とは限らない」ため、☆→△1の機械変換をしない。

## 10. 期待する効果

1. **Production順位が単調になる**
   - ◎○▲△1△2△3 = 1〜6位が明確。

2. **市場独立性が強くなる**
   - 人気薄という理由を印から除去できる。

3. **▲の役割が明確になる**
   - 「◎を逆転できる主要勝ち候補」を上位3頭に集約。

4. **△の役割が明確になる**
   - ヒモ候補として2〜3着価値を表現。

5. **買い目との整合性が上がる**
   - 勝てるほど評価する馬を下位印のまま馬券だけ上位列へ上げる矛盾を減らす。

6. **KPIが読みやすくなる**
   - 印とProduction順位が一対一に近づく。

## 11. リスク

### 11.1 混戦で上位3頭に圧縮しすぎる

4番手にも高い勝率があるレースは存在する。

対策：

- 印ではなく勝率・レンジで差の小ささを表す。
- 例：▲16%、△1 14%でもよい。
- △1だから勝率が低いと機械的に制限しない。

### 11.2 妙味馬が見えにくくなる

対策：

- 「市場評価との乖離」を別欄で明示。
- 印へ妙味を混ぜない。

### 11.3 △が増えて区別しづらい

対策：

- 表示を△1 / △2 / △3と順位付きにする。
- 内部属性「2着まで / 3着寄り」を保持する。

### 11.4 過去サイクルとの印別比較が崩れる

対策：

- サイクル横断KPIはProduction順位ベースを優先。
- 印別の旧新比較は制度変更前後で区切る。
