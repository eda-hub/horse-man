## 模擬1レースの手順予行（TABLETOP）

入力: `TEST-C3-01`を検証用だけに選定、ProductionはA/B/C、非価格更新なし、当日入力の一部は最終待ち。実在馬・実オッズは使わない。

1. 初回：市場前Productionを固定→検証フラグtrue/購入false→適用項目・最終待ち入力を台帳へ固定→本体/receiptの順で確認。
2. 最終：同branch/同baselineを回収→動的情報更新→REUSEDを固定→該当予想Shadowを別生成。入力不足の項目は理由付き未完了のまま、非該当へ変えない。
3. 買い目：価格時刻・自然な候補・券種別確率下側・依存額/率・崩れるシナリオ・採否・監査後判断を記入できるか照合。欠けるケースは正式FIXEDを止める。揃ったケースの検証用案は正式購入推奨と分離。基準案固定後に比較買い目を置く。
4. 保存・回答：本体・receipt両方を確認し、必須Shadow未完了ならProductionを維持しつつ未完了/影響を回答。一巡正常完了にしない。
5. 回顧：初回scope1Rを残し、結果取得→KPI別判定→日別record→cycle集計と照合。集計失敗ケースではCYCLE_AGGREGATION_PENDING。発走前の不足を結果後に作らない。

これは出力欄・分岐の机上予行であり、実際の予想生成・実レース保存・実回顧の代替合格ではない。
