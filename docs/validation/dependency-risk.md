# 31番：構成依存と任意市場の仮想資金リスク

## 価格不要の依存監査

dependency_risk.auditは候補券一覧、採用券一覧、軸馬、任意の全出走集合/枠対応から独立した読取結果を作る。候補と採用を別々に計数し、馬別点数、同一展開シナリオ別点数、軸を含む点数/割合を示す。馬別点数の総和は重複所属するため券点数ではない。

順序なし券は馬番を正規化し、馬単/三連単は順序を保持する。同一券は同じ/異なるシナリオであっても二重登録・二重計上を拒否。採用は候補の部分集合、同一券のシナリオも一致させる。取消・未知馬は与えた全出走集合と照合する。

既存推奨原本には候補券全点の記録がないため、recommendation.displayでは候補点数を「未記録」と表示する。採用点数を候補点数へ代用しない。原本から軸馬番号を特定できない表示入口では軸馬を推測せず、既存のALL/PARTIAL/NONE監査と馬別/シナリオ別点数を表示する。関数/CLIへ軸馬を明示した場合だけ点数依存率を求める。

枠連は特定馬への依存と同じではないため枠券数・枠依存を別集計する。標準7券種の推奨生成へ枠連を追加しない。表示・監査は予想/推奨の順位・券・価格・金額を変更しない。

## 任意市場の仮想配分

標準推奨は金額を要求しない。任意のallocationsで採用全点にamount_yen（0以上の整数円）を明示した場合だけ、合計配分、最大単券額、同一馬依存額、枠依存額を求める。未記録の配分を0として補完せず、重複配分/未採用券/欠測を拒否する。馬別額を合計配分として足し合わせない。

金額は仮想配分の分析入力であり、購入記録・実購入・投票・資金上限の新設ではない。枠連額を枠内すべての馬へ加算せず、馬別額は馬番号券の分、枠別額は枠券の分として読む。

## 全損率

配分だけでは全損率は未算定。周辺確率の積や軸依存率を全損率と呼ばない。

joint_modelを明示した場合だけ、入力した網羅・排他な共同結果モデルに条件付く全損率を算定する。必要項目はcoverage=EXHAUSTIVE_DISJOINT、source_ref、probability_method、place_places、outcomes。各outcomeは全出走馬の一意なfinish_orderと0〜1のprobabilityを持ち、確率総和1を検査する。CALIBRATED区分は既存契約の校正参照を必要とするが、参照の存在を証跡認証済みとはしない。

各券の的中を全頭着順から再計算し、正額を配分した券が一つも的中しない結果の確率を足す。0円券の的中を損失回避と数えない。金額0の全損率は未算定。これは全正額券が不的中となる確率であり、的中しても払い戻し不足となる収支赤字率ではない。

モデルは入力の仮定に依存する。網羅宣言・出所参照・数値整合の検査は実データ妥当性や校正証跡の認証ではない。候補・金額・確率を生成せず、性能昇格しない。同着/返還/取消を含む共同結果のモデルは対象外として別途検証が必要。

## 入口と受入

`python3 scripts/dependency_risk.py <入力JSON>`で候補/採用点数、馬・シナリオ依存、任意の仮想資金集中と全損率を日本語表示。入力JSONはselected、anchor（未確認null可）、任意のcandidates、field_horses、frames、allocations、joint_modelを持つ。原本を変更しない。

31-01は候補/採用・馬/軸点数、31-02は展開/券の重複、31-03は資金集中/全損の未算定と条件付き算定を検査。実施記録はimplementation/2026-10-13-task31.json。実測妥当性・校正・性能評価は継続検証、任意市場は標準推奨の前提へ逆流しない。
