## 8. 運用問題の切り分け

### O-01 7R GitHub参照停止

- **事象**: ownerが明示されていないことを理由に `horse-man` の取得を停止。
- **本質**: 接続済みリポジトリ検索を実行せず、リポジトリ解決をユーザー入力依存にした。
- **影響**: ◎7勝利レースで最終Production・買い目・Betting KPIを固定できなかった。
- **是正**: `horse-man` を直接検索し `eda-hub/horse-man` を解決。owner未記載を停止理由にしない。
- **区分**: 改善対象。

### O-02 10R タスク開始時刻と発走時刻の混同

- **事象**: 14:35を発走締切と誤認。実発走14:50。
- **本質**: snapshot保存可否の判断前に、実際の発走時刻と現在時刻を照合しなかった。
- **影響**: 保存不可との誤報告。ユーザー指摘で訂正し14:40に発走前保存できた。
- **是正**: 最終予想開始時に `task_start_at / race_post_time / now / persistence_deadline` を区別して確認。
- **区分**: 改善対象。

### O-03 12R 回答前snapshot保存ゲート未実行

- **事象**: 最終Production/見送りを回答した後にGit保存。
- **本質**: `BETTING_FIXEDまたは最終判断 → save → readback → answer` を状態遷移として強制できていなかった。
- **影響**: 結果漏洩はないが、現行運用契約の順序違反。厳格な運用KPIは不適格。
