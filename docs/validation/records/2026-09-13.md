## 3. 中山11R セントライト記念 — 発走前固定あり

重賞記録 `docs/yosou/jra_racing/stLiteKinen.md` は commit `89dbaa4cbb91e5c405e451b231a4b15886036789` により **2026-09-13 15:28:51 JST** に固定され、発走予定 **15:45 JST** より前の保存であることを確認した。

発走前記録には少なくとも次が存在する。

- `baseline_forecast_id=20260913-NAK-11-P001`
- Production順位・印・中心勝率
- 予想確信度 `B`
- 情報時刻
- 当日馬体重の全頭取得状態
- 市場評価とProduction推奨買い目

一方、第2サイクルの正式購入KPI用に要求する**10,000円固定仮想買い目**は発走前記録に存在せず、ユーザー予算4,000円に対する3,000円推奨案だけが保存されている。

さらに、第2サイクルでモード5自動対象となる全重賞に必要な51B / E-09 / E-10 / E-11 / E-12の発走前Shadow比較記録も存在しなかった。

### KPI判定

- 予想精度KPI: **PREDICTION_ELIGIBLE**
- 購入・ROI KPI: **BETTING_INELIGIBLE**
- 51B / E-09 / E-10 / E-11 / E-12: **SHADOW_INELIGIBLE**
- 理由: Production予想本体は発走前固定済みだが、正式検証用10,000円固定仮想買い目と必須Shadow比較が未保存

不足した固定仮想買い目・Shadow比較を結果後に比例拡大・再構成してROIや比較評価へ算入しない。

### 確定結果とProduction採点

確定上位は、

1. ⑦ジャスティンシカゴ
2. ⑥サヴォアフェール
3. ②アウダーシア

Productionは、

- ◎⑩バステール：13着
- ○⑧ゴーイントゥスカイ：6着
- ▲⑤アスクエジンバラ：4着
- 4番手⑥サヴォアフェール：2着
- 6番手②アウダーシア：3着
- ⑦ジャスティンシカゴ：個別上位評価外

だった。

予想確信度Bの正式予想精度サンプルとして、

- ◎勝利：0
- ◎3着内：0
- 上位3頭による勝ち馬捕捉：0
- 勝ち馬⑦の個別捕捉：失敗

と採点する。

予想の詳細な原因分析は `docs/yosou/jra_racing/stLiteKinen.md` を正本とする。

### エラー要約

主因は、⑦について発走前に確認可能だった、

- プリンシパルS 0.1秒差2着
- 直近1勝クラス2馬身半差勝ち
- 操縦性改善を伴う成長情報
- 強い最終追い切り

を、既存Productionルールの成長・クラスアップ・近走内容評価へ十分反映できなかったこと。

分類は **E：成長・上昇度評価ミス / H：情報の解釈ミス** を主因、Aを副因とする。

実レースは前半1000m62.5秒のスロー寄りとなり、Productionが30%置いた「位置取り重視」シナリオ方向は合っていたが、そのシナリオの主要受益馬⑦を候補化できていなかった。

### 購入側

Production推奨三連複5点は確定②-⑥-⑦を含まず全て不的中。ただし実購入は未確認のため、実収支を推奨案から代入しない。

- 実購入額: 未確認
- 実払戻: 未確認
- 実収支: 算定不可
- 正式固定仮想ROI: 発走前10,000円案欠落のため算定対象外
