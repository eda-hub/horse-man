## 運用上の注意

1. 上記は**意味の解決**であり、的中率・回収率・再現性の確認ではない。
2. 固定閾値がない表現（相対馬体重、人気馬、中枠等）は、レースごとに発走前時点の具体的な判定根拠を記録する。
3. `欧州血統` のように複数解釈を包含する表現は、結果後の後付け判定を防ぐため、個別claim化時に該当理由を明示する。
4. 血統の内包判定は、個別の原文に `母父` 等の限定語がある場合、その限定を優先する。
5. これらの定義を理由に BACKFILL_SEED を自動でProduction加点へ昇格させない。通常の `docs/manual/` による評価を先に作成し、利用する場合はU-02のpre-race evidenceとして別途固定する。
