## 4. 人気・市場への引っ張られ監査

6レースの発走前Production上位3頭と最終人気順位を照合した。

- 野路菊S: Production上位3頭 = 1・3・2番人気
- 中山9R: 3・2・1番人気
- 阪神10R: 3・1・2番人気
- 中山10R: 1・9・2番人気
- 阪神11R: 2・1・3番人気
- 中山11R: 1・3・2番人気

計18枠のうち、**17枠が最終1〜3番人気**だった（94.4%）。
買い判定5レースに限っても15枠中14枠（93.3%）。

この高一致率だけで「オッズを見て能力順位を作った」と断定はしない。公開情報を正しく評価すれば市場上位と予想上位が一致すること自体は自然である。

ただし本日は、
- 全レースで完全な「オッズ取得前Production snapshot」を独立保存できていない
- U-01の非価格低評価馬スキャンを発走前固定できていない
- 結果として人気薄の独立評価が薄い
- 実際に二桁人気馬が複数レースで上位へ入り、そこを取り逃した

ため、**市場と独立していたことを証明できない**。これは市場逆流が発生したと断定するより、「市場独立性の監査証拠が不足している」と分類する。

### 次回からの市場独立性監査案

1. オッズを取得する前に、非価格情報だけでProduction順位・確率・3大要因を固定する。
2. `pre_market_rank_snapshot` と取得時刻を保存する。
3. その後にオッズを取得し、30_bettingだけで市場比較・買い目を作る。
4. Production上位3頭と市場上位3頭の重複数を診断値として保存する。
5. 一致率が高くても順位を変えないが、`MARKET_CONFORMITY_HIGH` として継続監査する。
6. Production固定後、結果前にU-01/U-02/E-04等の必須Shadowを完了し、人気薄候補は人気・オッズを見ずに抽出する。

これは新しい能力評価ルールではなく、現行の「オッズを能力順位へ逆流させない」原則を実証可能にする運用改善候補として扱う。

## 5. 本日の主要な改善候補

### A. 万能軸監査の実効性
中山10Rと阪神11Rでは、勝ち馬を印内に持ちながら全資金を敗れた◎へ依存させた。

仮説:
- 予想確信度B以下
- ◎の勝率が圧倒的ではない
- ▲・△にも合理的な勝利シナリオがある

場合、馬依存率100%を許容する条件をより厳密に監査する。

単発で30_bettingを変更せず、既存48系監査の適用精度として継続検証する。

### B. U-01実行漏れ
本日の国内最終予想では、Production固定後に実行すべきU-01 latent-upsideスキャンが発走前snapshotとして残っていない。

結果後に⑫ビーアイフォルテ、②トゥロン、⑩カルパ、①ハナウマビーチ等を候補へ追加しない。

分類:
- `SHADOW_INELIGIBLE`
- 予想ロジックの不足とは分け、検証プロトコル実行漏れとして記録する。

### C. 直系親の同一条件適性
ユーザー所感を起点に、中山10R⑨アロンズロッドで「母アーモンドアイの中山芝2500m実績」を事前適性仮説へ取り込めるか検証する。

現行22の範囲内で、
- 親の同一競馬場 / 同一距離実走を取得
- サンプル数と文脈を保持
- 本馬実績より下位
- 1戦だけで強い減点をしない

という条件で検証候補とする。

## 7. 結論

本日の問題は「人気馬を選んだこと」そのものではない。

1. Production上位3頭と市場上位3頭の一致率が94.4%と極めて高かった。
2. オッズ取得前の独立snapshotが完全ではなく、市場独立性を証明できない。
3. 人気薄を非価格で拾うU-01等の比較工程が発走前に固定されず、検証機会を失った。
4. 中山10R・阪神11Rでは能力候補を持ちながら、買い目を1頭へ集中させすぎた。

したがって次回は、**非価格Productionの先行固定 → 市場取得 → 買い目作成 → U-01等Shadow固定**の順序をより厳格に実行し、市場一致率と人気薄候補の捕捉を前向きに計測する。
