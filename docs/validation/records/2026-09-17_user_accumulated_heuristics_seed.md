## 今後の前向き使用ルール

該当レースで本カタログを参照する場合、次を守る。

1. まず通常のProduction能力・適性評価を `docs/manual/` に従って作る。
2. 本カタログの該当項目を検索する。
3. 使う場合は、複数主張を原子的なclaimへ分解してレース固有 `user_evidence_id` を付与する。
4. そのclaimについて、可能なら当該レース時点までのデータで妥当性を事前確認する。
5. `VERIFIED / PARTIAL / UNVERIFIED / CONFLICT` を固定する。
6. Productionへ使った場合は `production_usage` と `influence_area` を固定する。
7. 結果後に `factual_validity / predictive_relevance / decision contribution` を回顧する。
8. 高配当・的中だけを理由に当該seedを昇格させない。

## 検証上の注意

- 血統傾向はサンプル数、対象期間、馬場、クラス、人気、世代交代等の交絡を受けやすいため、単純な好走率だけで強い因果としない。
- 枠傾向はコース形態だけでなく開催時期、使用コース、馬場傷み、頭数、脚質構成との交絡を確認する。
- 騎手・厩舎傾向は騎乗馬・管理馬の能力水準や人気との選択バイアスを分離する。
- 「人気馬」等を条件に含むseedは、能力評価と市場評価が混ざるため、Production能力根拠へ直接使わず、原則Shadow/診断で扱う。
- 同じ血統語が複数回現れても、同一原因の言い換えや重複を独立証拠として加算しない。
