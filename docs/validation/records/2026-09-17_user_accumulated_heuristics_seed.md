## 今後の前向き使用ルール

該当レースで本カタログを参照する場合、次を守る。

1. まず通常のProduction能力・適性評価を `docs/manual/` に従って作る。
2. 本カタログの該当項目を検索する。
3. 使う場合は、複数主張を原子的なclaimへ分解してレース固有 `user_evidence_id` を付与する。
4. そのclaimについて、可能なら当該レース時点までに元ソース・母集団・期間・サンプル条件を確認する。
5. `VERIFIED / PARTIAL / UNVERIFIED / CONFLICT` を発走前に固定する。
6. Productionで使った場合は、能力・適性・展開・状態・確信度・買い目のどこへ影響したかを記録する。
7. 結果後に factual validity / predictive relevance / decision contribution を分離採点する。
8. 同じseedが複数レースで再現した場合だけ、確認優先度・evidence weight調整候補とする。

`UNVERIFIED` のままでもShadow/診断材料として保持できるが、単独で強いProduction加点・減点へ使わない。
