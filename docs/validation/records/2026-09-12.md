最大の問題は単純な的中・不的中ではなく、**同一レースについて別チャット間でProduction相当の基準予想が大きく分岐していたこと**。

別系統の予想では⑮を上位に置いていたが、結果だけを見て「そちらが正解だった」とは扱わない。⑧・⑦まで含めて十分に捉えていたわけではなく、結果後の枝選びは後知恵になる。

この運用上の問題が、

- `baseline_forecast_id`
- 同一レースProductionの一意性
- Production / Shadow分離

を正式化する直接の背景となった。

## 3. 当日全体の主要な反省

### 3.1 買い目と資金配分

ユーザー所感として、資金量の低さだけでなく、**的中した場合でも払戻が伸びにくい配分**になっている可能性がある。

少額資金で複数券種・複数点へ広げると、1点あたりの金額が薄くなり、予想が当たっても回収額が伸びにくい。

今後は、

- レース構造から券種を先に選ぶ
- 少額ほど主力券種へ集中する
- 上位予想が明確なら下位馬を無理に買わない
- 本線的中時のトリガミを原則回避する

ことを正式運用へ反映する。

### 3.2 合理的に切った馬の扱い

予想下位馬を事前情報から合理的に切った結果、その馬が好走しても、**外したという事実だけで改善ルールを追加しない**。

回顧では、

- 合理的切り
- 想定外要素が上回った
- 事前確認可能な重要材料の見落とし
- 資金配分上の不採用
- 価格だけで印や役割を崩した判断

を分離する。

「何でも拾える予想」へ広げることで予想の鋭さを失わないことを優先する。

### 3.3 印と券種の役割

本日の回顧後の議論で、◎○▲☆△の役割、◎中心の買い目、券種選択、単勝ボーダー、複勝の独立性、馬連・ワイド・馬単・三連系の利用条件を再定義した。

これらは検証待ちではなく、**v1.6.0の正式実戦ルールとして即時適用**する。

本日の成績はそのルール導入の原因データであるため、v1.6.0の有効性サンプルには含めない。

### 3.4 オッズ予測

予想時オッズと最終オッズの乖離は改善対象とする。

今後は可能な範囲で、

- 予測最終オッズ
- 予測時刻
- 購入時オッズ
- 最終オッズ
- 人気順位

を保存し、単なる平均誤差だけでなく、**購入判断を変えた乖離**を重点的に評価する。
