# 2026-09-16 U-01 latent-upside 事前検証開始記録

## 位置づけ

- 対象: 第2検証サイクル
- 状態: 2026-09-16以降の対象レースで前向き検証開始
- 基準Production: `v1.6.1` のまま変更しない
- 検証種別: 補助Shadow / 診断
- 正式Productionの印・確率・買い目への自動反映: なし
- 恒久設計候補: `docs/jravan/13_ability_uncertainty_review.md`

目的は、結果後に無印好走馬を見てから「拾えたはず」と説明するのではなく、発走前の時点で次を区別して保存すること。

1. 中心能力が低く、比較材料も十分で合理的に切った馬
2. 中心能力は低いが、能力上限が未観測で推定幅が大きい馬
3. 上振れ方向の事前証拠が複数あり、候補抽出から漏れる危険がある馬

前開催の内容は今回だけ仮説生成に使用するが、過去レースをU-01の前向き成績へ後付け算入しない。

## 前開催からのseed hypothesis

### 1. ユーザー所感

2026-09-13時点で次の所感が記録されている。

- ◎本命馬が1着になるレースは多かった。
- 2着馬が無印だったレースが多かった。
- ◎以外で印を付けた馬は3着に入るケースが多かった。

この所感は集計済み統計ではないため、U-01では「無印2着候補を発走前に識別できるか」という仮説のseedにだけ使用する。

### 2. セントライト記念の具体例

⑦ジャスティンシカゴはProduction上位3頭外だったが、回顧では発走前に取得可能だった次の材料が確認されている。

- LプリンシパルS 0.1秒差2着
- 直近1勝クラスを2馬身半差で勝利
- 操縦性改善
- 好調教

この事例は「人気薄だから拾う」ではなく、**能力上限がまだ十分観測されていない馬に、上級条件接戦 + 自己条件完勝 + 実戦再現性改善という複数の上振れ証拠が重なっていた**例としてseedに使う。

ただし同レースはU-01開始前なので、U-01の捕捉成功・失敗件数には算入しない。

### 3. ローズステークスを反証例として扱う

ローズステークスは結果1〜3着を ◎⑦・△②・▲⑥ で捕捉している。したがって、無印馬救済を毎レース機械的に広げる仮説は採用しない。

U-01の目的は「無印を増やして全部拾う」ことではなく、既存の印で十分捕捉できているレースでは候補追加を抑え、**本当に能力推定幅が大きく、かつ上振れ証拠がある馬だけを別タグで残すこと**とする。

## 今回の候補抽出方針

Production順位・印・確率を先に固定する。その後、全出走馬を軽量スキャンし、無印または下位印を中心に次を確認する。

### 能力未知度を上げる要素

- キャリアが浅く、同等クラスとの直接比較が少ない
- 昇級直後で能力上限が未観測
- 条件替わりが大きく、過去平均をそのまま使いにくい
- 近走で成長・時計・位置取り・末脚・操縦性などが急改善している

未知要素だけでは候補にしない。

### 上振れ候補化を支える事前証拠

原則として、未知度に加えて複数の事前証拠を要求する。

- 上級条件 / L / OP等で通用を示す接戦内容
- 自己条件で能力差を示す勝ち方
- 時計・ラップ・追走・末脚の複数方向の改善
- 相手強化でも能力を維持できる根拠
- 操縦性・位置取り・実戦再現性の改善
- E-09やコース要求との適合が上振れシナリオを支える
- 調教・馬体等が実走改善と独立して補強する

同一原因の言い換えを複数根拠として数えない。

## オッズの扱い — U-01では候補抽出に使わない

ユーザー仮説として、こうした潜在上振れ馬は高オッズになりやすい可能性がある。そのため本事前検証では、候補抽出・候補強度の判定に人気・単勝オッズ・組み合わせオッズを使用しない。

順序を次で固定する。

```text
Production固定
→ 非価格情報だけでlatent-upside候補固定
→ 必要なら市場価格を後から記録
→ 結果確認
```

市場価格は、

- 潜在候補が実際に高オッズへ偏るか
- Shadow比較買い目の払戻 / ROIがどうなるか

を診断するためには保存してよい。ただし、候補を選ぶ理由や候補から外す理由にはしない。

Production正式買い目の市場評価は引き続き `30_betting.md` に従い、U-01の実験を理由に価格原則を変更しない。

## 発走前snapshot

候補馬ごとに最低限次を固定する。

| field | 値 |
|---|---|
| horse | 馬名 / 馬番 |
| production_mark | ◎○▲☆△ / 無印 |
| baseline_rank | Production基準順位 |
| evidence_coverage | LOW / MEDIUM / HIGH |
| ability_uncertainty | LOW / MEDIUM / HIGH |
| upside_evidence | NONE / WEAK / MODERATE / STRONG |
| upside_role | 2着圏 / 3着圏 / 上位全般 |
| latent_upside_candidate | true / false |
| evidence | 発走前に確認した根拠 |

`latent_upside_candidate=true` は、原則 `ability_uncertainty=HIGH` かつ `upside_evidence>=MODERATE` を目安にするが、機械的な点数ルールとしてProductionへ適用しない。

## 買い目比較

U-01単独ではProduction正式買い目を変更しない。

比較買い目を作る場合は、事前証拠が最も強い `primary latent-upside candidate` を原則1頭まで選び、Productionの中心軸は変えず相手列へ追加するShadow構造だけを保存する。

目的は、

- 2着無印漏れを減らせるか
- 3着無印漏れを減らせるか
- そのために何点増えるか

を測ることであり、オッズを見て都合のよい候補だけを採用しない。

## 回顧分類

結果後、重要な無印好走馬は発走前snapshotだけを使い次へ分類する。

- `SIGNAL_MISSED`: 事前の上振れ証拠を中心評価へ十分反映できなかった
- `UNCERTAINTY_UNDERMODELED`: 中心評価は合理的だが能力推定幅を狭く扱いすぎた
- `RATIONAL_EXCLUSION`: 中心能力が低く上振れ根拠も乏しく、事前除外は合理的だった
- `POST_HOC_ONLY`: 結果後にしか成立しない説明

## U-01診断指標

正式な第2サイクル主KPIとは分離し、補助診断として次を集計する。

- 対象レース数
- latent-upside候補数 / 1レース平均候補数
- 無印2着以内馬の事前捕捉率
- 無印3着馬の事前捕捉率
- primary候補の2着内率 / 3着内率
- 候補追加Shadowによる的中構造改善件数
- 追加点数
- 誤検出率
- 候補馬の最終オッズ分布（候補選択には不使用）
- 参考Shadow ROI（正式ROIとは分離）

候補捕捉率だけを最大化しない。候補数が過剰なら失敗と評価する。
