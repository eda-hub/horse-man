## 役割

ここには、Production確定後に生成したShadow比較、検証中ルールの差分、固定仮想買い目、KPI集計など、**検証の実データだけ**を置く。

ルール定義の正本は `docs/manual/` であり、このディレクトリをルール定義・システム設計・障害対応手順の正本として扱わない。取得方式や実装上の恒久対策は `DECISIONS.md` / `docs/jravan/` を参照し、ここへ重複定義しない。

## 固定仮想資金

### レース単位

- 買い判定：10,000円固定で仮想買い目を作成
- 見送り：正式投資0円
- 見送りでも強制10,000円の反実仮想案を参考保存可
- 反実仮想は正式ROIへ算入しない
- 実購入は別帳簿

### 日次単位

- 買い判定レースを購入優先度順に並べる
- 上位最大5レースを採用
- 1レース10,000円、1日最大50,000円
- 5レース未満なら残額は未投資
- 6位以下も全買い判定ROIには残す

## 予想確信度

Production予想確信度は `A / B / C / D` の4段階を使用する。購入確信度は別尺度として `A+〜C-` の9段階を維持する。

## 主KPI

1. 日次上位5レース仮想ROI
2. 全買い判定レース10,000円固定ROI
3. 選別リフト
4. 本線成立時ROI
5. トリガミ率
6. 予想確信度A/B/C/D別予想精度
7. 購入判断変更級オッズ誤差率

補助として、キャリブレーション、Brier Score、見送り反実仮想ROI、券種別ROI、最大ドローダウン、最大連敗数等を記録する。

## 前向き検証レースの事前固定

結果後の後知恵を防ぐため、KPIごとに**発走前に保存されていた項目だけ**を使用する。結果後に欠けた値を再構成して適格化しない。

### 予想精度KPIの適格条件

正式な予想精度サンプルには、発走前に最低限次を固定する。

- `baseline_forecast_id`
- レース識別情報・情報取得時刻
- Production順位・印・確率
- 予想確信度
- 当日予想では当日馬体重の取得状態

これらが揃っていれば、購入側の記録欠落だけを理由に◎勝率・上位3頭捕捉率・確率校正等の**予想精度サンプルまで捨てない**。

### 購入・ROI KPIの追加適格条件

購入・ROI・オッズ予測KPIへ算入するには、上記に加えて発走前に次を固定する。

- 買い / 見送り判定
- 使用オッズと取得時刻
- 買い判定時の10,000円固定仮想買い目・資金配分
- オッズ予測KPIを評価する場合は予測最終オッズ等の必要値

購入側だけ不足した場合は、`PREDICTION_ELIGIBLE / BETTING_INELIGIBLE` のようにKPI別に適格性を分ける。Production予想自体が発走前に固定されていない場合は予想精度KPIからも除外する。

## 保存形式

- サイクル集計：`cycle_02.md`
- 必要な日別・レース別記録：`records/YYYY-MM-DD.md` または `records/<race-id>.md`

同一内容を `40_shadow.md` や個別予想ファイルへ重複保存しない。個別レースの詳細が `docs/yosou/` にある場合は、ここには適格性・集計値・参照先など検証に必要な最小限だけを残す。
