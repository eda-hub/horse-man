## 役割

ここには、Production確定後に生成したShadow比較、検証中ルールの差分、固定仮想買い目、KPI集計など、**検証の実データだけ**を置く。

ルール定義の正本は `docs/manual/` であり、このディレクトリをルール定義の正本として扱わない。

## 固定仮想資金

### レース単位

- 買い判定：10,000円固定で仮想買い目を作成
- 見送り：正式投資0円
- 見送りでも強制10,000円の反実仮想案を参考保存可
- 反実仮想は正式ROIへ算入しない
- 実購入は別帳簿

### 日次単位

- 買い判定レースを購入優先度順に並べる
- 上位最大5レースを採用
- 1レース10,000円、1日最大50,000円
- 5レース未満なら残額は未投資
- 6位以下も全買い判定ROIには残す

## 予想確信度

Production予想確信度は `A / B / C / D` の4段階を使用する。購入確信度は別尺度として `A+〜C-` の9段階を維持する。

## 主KPI

1. 日次上位5レース仮想ROI
2. 全買い判定レース10,000円固定ROI
3. 選別リフト
4. 本線成立時ROI
5. トリガミ率
6. 予想確信度A/B/C/D別予想精度
7. 購入判断変更級オッズ誤差率

補助として、キャリブレーション、Brier Score、見送り反実仮想ROI、券種別ROI、最大ドローダウン、最大連敗数等を記録する。

## 前向き検証レースの事前固定

正式な予想精度サンプルは、発走前にProductionスナップショットを保存できたレースだけとする。最低限、`baseline_forecast_id`、レース識別情報、情報取得時刻、Production順位・印・確率・予想確信度、買い/見送り判定、使用オッズの時刻を保存する。当日予想では当日馬体重の取得状態も保存する。

結果後に欠けていた予想値を補完して正式サンプル化しない。事前スナップショットが欠けた場合は結果と確認済みの事実だけを記録し、監査欠落として正式KPIの分母から除外する。
