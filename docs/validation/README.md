## 固定仮想資金

### レース単位

- 買い判定：10,000円固定で仮想買い目を作成
- 見送り：正式投資0円
- 見送りでも強制10,000円の反実仮想案を参考保存可
- 反実仮想は正式ROIへ算入しない
- 実購入は別帳簿

### 日次単位

- 買い判定レースを購入優先度順に並べる
- 上位最大5レースを採用
- 1レース10,000円、1日最大50,000円
- 5レース未満なら残額は未投資
- 6位以下も全買い判定ROIには残す

## 予想確信度

Production予想確信度は `A / B / C / D` の4段階を使用する。購入確信度は別尺度として `A+〜C-` の9段階を維持する。

## U-01 能力未知度 / latent-upside 事前検証

本項は第2サイクルだけの前向き検証運用であり、正式なProductionルールではない。恒久設計候補は `docs/jravan/13_ability_uncertainty_review.md` を参照する。

2026-09-16以降、本サイクルでProduction最終予想を保存する対象レースでは、Productionの順位・印・確率を固定した後、結果確認前かつ発走前に全出走馬を軽量スキャンする。目的は、無印馬について「中心能力が低い」と「中心能力の推定幅が大きい」を分離して事前保存することである。

最低限、候補馬について次を保存する。

- Productionの印・基準順位
- `evidence_coverage`: LOW / MEDIUM / HIGH
- `ability_uncertainty`: LOW / MEDIUM / HIGH
- `upside_evidence`: NONE / WEAK / MODERATE / STRONG
- 上振れ根拠の要約
- `latent_upside_candidate`: true / false
- 候補なら想定役割：2着圏 / 3着圏 / 上位全般

候補抽出では**人気・単勝オッズ・組み合わせオッズを使用しない**。まず非価格情報だけで候補を固定し、その後に市場価格を記録する場合も、候補選定の根拠へ逆流させない。これにより「潜在上振れ候補は実際に高オッズになりやすいか」自体を結果と独立して観察できる。

Productionの正式印・正式買い目はU-01だけを理由に変更しない。比較買い目を作る場合は、買い目点数の無制限な膨張を避けるため、事前証拠が最も強い `primary latent-upside candidate` 1頭を上限として、Productionの中心軸を変えず相手列へ追加したShadow構造を保存する。オッズ不足を理由に候補自体を消さない。

回顧では、無印好走馬を発走前snapshotだけから `SIGNAL_MISSED / UNCERTAINTY_UNDERMODELED / RATIONAL_EXCLUSION / POST_HOC_ONLY` に分類する。結果後に候補を新設して適格化しない。

本検証の開始根拠・前開催からの仮説は `records/2026-09-16_latent_upside_precheck.md` に保存する。前開催の事例は仮説生成にだけ使用し、U-01の前向き成績には算入しない。

## U-02 騎手・厩舎定量プロファイル事前検証

本項は第2サイクルだけの補助的な前向き検証であり、正式なProductionルール、固定スコア、加減点表ではない。目的は、現行ルール15 / 15.1 / 51-8 / 51-8.1で確認対象となっている騎手・厩舎情報について、**安定取得できる範囲、適切な集計期間、母数、予測への追加価値、取得コスト**を前向きに測ることである。

### 実行原則

- Production順位・印・確率を固定した後にU-02を実行し、同一レースのProductionへ逆流させない。
- 全出走馬について取得コストの低い共通項目を可能な範囲で揃える。細条件はProduction上位5頭、U-01 primary候補、E-04 `pace_key` 候補を優先してよい。
- 各集計値には**対象条件、集計期間、母数**を必ず対応付ける。期間不明・母数不明の率を比較根拠にしない。
- 取得不能項目を推測・補完せず `UNAVAILABLE` とする。
- 固定総合点、最低母数、最適集計期間、各指標の重みは本サイクル中に確定しない。

### 取得候補

可能な範囲で、当年、直近4週、直近8週、当該競馬場、芝 / ダート・距離帯、重賞、騎手×当該馬、厩舎×今回騎手等について、出走数・勝率・連対率・複勝率を取得する。単勝回収率・複勝回収率や人気・オッズ補正は取得できる場合の追加診断とし、必須化しない。

期間を比較できる場合は同じ指標を `YTD / LAST_4W / LAST_8W` 等のラベル付きで保持し、後から都合のよい期間だけを選ばない。

### シグナルを潰さず保持する

馬個体の直接実績と一般的な騎手・厩舎統計が衝突する場合を検証できるよう、少なくとも次を分離して保存する。

- `jockey_general_signal`: POSITIVE / NEUTRAL / NEGATIVE / UNKNOWN
- `trainer_general_signal`: POSITIVE / NEUTRAL / NEGATIVE / UNKNOWN
- `jockey_horse_signal`: POSITIVE / NEUTRAL / NEGATIVE / UNKNOWN
- `trainer_jockey_signal`: POSITIVE / NEUTRAL / NEGATIVE / UNKNOWN
- `jockey_evidence_coverage`: LOW / MEDIUM / HIGH
- `trainer_evidence_coverage`: LOW / MEDIUM / HIGH
- 各シグナルの証拠強度: WEAK / MODERATE / STRONG
- `horse_direct_evidence_alignment`: SUPPORT / CONFLICT / NONE
- `context_connection`: 今回の展開・位置取り・仕上げ・ローテとの接続理由
- `shadow_direction`: UP / HOLD / DOWN

`shadow_direction` は成分を固定重みで合算した点数ではない。今回の展開・位置取り・仕上げ・ローテとの接続を文章で確認したうえで、診断上の方向だけを保存する。

### 回顧・評価

結果後は、各成分シグナルと集計期間を分けて、好走率・誤検出、Production上位馬間の順序判断への追加価値、無印・低評価馬の事前捕捉、馬個体実績との衝突時の成否、取得率・取得コストを比較する。結果を見てから条件や集計期間を追加して適格化しない。

サイクル終了時に、指標ごと・期間ごとに **採用 / 継続検証 / 棄却 / 判断保留** を判定する。

## 前向き検証レースの事前固定

結果後の後知恵を防ぐため、KPIごとに**発走前に保存されていた項目だけ**を使用する。結果後に欠けた値を再構成して適格化しない。

### 予想精度KPIの適格条件

正式な予想精度サンプルには、発走前に最低限次を固定する。

- `baseline_forecast_id`
- レース識別情報・情報取得時刻
- Production順位・印・確率
- 予想確信度
- 当日予想では当日馬体重の取得状態

これらが揃っていれば、購入側の記録欠落だけを理由に◎勝率・上位3頭捕捉率・確率校正等の**予想精度サンプルまで捨てない**。

### 購入・ROI KPIの追加適格条件

購入・ROI・オッズ予測KPIへ算入するには、上記に加えて発走前に次を固定する。

- 買い / 見送り判定
- 使用オッズと取得時刻
- 買い判定時の10,000円固定仮想買い目・資金配分
- オッズ予測KPIを評価する場合は予測最終オッズ等の必要値

購入側だけ不足した場合は、`PREDICTION_ELIGIBLE / BETTING_INELIGIBLE` のようにKPI別に適格性を分ける。Production予想自体が発走前に固定されていない場合は予想精度KPIからも除外する。

## 実行完了ゲート — 既存モード5規約の適用漏れ防止

本節は新しい予想ルールを定義せず、`docs/manual/50_review.md` の第2サイクル・モード5自動実行規約が**実際に発走前保存まで完了したか**を監査する運用ゲートとする。

モード5自動対象レース、とくに全重賞では、Production固定後かつ結果確認前に、該当する比較予想・比較買い目が保存されているか確認する。

- 51B
- E-09
- E-10
- E-11 / E-12

対象レースで必須Shadowが欠落した場合：

1. Production予想精度KPIの適格性はProduction固定条件だけで独立判定する。
2. 欠落したShadow項目は `SHADOW_INELIGIBLE` として記録し、結果後に再構成して適格化しない。
3. サイクル記録へ実行漏れとして即時記録し、次対象レースではProduction保存だけで処理完了と扱わない。
4. 既存ルールの定義不足ではなく運用漏れの場合、単発事象だけで `docs/manual/` に重複ルールを追加しない。

2026-09-13セントライト記念で、Productionは発走前保存された一方、必須Shadowの事前固定が欠落したため本ゲートを追加した。
