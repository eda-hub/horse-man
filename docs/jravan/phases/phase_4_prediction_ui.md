# Phase 4 — Prediction Web UI

## 目的
Macのブラウザから日常の予想操作を可能にする。

## 対象
- レース一覧
- race detail
- marks / score /根拠表示
- 血統/近走/当日情報
- PRE/DAY/FINAL切替
- FINAL確定
- User Note
- data freshness/status

## 受入条件
- MacからWindows VMへローカル接続できる。
- Internetへ公開されない。
- FINAL確定前後の状態が明確。
- 既存CLIを使わず主要予想情報を確認できる。
- Web UIから任意SQL/OSコマンドを実行できない。
