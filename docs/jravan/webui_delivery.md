# WebUI 実装・検証記録（2026-10-02）

依頼：Macのブラウザから初回予想で候補を絞り、対象だけの最終予想・買い目を確認し、購入・見送りを記録できる最小WebUIを本人限定でホストする。

| 要件 | 実装 | 検証結果 |
|---|---|---|
| 全レース初回一覧 | 1回72レースまでのINITIAL取り込み、開催日・競馬場選択 | API取り込み／ページHTML生成を確認 |
| 検証・購入候補の選別 | 独立した2チェック、件数と対象一覧 | APIで候補変更を保存・読戻し |
| 対象だけの最終予想 | 候補一覧のみ表示、未選定FINAL取り込みを拒否 | 未選定FINALを拒否し、候補選定後のFINAL保存を確認 |
| 基準予想の維持 | 初回とFINALの基準・馬・順位・印・勝率を一致確認 | 基準不一致・確率変更を拒否 |
| FINALを上書きしない | 初回／FINAL各1snapshot、同一再取り込みのみ許容 | 同一重複を無害化、変更のあるFINALを拒否 |
| オッズの区別 | 観測・予測最終・予測レンジを別列に表示 | 型検査とデータ読戻し |
| 見送り記録 | 理由とメモ、snapshot参照を保持 | 理由未入力・その他説明不足を拒否、見送り保存後も買い目を保持 |
| 購入判断 | 購入候補・FINAL・買い目・発走前・100円単位が必要 | 不正金額／FINALなし／発走後を拒否、保存と見送りからの訂正履歴を確認 |
| 判断履歴 | append-only event、revisionの一意制約 | 訂正前のSKIP保持、古いrevisionを拒否、同じ操作の再試行を重複保存せず異なる内容を拒否 |
| 永続化 | サーバーD1、owner単位、UI保存時刻、JSON書き出し | 別リクエストで再取得し保存状態を確認 |
| 認証・隔離 | ホストは本人限定、APIは認証ID必須、ownerで全クエリを絞る | 無認証401、別ownerから既存記録が見えない、別Originの書込403 |
| 実データ／サンプルの分離 | 別raceキー、UIの種類選択とサンプル帯 | 両データ取り込みを確認、実データのmodule hash不足・未来作成時刻を拒否 |
| 時点再現性 | release/hash/cutoff/source/created_atを保存 | cutoff逆転／発走後作成を拒否 |
| Macで利用 | ブラウザの標準API、レスポンシブCSS、loopback開発手順 | TypeScript／本番ビルド／HTML生成を確認。Safari実機は未確認 |

実行済み：`node node_modules/typescript/bin/tsc --noEmit`、Sitesの本番ビルド、`HORSE_TEST_MINIFLARE=1 node scripts/test-race-api.mjs`。APIテストはビルド済みのWorkerをMiniflareで動かし、生成されたmigrationを専用の一時D1に適用して実行した。全assertion成功。実ユーザーのデータ・認証情報をテストへ使用していない。

## 残る範囲

- ブラウザ自動操作用の機能が利用できず、Mac／Safariの実機クリック・見た目・200%拡大の検証は未実施。HTML生成、型、本番実行形式、保存APIは検証済み。
- WebMCPの候補読取・詳細表示をfeature detection付きで実装したが、対応ブラウザ内の登録・呼出確認は未実施。未対応ブラウザでも通常UIは動く。
- JRA-VAN/JV-Link自動取得、予想エンジン、DuckDB自動同期、結果精算、AI回顧は既存設計の後続実装。今回は予想JSONを取り込んで利用する。
- UI保存は公式execution gate／receipt／Git発走前保存の検証ではなく、Production/KPI適格性を新たに認定しない。
- サンプルは架空。初回表示で自動保存せず、操作用ボタンから明示的に読み込む。

## 運用境界

既存の `DECISIONS.md` と `docs/jravan/` はローカル優先のまま。本人限定ホストは今回の依頼によるWebUI先行配布で、D1はUIの予想コピー・判断記録に限定。DuckDBの正本や既存Markdown予想記録を置換しない。公開設定を変更する処理は実装していない。PAT・銀行・自動投票・外部AIキーは扱わない。
