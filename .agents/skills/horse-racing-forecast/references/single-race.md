# Single race workflow

## 原本の参照範囲

必ず0.1〜0.6、0.13、0.17〜0.18、1〜7、10〜18、21〜22、24〜32.1、35〜48、標準予想フローを読む。若駒・初条件は8〜9、Live補正は19〜20・34・37、穴軸は45・49も読む。

## 事前予想

1. 日付、競馬場、R、発走時刻、条件、全出走馬を公式情報で確定する。
2. 公開情報から近走内容、相手、時計・ラップ、位置、適性、状態、騎手、枠、馬場、オッズを収集し、事実→解釈→予測の`Evidence`にする。
3. 馬場サンプルが不足する場合は`morning`とし、少数結果からLive馬場を断定しない。
4. 市場価格を除いて3大要因、レース質、複数シナリオ、全馬確率、印、確信度を作り、Coreを保存する。
5. 該当Moduleだけを差分適用し、Experimentalは仮説IDと変更量を明記してFinalを保存する。
6. オッズを比較し、①/②/①＋②/見送り、最も勝つ馬、最も買いたい馬、穴軸昇格、買い条件、買い目を戦略として保存する。
7. 馬依存率・シナリオ依存率と100%依存警告を確認し、レースレポートを生成する。

## 直前更新

- 既存Coreを読み、馬体重、取消・騎手変更、最新馬場、最新オッズだけを追加調査する。
- 市場価格だけの変化は戦略へ反映し、Core能力評価や印を変更しない。
- Live馬場Moduleには複数の関連レース根拠を付ける。弱い証拠はシナリオ確率、不確実性、資金配分への小幅変更に留める。
- 新しいFinal revisionとStrategy revisionを保存し、旧スナップショットを上書きしない。
