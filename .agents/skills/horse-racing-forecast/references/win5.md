# WIN5 workflow

原本50章とWIN5標準フローを読む。対象5レースのdossierへ`win5Leg` 1〜5を設定し、通常ルールによるFinal勝率を先に完成させる。

1. 通常馬券の妙味順位ではなく勝率順位を使う。
2. ユーザーの点数上限を確認する。指定がなければ勝手に仮定せず尋ねる。
3. 次を実行して、点数とカバー率の非劣解を取得する。

```text
node dist/cli.js win5 analyze --date YYYY-MM-DD --max-points N [--unit-yen 100]
```

4. 1頭固定は中心勝率だけでなく、レンジ下側、2番手との差、複数シナリオ、位置・状態・操縦性、逆転シナリオを確認する。
5. 候補から外す馬を、評価外、点数制約切り、人気・配当を考慮した戦略的切りに分類する。
6. 混沌レースが複数、弱い固定、意味ある馬の大量切り、低い全体カバー率があれば見送る。
7. 市場人気と高配当余地は候補集合の確定後に評価する。

結果後は途中で外れても全5レースを回顧し、W-A〜W-Fの主因・副因と5レース中のカバー数を記録する。
